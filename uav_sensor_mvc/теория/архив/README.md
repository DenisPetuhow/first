держать под рукой: живой журнал стал **629 строк вместо 3 806**. Пункты не удалены —
ссылки из [указателя журнала](../журнал/README.md) ведут именно сюда.

**Действующий план один** — [планы/7_ЕДИНЫЙ_ПЛАН.md](../планы/7_ЕДИНЫЙ_ПЛАН.md):

на пронумерованные части (`ИМЯ_1.md`, `ИМЯ_2.md`, …) — как сделано с журналом.
