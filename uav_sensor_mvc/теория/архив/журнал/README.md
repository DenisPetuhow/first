## Правило

Часть журнала переезжает в архив, когда её пункты перестают запрашиваться в текущей
работе. **Ссылки при этом чинятся**: у перенесённого файла меняется глубина пути, и
относительные `../` перестают попадать в цель — это уже случалось при переносе
(24 ссылки в `ЖУРНАЛ_2.md`). После любого переноса — прогон `docmap.py`.
