# Структура теории — что лежит в каждом файле и папке

> **Что это.** Одна страница на ВСЮ документацию (`теория/`): каждая папка и каждый файл
> в ней — с однострочным «о чём» и прямой ссылкой. Не пересказ содержимого (оно в самих
> файлах и в README каждой папки), а **указатель второго уровня**, чтобы не открывать
> 14 разных README подряд в поисках нужного файла.
>
> **Не путать с [СТРУКТУРА_ПРОЕКТА.md](СТРУКТУРА_ПРОЕКТА.md)** — там КОД (файлы `.py`,
> классы, функции), здесь — ДОКУМЕНТАЦИЯ (файлы `.md`). Разные вопросы: «что делает
> `threat_grid.py`» — туда; «в каком файле написано про рельеф» — сюда.
>
> **Три уровня навигации**, как и everywhere в проекте: [README.md](README.md) (по
> задаче) → эта страница (по файлу) → [журнал](журнал/README.md) (по времени, «когда и
> почему»).
