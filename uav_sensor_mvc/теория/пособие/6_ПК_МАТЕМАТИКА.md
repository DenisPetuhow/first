## 0. Исходные данные, показатели и обозначения

Как в образце, параметры задачи разбиты на множества.

| Множество | Что входит | Где задаётся |
|---|---|---|
| **X** — входные | рамка района; слои OSM (реки, дороги, ЛЭП, просеки, застройка, населённые пункты); рельеф (`arh_hh.tif`); объекты защиты (цели) с приоритетами; точки входа или сектор появления; тип БПЛА (скорость V, крен φ, запас хода L_max, высота `alt_m`); типы средств (радиус R, кратность k, число N, правило места) | окна «Исходные данные», «Датчики», «Объекты защиты», «Условия моделирования»; `область.txt`; справочники `типы_датчиков.json`, `типы_бпла.json` |
| **Z** — внутренние | шаг сетки h; веса слоёв; силы и пороги рельефа; «температура» выбора соседа τ; веса критериев a1, a2; разнос | `config.py` |
| **E** — условия | запретные зоны; круглый ли район; паузы повтора стартов; профиль расхода запаса хода | интерфейс, `Params` |
| **Y** — выходные | весовая карта w; выборка маршрутов Γ = {γ₁ … γ_T}; расстановка S | расчёт |
| **Q** — показатели | доля покрытого веса; засечка ≥ 1 и ≥ k; средняя кратность; нагрузка на средство; рубеж первой засечки; приход по направлениям; время подлёта; зазор до лучшего | `ThreatModel.metrics()`, «Анализ» |

## 1. Сетка района

Район делится на квадратные ячейки размера h. Ячейка точки (x, y) определяется по формуле

```
iₓ = ⌊(x − x₀) / h⌋,   i_y = ⌊(y − y₀) / h⌋                                                    (1.1)
```

где x, y – координаты точки в плоском кадре района, км; x₀, y₀ – юго-западный угол сетки, км; h – шаг сетки, км
(`THREAT_CELL_M` = 500 м → 0.5 км); ⌊·⌋ – округление вниз (не `int`: у отрицательных чисел `int` округляет к нулю).
Центр ячейки — (x₀ + (iₓ + 0.5)·h, y₀ + (i_y + 0.5)·h).

**В коде:** `threat_routes._cell_of`, `ThreatGrid.cell_centers_km`, `threat_grid._cell_index`.
**Пример:** x₀ = 0, h = 0.5; точка x = 12.74 км → iₓ = ⌊25.48⌋ = 25, центр ячейки — 12.75 км.

## 2. Весовая карта — «где удобно лететь»

Вес ячейки w(e) — правдоподобие пролёта: аппарат держится линейных ориентиров, обходит города и возвышенности. Порядок
сборки важен (`threat_grid.build_grid`): слои → мосты → бонус пересечений → населённые пункты → рельеф — последним.

### 2.1 Вклад линейного слоя

```
вклад_L(e) = w_L · ℓ_L(e) / h                                                               (2.1)
```

где w_L – вес слоя L из `THREAT_LAYERS`; ℓ_L(e) – длина объектов слоя внутри ячейки e, км; h – шаг сетки, км.

Веса слоёв: река/канал 10; ручей 4; канава 2; дорога крупная 10; дорога местная 3; лесная дорога 2; ж/д 8; ж/д брошенная
8; ЛЭП 5; трубопровод 5; лесополоса 5; просека 10; мост 20; застройка −15 (площадной слой).

**В коде:** `ThreatGrid.add_line_layer`.
**Пример:** крупная дорога пересекает ячейку 0.5 км насквозь по прямой — 10·0.5/0.5 = **10**; по диагонали (0.707 км) —
14.1; задевает угол на 0.1 км — 2.0.

### 2.2 Площадной слой (застройка)

```
вклад_A(e) = w_A · Σ_P [центр e внутри контура P]                                           (2.2)
```

где w_A – вес площадного слоя (−15); P – контур; [·] – 1, если условие выполнено, иначе 0.

⚠️ После обработки населённых пунктов (§2.4) этот вклад **вычитается обратно**: город и деревня берут его роль на себя,
иначе деревня получала бы минус дважды (`apply_settlements`).

### 2.3 Бонус пересечения ориентиров

```
бонус(e) = b · max(0, m(e) − 1)                                                              (2.3)
```

где b – `THREAT_INTERSECTION_BONUS` = 5; m(e) – число разных слоёв-ориентиров в ячейке.

**В коде:** `ThreatGrid.add_intersection_bonus`.
**Пример:** в ячейке река, крупная дорога и ЛЭП — m = 3 → бонус 5·2 = **10**.

### 2.4 Населённые пункты

**Город** — пролёт запрещён: вес ячеек города с буфером `THREAT_URBAN_BUFFER_KM` = 0.4 км обнуляется.

**Деревня** — штраф от центра к краю:

```
           ⎧ p_ц + (p_к − p_ц) · t / 0.5,     t ≤ 0.5
штраф(t) = ⎨ p_к · (1 − (t − 0.5) / 0.5),     0.5 < t ≤ 1           t = d / r,   r = clip(√S, r_min, r_max)   (2.4)
           ⎩ 0,                                t > 1
```

где d – расстояние от центра деревни до центра ячейки, км; S – площадь деревни (связной группы её ячеек), км²;
p_ц = −10 (`THREAT_VILLAGE_PENALTY_CORE`); p_к = −5 (`…_EDGE`); r_min = 1 км, r_max = 4 км. Если ячейку задевают
несколько деревень, берётся наихудший штраф.

**Пол штрафа** — деревня ослабляет ориентир, но не стирает его:

```
w'(e) = max( w(e) + штраф(e),  min(w(e), f) ),   если w(e) > 0                               (2.5)
```

где f – `THREAT_VILLAGE_FLOOR` = 1. Ячейка с w ≤ 0 получает штраф без пола.

**В коде:** `ThreatGrid._village_field`, `apply_settlements`.
**Пример:** деревня 2.25 км² → r = 1.5 км. Ячейка в 0.3 км от центра: t = 0.2, штраф = −10 + 5·0.4 = −8. Река (w = 10)
даёт 10 − 8 = 2. Местная дорога (w = 3) даёт max(3 − 8, min(3, 1)) = **1**: пол держит коридор.

### 2.5 Рельеф — множитель

Превышение ячейки над окрестностью в двух масштабах:

```
A(e) = z(e) − z̄₁₅(e),    B(e) = z(e) − z̄₂(e)                                                  (2.6)
```

где z – средняя высота ячейки по рельефу, м; z̄₁₅, z̄₂ – средняя высота в квадратном окне ±15 км (`THREAT_DEM_AREA_KM`) и
±2 км (`THREAT_DEM_LOCAL_KM`) вокруг ячейки, м.

```
k(e) = clip( 1 − s_A · f(A / A₀) − s_B · f(B / B₀),  k_min,  k_max )                           (2.7)

         ⎧ x^1.5,    x > 0            (x предварительно зажат в [−1, 1])
f(x) =   ⎨
         ⎩ 0.5 · x,  x ≤ 0
```

где s_A = 0.75, s_B = 0.45 – силы района и окрестности; A₀ = 60 м, B₀ = 35 м – уровни насыщения; k_min = 0.25, k_max =
1.40. Асимметрия f намеренная: вверх штраф растёт быстрее (зона, откуда виден аппарат, растёт быстрее высоты), вниз
выигрыш умеренный.

```
w'(e) = max( w(e) · k(e),  min(w(e), 1) ),   если w(e) > 0;      w'(e) = 0,   если A ≥ 80 м или B ≥ 50 м     (2.8)
```

где 1 – пол коридора `THREAT_DEM_FLOOR`; 80 и 50 м – отсечка «уж очень высокой горы» (`THREAT_DEM_CUT_AREA_M`,
`…_LOCAL_M`). Множитель, а не слагаемое: ноль остаётся нулём — нет ориентира, нет и коридора.

**В коде:** `ThreatGrid.add_relief_layer`, `_relief_f`, `_box_mean`.
**Пример:**
* бугор: A = +30 м, B = +10 м → f(0.5) = 0.354, f(0.286) = 0.153 → k = 1 − 0.265 − 0.069 = **0.666**; дорога w = 10 → 6.66;
* низина: A = −30, B = −10 → k = 1 + 0.188 + 0.064 = **1.252** → 12.52.

### 2.6 Итог

```
w(e) = [ Σ_L вклад_L(e) + бонус(e) ] → населённые пункты (2.4–2.5) → рельеф (2.7–2.8)            (2.9)
```

## 3. Проходимость и область залёта

### 3.1 Проходимые ячейки

```
П = ( D_s( З_g( {e : w(e) > 0} ) ) ) \ (город ∪ отсечка рельефа ∪ запретные зоны ∪ вне круга района)      (3.1)
```

где З_g – замыкание (расширение и сжатие) радиусом r_g = round(0.5·Δ_разр / h) ячеек: «мостики» через провалы короче
разрыва Δ_разр = `threat_max_gap_km` = 2 км; D_s – расширение на r_s = round(Δ_ух / h) ячеек — уход от ориентира
Δ_ух = `threat_corridor_slack_km` = 1 км. Город, отсечка и зоны вычитаются **после** расширения, иначе оно их вернуло бы.
Вокруг входов и цели проходимость открыта квадратом ±3 км — «добраться до коридора».

**В коде:** `threat_routes.passable_mask`, `_open_endpoints`.
**Пример:** h = 0.5 → r_g = round(0.5·2/0.5) = 2, r_s = round(1/0.5) = 2 ячейки.

### 3.2 Поле расстояний (Дейкстра)

```
g(v) = min_u [ g(u) + ℓ(u, v) ],   ℓ = h (по стороне) или h·√2 (по диагонали),   g(старт) = 0          (3.2)
```

где u – проходимая соседняя ячейка из 8. Итог — кратчайший путь по проходимым ячейкам, км.

**В коде:** `threat_routes._dijkstra_dist`.

### 3.3 Область залёта

```
Ω = ⋃ᵢ { e : gᵢ(e) + g_ц(e) ≤ L_max,i }                                                       (3.3)
```

где gᵢ – поле от i-й точки входа; g_ц – поле от цели; L_max,i – запас хода у точки входа i. Ячейка достижима, если через
неё есть путь «вход → ячейка → цель» не длиннее запаса.

```
L_max,i = L_max,тип − |старт − вход_i|                                                          (3.4)
```

где |·| – прямая от точки старта БПЛА до точки входа, км; ручной запас из таблицы точек заменяет расчётный.

**В коде:** `threat_routes.flight_envelope`, `entry_L_max`; `ThreatModel.entry_L_max_km`.
**Пример:** «Лютый» (1 500 км), старт в 1 359 км от входа → в районе остаётся **141 км**.

## 4. Цена шага и поля «жадности»

### 4.1 Вес в долях

```
ŵ(e) = clip( max(w(e), 0) / P₉₀,  0,  1 )                                                     (4.1)
```

где P₉₀ – 90-й перцентиль положительных весов карты.

**В коде:** `threat_routes.weight_norm`.

### 4.2 Множитель цены ячейки

```
μ(e) = (1 + P_w · (1 − ŵ(e))) · (1 + P_r · (1 − k̂(e))),     k̂ = clip( (k − 0.25) / (1.40 − 0.25), 0, 1 )      (4.2)
```

где P_w – `THREAT_COST_POWER` = 1 (тяга к весу); P_r – `THREAT_COST_RELIEF` = 1 (тяга к низинам); k – множитель
рельефа (2.7). Дёшево там, где есть ориентир и где низко; оба множителя — от 1 до 2.

### 4.3 Цена шага и поле стоимости

```
c(u, v) = ℓ(u, v) · (μ(u) + μ(v)) / 2                                                           (4.3)
```

Поле стоимости G(v) — формула (3.2) с ценой c вместо длины ℓ. Цена симметрична: из A в B стоит столько же, сколько из
B в A.

**В коде:** `threat_routes._cost_mul`, `_dijkstra_cost`.
**Пример:** ŵ = 0.649, k = 0.666 → k̂ = 0.362 → μ = 1.351·1.638 = **2.21**. Шаг по стороне в соседнюю ячейку с μ = 1.5:
0.5·(2.21 + 1.5)/2 = **0.93**.

### 4.4 Поля разной «жадности»

```
μ_a(e) = 1 + a · (μ(e) − 1),    a ∈ {0; 0.35; 0.7; 1}   (`THREAT_COST_MIX_STEPS`)                    (4.4)
```

Для каждого a — своё поле до цели (a = 0 — чистые километры, a = 1 — полная стоимость). Каждый маршрут берёт одно:

```
i = min( ⌊u^β · 4⌋, 3 ),   u ~ U(0, 1),   β = `THREAT_COST_MIX_BIAS` = 0.8                          (4.5)
```

Отсюда P(i ≤ j) = ((j + 1)/4)^(1/β): вероятности полей — 0.177 · 0.244 · 0.278 · 0.302 (чаще берутся «жадные»).
Масштаб поля — f_s = среднее μ_a по проходимым ячейкам: на него умножаются пороги, заданные в км (§5).

**В коде:** `threat_routes.build_iter_context` (набор `gt_mix`), `sample_one_route`.

## 5. Маршрут — стохастический спуск по полю (Монте-Карло)

Маршрут идёт от входа к цели шагами по соседним ячейкам. На каждом шаге сосед v выбирается «рулеткой» с вероятностью,
пропорциональной его оценке.

### 5.1 Свободный запас и «температура»

```
s = (L_бюджет − ℓ_пройдено) − g_км(текущая)                                                     (5.1)
```

где g_км – кратчайший путь до цели в км (а не в стоимости — это про топливо). При s < 0 маршрут обрывается: дойти уже
нельзя.

```
τ = f_s · [ τ_т + (τ_св − τ_т) · min(1, s / 10 км) · ψ ]                                           (5.2)

     ⎧ 1 − доля,                                  профиль late (по умолчанию)
ψ =  ⎨ доля,                                      профиль early
     ⎩ clip( 0.5 + 3·(доля − потрачено), 0, 1 ),  профиль even
```

где τ_св = 0.20 (`_TAU_FREE`), τ_т = 0.05 (`_TAU_TIGHT`); доля – пройденная доля всего маршрута; потрачено – доля уже
истраченного свободного запаса; профиль расхода — `late` (по умолчанию: виляет в начале, к цели выпрямляется), `early`,
`even`.

### 5.2 Оценка соседа

```
σ(v) = exp( (G(тек) − G(v)) / τ ) · κ(ŵ(v)) · a(v)³ · η(v) · 0.12^[v уже пройдена]                 (5.3)
```

где:
* G – поле стоимости до цели (§4.4), его разность — продвижение к цели;
* κ – тяга к весу по режиму при g = `THREAT_WEIGHT_GAIN` = 4: «max» — 0.10 + g·ŵ; «min» — 0.10 + g·(1 − ŵ); «medium» —
  0.30 + 0.5·g·ŵ; «mix» — режим разыгрывается на маршрут;
* a(v) – средний множитель рельефа на `THREAT_LOOKAHEAD_KM` = 2 км впереди по этому направлению — холм видно заранее;
  степень 3 — `THREAT_LOOKAHEAD_POWER`;
* η – удержание курса. Пока пройдено меньше L_держ = min(max(1, L_прям), 6) км с последнего поворота: η = 14 (прямо,
  cos > 0.9), 2.5 (cos > 0.7), 0.5 (иначе); потом — η = 1 + 2.5·max(cos, 0). Здесь cos — косинус угла между курсом и
  шагом; L_прям = `threat_turn_interval_km` = 8 км;
* 0.12 – штраф за повторный заход в ячейку: гасит петли, но не запрещает (иначе тупики).

```
P(v) = σ(v) / Σ_{v'} σ(v')                                                                      (5.4)
```

**Запреты шага** (проходы от строгого к мягкому):
* сосед дальше от цели больше чем на 0.8·f_s;
* позади точки вылета больше 1 км;
* поворот круче предела θ_max (5.5);
* за 3 км курс сменился больше чем на 90°;
* сектор 140° радиусом 2 км позади пройденных точек;
* ближе 10 км к цели — удаление от неё больше 0.25 км за шаг.

**Предел поворота** — физика аппарата самолётного типа:

```
R_min = V² / (g · tg φ),        θ_max = min( 45°, max( 2·arcsin( h / (2·R_min) ), 45° ) )              (5.5)
```

где V – скорость, м/с; φ – крен; g = 9.81 м/с²; 45° – шаг направлений сетки: строже — значит «только прямо», и маршруты
не строятся (замер 21.09.2026). У мультиротора R_min = 0.

**В коде:** `threat_routes._walk_field`, `_spend_tau`, `_mode_corridor_pref`, `_lookahead_fields`, `turn_limit`;
`trajectories.turn_radius_km`.

**Пример.** Два соседа при τ = 0.20 (f_s ≈ 1.8, свободный запас 6 км, пройдено 30 %, профиль `late`), режим «medium»,
рельеф ровный (a = 1), курс держится:
* прямо: продвижение 0.5, ŵ = 0.8 → σ = e^2.46 · 1.9 · 14 = **311**;
* под 45°: продвижение 0.35, ŵ = 0.2 → σ = e^1.72 · 0.7 · 2.5 = **9.8**;
* P(прямо) = 311 / 321 = **0.97**.

«Лютый» (180 км/ч = 50 м/с, крен 25°): R_min = 2 500 / (9.81·0.466) = **547 м**; 2·arcsin(0.5 / 1.094) = 54.4° → предел
**45°**.

### 5.3 Сглаживание рисуемой линии

1. **Упрощение RDP** с допуском ε = clip(0.18·L_прям, 1.2·h, 8 км) = 1.44 км при L_прям = 8 км.
2. **Сплайн Катмулла–Рома**, центростремительный, α = 0.5; точек на звено — clip(длина / 1.5 км, 2, 24).
3. **Скругление** — 4 прохода p ← (p₋ + 2p + p₊) / 4, смещение не больше 0.25 км от расчётной линии.

Линия принимается, если она:
* не выходит из проходимого;
* сохраняет ≥ 97 % среднего веса расчётной (`SMOOTH_WEIGHT_KEEP`).

Иначе допуск делится пополам, до 5 раз.

**В коде:** `threat_routes._smooth_safe`, `_rdp`, `_catmull_rom`, `_round_corners`.

### 5.4 Длина и время

```
L(γ) = Σᵢ |pᵢ₊₁ − pᵢ|,      t(γ) = L(γ) / V                                                     (5.6)
```

**В коде:** `approach_time.route_length_km`, `approach_times` (наименьшее, медиана, наибольшее время по выборке).
**Пример:** L = 141.8 км, V = 180 км/ч → t = 0.788 ч = **47.3 мин**.

## 7. Матрицы покрытия — вход жадного

Для маршрута r (точки p₁ … p_P) и места c радиуса R:

```
H_rc = [ ∃ i : |pᵢ − c| ≤ R ]                                       засечка                     (7.1)
M_rc = Σ_{j=0}^{L−1} 2ʲ · [ ∃ i ∈ Iⱼ : |pᵢ − c| ≤ R ]               накрытые сегменты (биты)    (7.2)
F_rc = (1/P) · #{ i : |pᵢ − c| ≤ R }                                доля пути в зоне            (7.3)
```

где Iⱼ – номера точек j-го из L = `L_seg` = 10 равных по числу точек сегментов маршрута.

**В коде:** `optimization.CoverageCache.add_trajectory`; уже стоящие средства других радиусов — `_add_placed_row`.
**Пример:** маршрут из 200 точек; в круге места — 30 точек в сегментах 3 и 4 → H = 1, M = 2³ + 2⁴ = 24, F = 30/200 = **0.15**.

## 8. Жадная расстановка — три уровня ключа (критерии оптимизации)

Три уровня ключа (8.2)–(8.4) — **критерии оптимизации** (заказчик, 17.10.2026, вечер): по ним жадный выбирает следующее
место. Что в них выбрано, а не выведено, когда у жадного есть гарантия и как сделать постановку обоснованной —
[план 100](../история/планы/100_ПЛАН_ПОКАЗАТЕЛИ_И_ОПТИМИЗАЦИЯ.md) (задел).

### 8.1 Целевая функция

```
F(S) = (1/T) · Σ_r [ a1 · min(n_r(S), k) / k + a2 · |m_r(S)| / L ]                                (8.1)
```

где:
* T – маршрутов в выборке;
* n_r(S) – засечек маршрута r расстановкой S: Σ_{c∈S} H_rc;
* m_r(S) – накрытые сегменты: объединение битов M_rc по c ∈ S, |·| — число единиц;
* k – требуемая кратность (`threat_k` = 3);
* a1, a2 – веса критериев по режиму (`config.MODES`): сбалансированный 0.5 / 0.5 (по умолчанию), пересечение
  0.75 / 0.25, распределение 0.25 / 0.75.

min(n, k)/k — насыщение: засечки сверх k не нужны.

### 8.2 Уровень 0 — кратность и сегменты

```
Δ₀(c) = (1/T) · Σ_r [ a1 · ( min(n_r + H_rc, k) − min(n_r, k) ) / k  +  a2 · ( |m_r ∪ M_rc| − |m_r| ) / L ]      (8.2)
```

С бонусом места (план 13, 13.7): оценка = Δ₀(c) + s₁·b(c), где s₁ — наибольший Δ₀ первого шага, b — бонус места.

### 8.3 Уровень 1 — доля пути (когда у всех Δ₀ = 0)

```
Δ₁(c) = ε · (1/T) · Σ_r [ min(cov_r + F_rc, 1) − cov_r ]                                         (8.3)
```

где cov_r – доля пути маршрута r под наблюдением; ε = `SPREAD_EPS` = 1.

### 8.4 Уровень 2 — сколько маршрутов накрывает (когда и Δ₁ = 0)

```
Δ₂(c) = Σ_r H_rc                                                                                 (8.4)
```

### 8.5 Шаг прохода

1. Каждый тип t с неисчерпанной квотой предлагает своё лучшее доступное место:
   c*_t = argmax Δ_ℓ(c), где ℓ — младший уровень, на котором у типа ещё есть прирост.
2. Из предложений берётся младший уровень, на нём — наибольший прирост.
3. При равенстве (с точностью 10⁻¹²) ходит самый **стеснённый** тип:

```
стеснённость_t = (N_t − |S_t|) / #доступных мест_t                                                (8.5)
```

   при равенстве и в этом — тип с меньшим номером.
4. Место ставится, покрытие обновляется (засечки общие при «одной на все типы»):

```
n_r ← n_r + H_rc,   m_r ← m_r ∪ M_rc,   cov_r ← min(cov_r + F_rc, 1)                              (8.6)
```

5. **Разнос:** закрываются места того же типа ближе sep_t и места других типов ближе pair·(R_t + R_u):

```
sep_t = max( 1.6·R_t,  max(0.1, f_min)·R_t ),    pair = `THREAT_SPREAD_PAIR` = 0.8                  (8.7)
```

   где f_min = `threat_min_sep_frac` = 0.75 — нижний разнос, до которого желаемый 1.6·R ослабляется, если квота не
   набрана. Разнос между типами не применяется, если закрыл бы типу все места.
6. Закреплённые человеком места ставятся первыми, разнос — от них.

**В коде:** `joint_greedy.joint_greedy`, `_primary_gain`, `_Kind.gains`, `_Kind.cov_gains`, `_take`, `_exclude`;
`ThreatModel._greedy_weights`, `_sep_range`.

### 8.6 Оценка зазора до лучшего (граница Минью)

```
UB = F(S) + Σ_t top_{N_t}( Δ₀ ),      доля = (F(S) − F₀) / (UB − F₀)                                 (8.8)
```

где top_N – сумма N наибольших неотрицательных приростов типа на итоговом покрытии; F₀ – F до прохода. Гарантии:
* у одного типа — (1 − 1/e) ≈ 0.632 (F монотонна и субмодулярна);
* у квот по типам — 1/2 (матроид разбиения).

⚠️ Строго — только без попарного разноса: ОГРАНИЧЕНИЯ 1.14.

### 8.7 Пример с расчётом

Два маршрута, k = 3, a1 = a2 = 0.5, L = 10.
* **Состояние:** маршрут 1 — n = 0, сегментов 0; маршрут 2 — n = 2, сегментов 5, cov = 0.4.
* **Место c** засекает оба маршрута; добавляет маршруту 1 три сегмента, маршруту 2 — один; доли F = (0.2; 0.1).
* **Место d** засекает только маршрут 2 и добавляет ему 4 сегмента.

Приросты уровня 0:
```
Δ₀(c) = ½·[0.5·1/3 + 0.5·3/10 + 0.5·1/3 + 0.5·1/10] = ½·0.533 = 0.267
Δ₀(d) = ½·[0 + 0 + 0.5·1/3 + 0.5·4/10]          = ½·0.367 = 0.183
```

Выбрано **c**. Если бы уровень 0 был исчерпан: Δ₁(c) = ½·[0.2 + 0.1] = 0.15, Δ₂(c) = 2.

**Равенство между типами:** МОГ и ПВН предложили по 0.267. У МОГ поставлено 3 из 10 при 50 доступных местах —
стеснённость (10 − 3)/50 = 0.14; у ПВН 5 из 20 при 40 местах — (20 − 5)/40 = 0.375. Ходит **ПВН**.

**Разнос:** МОГ 1 км и ПВН 0.5 км — 0.8·1.5 = **1.2 км**; МОГ и пост 25 км — 0.8·26 = **20.8 км** (план 16 меняет это,
§10.1).

## 9. Показатели (множество Q)

```
доля покрытого веса = Σ_{e: w>0, ∃s: |e−s| ≤ R_s} w(e) / Σ_e max(w(e), 0)                            (9.1)
засечка ≥ 1        = (1/M) · #{ r : n_r ≥ 1 },        n_r = #{ s : minᵢ |pᵢ − s| ≤ R_s }                (9.2)
засечка ≥ k        = (1/M) · #{ r : n_r ≥ k }   («одна на все типы»; иначе — хоть один тип своими ≥ k_t)  (9.3)
средняя кратность  = (1/M) · Σ_r n_r                                                                  (9.4)
нагрузка средства s = 100 % · #{ r : s видит r } / M                                                  (9.5)
рубеж первой засечки d_r = | p_первая засечённая − цель |   (не засечён — 0); медиана и 10-й перцентиль   (9.6)
сектор прихода = round( азимут(цель → последняя точка дальше 0.5 км) / 30° ) mod 12                    (9.7)
```

где M – маршрутов в оценке; R_s – радиус своего типа у каждого средства; азимут — от севера по часовой.

**В коде:**
* `ThreatModel._evaluate`, `_detection`, `_meets_k`, `_covered_weight`, `sector_stats`, `_approach_bearing`;
* `sensor_load.seen_matrix`, `load_rows`; `target_stage.first_line`.

**Пример:**
* положительный вес карты 1 000, в кругах средств 530 → **0.53**;
* средство засекает 45 маршрутов из 150 → нагрузка **30 %**;
* азимут захода 47° → round(1.57) = 2 → сектор «60°» (он охватывает 45…75°).

**Доп. показатель — обзор средства и сумма** (проект; заказчик 17.10, вечер: «общий радиус обзора по каждому средству
и в сумме»; показ — [план 16](../история/планы/16_ПЛАН_РЕКОМЕНДАЦИИ_И_АНАЛИЗ_ОБСТАНОВКИ.md), задача 16.15):

```
ρ_s = R_s  (при «Реальной видимости» — R_факт,s = (1/72)·Σ_α r_s(α), (10.8));     сумма = Σ_s ρ_s;     прикрытие = Σ_s 2·ρ_s      (9.8)
```

**Пример:** 10 МОГ по 1 км — сумма 10 км, прикрытие 20 км; с «Реальной видимостью» у мест МОГ R_факт по медиане
0.43 км (шаг луча 15 м — не крупнее пикселя рельефа; при 50 м было бы 0.78) — прикрытие 8.6 км.
Как критерий не годится: сумма не учитывает перекрытия (план 100 §3.5).

### 10.1 Разнос средств разного масштаба (16.1, решение заказчика 17.10)

```
           ⎧ pair · 2 · R_min,         если R_max > 4 · R_min
sep(1, 2) = ⎨                                                                                     (10.1)
           ⎩ pair · (R₁ + R₂),         иначе
```

### 10.2 «Степень покрытия» с площадными средствами (16.1) — решение заказчика 18.10: вариант H

Подробный разбор с пошаговыми примерами (откуда «½·(0 + 2)» и «½·(2 + 2)», пост поверх малых, порядок у B) — [датчики/СТЕПЕНЬ_ПОКРЫТИЯ_РАЗНЫЙ_МАСШТАБ](../датчики/СТЕПЕНЬ_ПОКРЫТИЯ_РАЗНЫЙ_МАСШТАБ.md).

**Обозначения.** T — маршрутов, L — участков в маршруте, k — нужная кратность; S = Sм ∪ Sп — расставленные средства:
Sм — малые, Sп — площадные (флажок «площадное» в настройке типа, ОГРАНИЧЕНИЯ 9.23); nₜ(S) — сколько средств засекают
маршрут t; Uₜ(X) — участки маршрута t, которые видит хоть одно средство набора X.

```
K(S) = (1/T) · Σₜ min(nₜ(S), k) / k                  кратность — засечки общие для всех типов
C(X) = (1/T) · Σₜ |Uₜ(X)| / L                         степень покрытия набором X
ΔC(X) = C(X ∪ {s}) − C(X)                             сколько новых участков даёт место s для набора X
```

C(S) — задача «**засечь вообще**» (участок видит любое средство); C(Sм) — «**наблюдать малыми**»; C(Sп) —
«наблюдать площадными». Второй ключ «доля пути» — так же, с долей пути вместо участков.

```
E — было:          F = a1·K(S) + a2·C(S)
F — свои слои:     F = a1·K(S) + a2·[ C(Sм) + C(Sп) ]                                              (10.2а)
H — выбрано:       F = a1·K(S) + a2·½·[ C(S) + C(Sм) ]                                             (10.2)
B — правило 17.10: прирост малого a1·ΔK + a2·ΔC(Sм), площадного a1·ΔK + a2·ΔC(S); одной F нет        (10.2б)
```

| Вариант | Прирост малого места s | Прирост площадного места s | Одна функция |
|---|---|---|---|
| E | a1·ΔK + a2·ΔC(S) | то же | да |
| F | a1·ΔK + a2·ΔC(Sм) | a1·ΔK + a2·ΔC(Sп) | да |
| **H** | a1·ΔK + a2·½·[ΔC(S) + ΔC(Sм)] | a1·ΔK + a2·½·ΔC(S) | **да** |
| B | a1·ΔK + a2·ΔC(Sм) | a1·ΔK + a2·ΔC(S) | нет |

**Свойства.**
* K и каждое C — функции покрытия: монотонны и субмодулярны (убывающая отдача); сумма с неотрицательными весами — тоже.
  Поэтому у E, F и H — гарантия жадного (≥ ½ при квотах по типам, ≥ 1 − 1/e при одной квоте; строго — без разноса,
  разнос не матроид) и граница Минью после прохода — и по типу, и в целом.
* У B приросты малого и площадного — разности **разных** функций: общей F нет. Пример: пост и МОГ видят одни и те же
  2 участка; «МОГ, затем пост» — 2 + 0 = 2, «пост, затем МОГ» — 2 + 2 = 4: одна пара мест «стоит» по-разному — доли
  «от лучшего» нет. Граница по типу остаётся, «в целом» — не считается.
* Флажок «площадное» снят у всех: Sп = ∅, Sм = S — H даёт ½·[C(S) + C(S)] = C(S), F — C(S) + 0: оба равны E до бита.
* Граница Минью (8.1) берёт приросты всех кандидатов, и закрытых разносом, — верна при любом правиле разноса.

**Разбор варианта F — почему не он.** F — сумма двух слоёв, которые друг друга не видят.

*Пример — пост после малых.* Маршрут A (10 участков) уже накрыт пятью МОГ, маршрут B — никем. Место P1 — пост над A,
P2 — над B. Прирост в участках, без деления на T·L и без a2:

| | P1 — поверх малых | P2 — где малых нет |
|---|---|---|
| F: ΔC(Sп) | 10 — в слое площадных A не накрыт | 10 — ничья: пост может встать поверх малых |
| H: ½·[ΔC(S) + ΔC(Sм)] | ½·(0 + 0) = 0 | ½·(10 + 0) = **5** — пост идёт туда, где пусто |

Замер М4б–М4г (план 16 §2.1а, три зерна): у F покрытая доля **0.528 · 0.522 · 0.470** — в зерне 1002 пост встал поверх
малых; у H — **0.530 · 0.523 · 0.531**, при общем покрытии E — 0.532 · 0.527 · 0.532.

**Почему H.** *Пример — МОГ у поста.* Пост видит все 10 участков маршрута; место M1 (у поста) видит его участки 4–5,
место M2 (вне поста) — 2 участка другого маршрута, их не видит никто:

| | M1 — в зоне поста | M2 — вне поста |
|---|---|---|
| F: ΔC(Sм) | 2 | 2 — МОГу всё равно, есть ли пост |
| H: ½·[ΔC(S) + ΔC(Sм)] | ½·(0 + 2) = 1 | ½·(2 + 2) = **2** — сначала туда, где не видит никто |

* МОГ встают в зоне постов, как по правилу заказчика: 7 · 8 · 8 из 10 у H, F и B; при E — 0 · 1 · 1.
* Пост видит покрытое малыми и не встаёт поверх без нужды — провала F нет.
* Одна функция — гарантия и строка «в целом: не хуже Y % от лучшего» в «Анализе» (план 16.01, В16.01.3).
* Пост поверх малых — не запрет: встанет, если там не набрана кратность (a1·ΔK), если малые накрыли место частично или
  пустых мест не осталось.
* **½ — равный вес двух задач** (решение заказчика, как a1 и a2), а не вероятность и не подбор.

**Форма с долей q — задел** ([план 101 §9](../история/планы/101_ПЛАН_ЗАДЕЛ.md), 101.10):

```
F_q = a1·K + a2 · [ (1 − q)·C(Sм) + q·C(S) ]                                                         (10.3)
```

Это ожидаемое покрытие, если площадное средство видит БПЛА с вероятностью q: 1 − (1 − [малое])·(1 − q·[пост]) =
(1 − q)·[малое] + q·[малое или пост]. При q = ½ совпадает с H до знака, но смысл другой: q — свойство средства, его
нельзя подбирать (q = 0.5 взято перебором на одной выборке); вернётся, когда в паспорте появится вероятность
обнаружения, — тогда (10.3), а в общем виде — вероятностное покрытие с p каждого типа
([план 100 §3.1](../история/планы/100_ПЛАН_ПОКАЗАТЕЛИ_И_ОПТИМИЗАЦИЯ.md), (П.2)).

**Правило словами заказчика** (17.10, вечер) — история решения: места между типами — с учётом двух радиусов, а если один
больше другого в 4 раза — не ближе суммы двух малых; всё, что подпадает под правило, в критерии «новые участки» не
учитывать. Это B (10.2б): числа хорошие (М4д: МОГ в зоне постов 7–8 из 10, покрытая доля 0.528 · 0.522 · 0.525), но
одной функции нет. 18.10 заказчик выбрал H — то же поведение малых с гарантией.

### 10.3 Видимость БПЛА с места (16.2, «Реальная видимость»)

Вдоль луча азимута α с шагом Δd (15 м у МОГ и ПВН, 50–100 м у площадных) отсчёт i на дальности dᵢ:

```
βᵢ = ( zᵢ + h − δᵢ − z₀ − hₛ ) / dᵢ,     αⱼ = ( zⱼ + Hⱼ − δⱼ − z₀ − hₛ ) / dⱼ,     δ = d² / (2·k·R_З)     (10.4)

БПЛА в отсчёте i виден  ⟺  βᵢ > max_{j<i} αⱼ   и   dᵢ ≤ R                                             (10.5)
```

где:
* z – земля (FABDEM; пока его нет — `arh_hh`), м; z₀ — под датчиком: земля, а у датчика на крыше — верх здания;
* H – высота предмета над землёй: кроны или постройка (план 16.5), м;
* h – высота БПЛА над землёй — одна, из ТТХ типа (`alt_m`), м; hₛ – высота установки датчика над землёй или крышей, м — поле типа,
  **по умолчанию 0** (заказчик 17.10, вечер; антенны РЭБ — задел);
* δ – понижение за кривизну Земли; k = 4/3 у радио, 1 у оптики; R_З = 6 371 км.

**Пример:** δ на 1 / 2 / 5 / 10 / 15 / 25 км — 0.06 / 0.24 / 1.5 / 5.9 / 13 / 37 м: у МОГ и ПВН (до 2–5 км) — меньше
1.5 м, у поста 25 км — треть высоты БПЛА 100 м.

```
радиогоризонт  D = 4.12 · ( √hₛ + √h )  км  (высоты — в метрах)                                    (10.6)
```

**Пример:** мачта 10 м, БПЛА 100 м → 4.12·(3.16 + 10) = **54 км**; глаз на земле (hₛ = 0): БПЛА 100 / 50 / 30 м →
41 / 29 / 23 км — круг 25 км горизонт режет только у БПЛА ниже 37 м.

**Частный случай** — ровная земля и одна стена леса высотой H на расстоянии D (опушка):

```
R_эфф(α) = min( R,  D · (h − hₛ) / (H − hₛ) )                                                       (10.7)
```

**Пример:** D = 100 м, H = 20, hₛ = 3, h = 100 → 100·97/17 = **570 м**; при hₛ = 0 — 100·100/20 = **500 м**.
**Пример — дом рядом с МОГ:** трёхэтажный дом H = 10 м в D = 30 м, hₛ = 0, h = 100 м → в секторе, который закрывает дом,
R_эфф = 30·100/10 = **300 м**; дом длиной 40 м закрывает 67° — 19 % круга.

**Фактический радиус, видимая доля круга и «прикрытие»:**

```
r(α) = d начала первой тени на луче α (тени нет — R);   r_вид(α) = r(α) + длина островов за тенью на луче α
R_факт = (1/72) · Σ_α r_вид(α)  (галка «Острова видимости» снята — r_вид = r);   прикрытие = Σ_s 2·R_факт,s
f = (1/72) · Σ_α Σᵢ wᵢ · [виден αᵢ до первой тени],   wᵢ = dᵢ / Σ dᵢ                                   (10.8)
```

**Пример (М13):** МОГ у опушки, глаз 0 м — R_факт 0.40 км, f = 0.155; пост 15 км, антенна 25 м — R_факт 12.94 км,
f = 0.79. Тень — отсчёты луча, где БПЛА ниже луча зрения через вершину препятствия; остров — видимые отсчёты за тенью: в
засечку и показ не входят (у мест МОГ — 0 %, у поста — 1.8 % круга).

### 10.4 Маршруты сектора без ломаных (16.6)

Кадр — азимутальная равнопромежуточная проекция от точки старта (φ₁, λ₁):

```
c = arccos( sin φ₁ sin φ + cos φ₁ cos φ cos(λ − λ₁) ),
θ = atan2( sin(λ − λ₁) cos φ,  cos φ₁ sin φ − sin φ₁ cos φ cos(λ − λ₁) ),
x = R_З · c · sin θ,   y = R_З · c · cos θ                                                          (10.9)
```

Блуждание «только вперёд» по полю стоимости D до входа:

```
σ(v) = exp( β · (D(тек) − D(v)) / ℓ ) · hold^поворот,    β = 8,   hold = 0.3,   поворот — в шагах по 45°      (10.10)
```

**«Нить»** — от вершины i к самой дальней вершине пути j, для которой:

```
прямая i → j проходима   и   цена(i → j) ≤ (1 + tol) · (C_j − C_i),    tol = 0.05                   (10.11)
```

где C – накопленная цена пути по ячейкам; цена прямой = среднее μ вдоль неё × длина.

**Дуга** на повороте Δ (прямая — дуга — прямая); радиус — по ТТХ (заказчик 17.10, вечер: «не подгонкой»):

```
t = min( r_у · tg(Δ/2),  место ),     r = t / tg(Δ/2),     длина дуги = r · Δ                         (10.12)
r_у = max( R_min, ρ_зоны ),     R_min = V² / ( g · tg φ )                                            (10.12а)
```

где:
* место – половина соседнего звена (у крайних — целое звено);
* V – скорость типа БПЛА, м/с; φ – наибольший крен (`threat_bank_deg` = 25°); g = 9.81 м/с²;
* ρ_зоны – у поворота, огибающего зону облёта: расстояние от вершины до центра зоны вдоль биссектрисы × cos(Δ/2) —
  дуга идёт вдоль края зоны; не у зоны — 0.

Вершины, между которыми не помещается t = R_min·tg(Δ/2), сливаются. Прежнее R_т = 20 км (М8б) — подобрано, заменено.
**Пример:** «Лютый» 180 км/ч = 50 м/с: R_min = 2 500 / (9.81·0.466) = **547 м**; Δ = 30° → t = 0.547·0.268 = 0.15 км.
**Замер М8в:** по 10 маршрутов к 4 входам — наименьший радиус 0.55 км, поворотов 5–13° на 100 км; к северному входу
(с тыла, запас 15 км) — 1 490 км.

**Полосы и запас облёта** (М8г, заказчик 17.10, поздний вечер: «выборка по сектору слева направо», «запас — 15 %
площади района»):

```
u_k(t) = u_оси(t) + s_k · w_±(t) · min(1, (1 − t)/0.25),   t = 0.1, 0.2, …, 0.9                  (10.12б)
P · m + π · m² = 0.15 · A   →   m = ( −P + √(P² + 0.6·π·A) ) / (2π)                                (10.12в)
```

где u_оси(t) — ось «старт → точка перед входом» на доле пути t; s_k ∈ (−1, 1) — полоса k (по одной на десятую часть
ширины, слева направо); w_± — полуширина сектора от оси по стороне полосы; A, P — площадь и периметр района, m — ширина
полосы запаса. **Пример:** `arh` — A = 8 568 км², P = 380 км → m = 3.29 км; 10 из 10 разных линий, размах в середине
пути 174–182 км, поворотов 34–44° на 100 км.

### 10.5 Подлёт к точке района (16.7)

```
Lᵢ(P) = L_внеш,i + dᵢ(P),     t = L / V,     остаток = L_max − L                                       (10.13)
```

где L_внеш,i – путь i-го маршрута сектора до его точки входа; dᵢ(P) – поле от входа по сетке района (цена маршрутов
района). В точке — среднее, наименьшее и наибольшее по 10 маршрутам.

## 11. Допущения и ограничения

1. **Плоский кадр** в км от якоря участка. На районе в десятки км ошибка мала. Для сектора от далёкого старта нужна
   азимутальная проекция (10.9): кадр программы от Сум ошибается на 15–23 км.
2. **Маршрут — по ячейкам** 8-связной сетки: направления через 45°. Плавность — от ограничений шага и сглаживания
   рисуемой линии, а не от кинематики (§5.3).
3. **Веса слоёв — гипотеза**, не калибровка по статистике пролётов.
4. **Засечка мгновенная и надёжная**: точка маршрута в круге R — засечён (P = 1). Без рельефа и леса — до 16.2. Вероятность обнаружения p < 1 — план 100 §3.1.
5. **Выборка конечна**: F считается по T маршрутам (метод выборочного среднего); при T = 150 разброс между зёрнами —
   доли процента у доли покрытия (план 16, М4д).
6. **Рельеф — поверхность Copernicus**: лес и дома в нём занижены. Для весов это допустимо; для видимости нужны
   земля и высоты предметов отдельно (план 16.5).
7. **Огибание рельефа** — высота полёта постоянна над поверхностью; в веса не входит (РАДИОВИДИМОСТЬ_ЗАДЕЛ §5).
8. **Засечка — до первой тени** (план 16, 16.2): острова видимости за тенью не учитываются — у мест МОГ 0 %, у поста
   15 км 1.8 % круга (М13).
9. **Высота БПЛА одна на тип** (из ТТХ), над землёй; глаз — земля или крыша, hₛ = 0.
10. **Высота этажа одна на участок** — средняя по постройкам с высотой и этажами; нет пар — 3 м (план 16.5, М12б).
