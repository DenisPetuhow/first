# Учебное пособие — указатель папки

> **Что это.** Четыре документа, объясняющие задачу с нуля: от понятия
> оптимизационной задачи до полного разбора обеих постановок программы. Написаны
> **дважды на каждом шаге**: сначала строгая формулировка (годная для статьи), затем
> то же самое обиходным языком, плюс числовой пример.
>
> **Чем отличается от рабочих методичек.** Методички в
> [теория/](../README.md) отвечают на вопрос «как это устроено **сейчас** в коде» и
> переписываются вслед за правками. Пособие отвечает на вопрос «**почему** так и что
> это вообще значит» — оно объясняет, а не документирует.

---

## С чего начинать

| Кто читает | Порядок |
|---|---|
| впервые видит задачу | 1 → 2 → 3 → 4 |

| пишет статью | 3 и 4 — там постановки целиком; 1 — обоснование метода |
| не понимает формулу из рабочей методички | 2 — словарь символов |

## Рисунки

Все — в [рис/](рис), формат SVG. **Руками не рисовались:** каждый считается по той же
формуле, что записана в тексте, поэтому картинка не может разойтись с формулой.

```bash
python tools/переносимое/make_figures.py            # пересобрать все рисунки
python tools/переносимое/make_figures.py --list     # какие есть и что показывают
```
