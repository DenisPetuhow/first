## 1. Типы датчиков

| Тип | Радиус | Кратность | Где ставится | Статус |
|---|---|---|---|---|
| **МОГ** | 1 км | 3 | везде, кроме воды, в зоне пролёта | 📋 справочник типов — 13.1 (сейчас — поля «тип 1–3») |
| **ПВН** | 0.5 км | 4 | только **карта ПВН** (§6) + **доля у объектов защиты** (§8) | 📋 13.1, 13.4, 13.17, 13.18 |
| **большие** | 15 км | — | кольцо у объекта защиты, «не двигаются» | ✅ кольцо; 📋 в справочник — 13.9 |

Число датчиков — **задание в окне**, радиус и кратность — **свойство типа** (В13.2 ✅).

## 2. Интерфейс — что настраивается

**Окно «Датчики»** (кнопка в «Исходных данных», 📋 13.2):

* выбор типа из списка, «добавить тип», «удалить тип»;
* **мини-таблица типов: тип · цвет · количество N · кратность k** — правится в ячейках;
* галка **«общая кратность»** с полем k рядом; снята — у каждого типа своя k из таблицы;
* галка **«распределённое размещение»** — разнос между типами (§5);
* ниже — прежняя таблица датчиков (номер, тип, координаты, статический / динамический).

**Окно «Тип датчика»** (справочник, 📋 13.3): название · радиус · кратность · режим по
умолчанию (статический / динамический) · палитра · правило места · галка **«показать
разрешённую карту»** (маска и точки-кандидаты на карте).

**Только у ПВН — три поля долей на объектах защиты** (решение 23.09.2026, 📋 13.3 + 13.18):

| Поле | Умолчание |
|---|---|
| доля ПВН на объекты защиты | **70 %** |
| при одной цели — не более | **50 %** |
| кратность цели | **1** |

## 3. Кратность

| Правило | Статус |
|---|---|
| галка «общая кратность» **стоит** — одна k, засечки считают **все типы вместе** | ✅ |
| галка **снята** — у типа своя k, набирает он её **только своими** датчиками | ✅ 23.09.2026 (В13.13) |
| отчёт при своей k: «засечено **своей кратностью типа**» = хоть один тип набрал свою k | ✅ |
| большие датчики в засечку малых **не входят** | ✅ |

Замер: своя засечка второго по очереди типа ПВН **0.4 → 11.6 %** после правки
([ОГРАНИЧЕНИЯ 1.10а](ОГРАНИЧЕНИЯ.md)).

## 4. Сетка кандидатов

| Правило | Статус |
|---|---|
| у каждого типа **своя сетка, шаг R/2** (ПВН — 0.25 км) | 📋 13.5 (сейчас одна на всех) |
| узлы — **только внутри разрешённой карты типа** (быстро: ПВН 1 395 мест вместо 140 744) | 📋 13.5 |
| в ячейке с постройками ПВН встаёт **на самую высокую постройку** (§7) | 📋 13.17 |

## 5. Разнос

| Правило | Значение | Статус |
|---|---|---|
| внутри типа | 1.6·R, при нехватке мест ослабляется до 0.75·R | ✅ |
| между типами (галка «распределённое размещение») | **0.8·(R₁ + R₂)** — **не менять** (решение 23.09.2026) | ✅ |

⚠️ При своей кратности **порядок типов решает только разнос**: без разноса все порядки дают
одно и то же. Цена разноса и порядков — план 13 §0.4б, §0.4г.

## 6. Где можно ставить

**Для всех типов** (✅): не на воде · внутри рамки района (круга) · в зоне пролёта.

**Карта ПВН** (решение 23.09.2026, 📋 13.4) — строится **один раз** при сборке карты:

```
карта_ПВН = (застройка ∪ ячейки с постройками ± 0.5 км)
          ∩ ¬(лес, кроме полосы 0.5 км у дорог и построек)
          ∩ ¬вода ∩ проходимость
```

| Правило | Почему |
|---|---|
| застройка = жилые и промышленные зоны (`landuse`) + **постройки** | у цели Мирный `landuse` 9 ячеек, с постройками 34 |
| у дорог и ЖД — **только где есть постройки**, желательно 2–3 этажа | дорога в лесу без построек — не место для ПВН |
| **лес запрещён**, кроме полосы 0.5 км у дорог и построек | лес — 35.3 % района; запрет почти бесплатен |
| внутри **большого города** ставить бесполезно | маршруты его обходят: из 95.8 км² застройки проходимы 74.2 |

Замер: карта 473.2 км², засечка ПВН ≥ 4 своими **39.6 %** (вся карта без запретов — 56.4 %).

## 7. Постройки (📋 13.17)

* новый слой `building=*`: на ячейку — **число построек** и **самая высокая**; в вес карты
  **не идёт** — только карта ПВН и показ;
* «самая высокая» (В13.19 ✅ решено): **этажность → тип здания → площадь пятна**
  (`apartments`, `dormitory`, `school`, `commercial`, `industrial` — выше; `house`,
  `detached`, `garage` — одноэтажные);
* **бонус высоте** при выборе места — чтобы ПВН чаще вставал на 2–3 этажа (📋 13.7);
* ⚠️ этажность в OSM есть лишь у **6 %** построек (726 из 12 011) — без запасного признака
  «самую высокую» не выбрать.

## 8. Объекты защиты и доля ПВН (📋 13.18)

| Правило | Статус |
|---|---|
| до **пяти** целей, окно «Объекты защиты», приоритеты (поровну, сумма ≤ 1) | ✅ |
| цель маршрута разыгрывается **без повторов подряд** | ✅ |
| кольцо больших — у **приоритетной** цели; приоритеты равны — большие ставит человек | ✅ |
| **кратность цели 1** — только для ПВН, отдельно от кратности типа | 📋 |
| **70 % ПВН** на цели, делятся **по приоритету**; одна цель — **не более 50 %** | 📋 |
| у цели ставится **вся её доля** (В13.18 ✅ «Б»), а не «до кратности» | 📋 |
| доли — **в настройке типа**, пока **только у ПВН** | 📋 |
| **зона цели — по объекту, а не «6 км»** (замечание 23.09.2026): связный массив застройки и построек, где стоит цель (разрывы до R = 0.5 км — тот же массив: город с пригородом, посёлок с дачами), ± R, ∩ карта ПВН | 📋 |
| **подлёт** — точки маршрутов к этой цели **внутри её зоны** (вместо «последних 5 км») | 📋 |
| маленький объект не вмещает долю — **доля ограничивается вместимостью зоны**, остаток — в общий проход | ❓ В13.20 (умолчание) |
| цель в лесу (массива построек нет) — **зону задаёт человек**; пока не задана — ближайший массив | ❓ В13.21 (умолчание) |

Замер (три цели 0.5 / 0.3 / 0.2 → ПВН 7 / 4 / 3 из 20): подлёт к целям прикрыт
34 / 72 / 73 % → **98 / 93 / 96 %**, общая засечка ПВН 16.8 → 11.2 %.

## 9. Порядок проходов (📋 13.18 + 13.6)

```
1. ЦЕЛИ — по убыванию приоритета, у каждой свой маленький жадный:
   места — зона цели (массив её застройки и построек ± R ∩ карта ПВН);
   критерий — подлёт (точки маршрутов к ней внутри зоны) с кратностью цели 1;
   число — её доля, но не больше вместимости зоны
2. ОБЩИЙ — один жадный по всем типам, у каждого своя k и своя карта;
   ПВН целей уже стоят, их засечки СЧИТАЮТСЯ в кратности ПВН
```

* ПВН целей **считать** в кратности ПВН: иначе общий проход ставит ПВН рядом с ними
  (засечка 11.2 → 8.4 %);
* в общем проходе «через один» и «по приросту» дают то же, что «МОГ, потом ПВН»;
  **«ПВН первым» хуже** для МОГ (32.0 → 26.4 %).

## 10. Замеры

* все замеры по датчикам — **без больших** (`threat_N_big` = 0, решение 23.09.2026);
  исключение — контрольный прогон `reference_run`: его эталон снят с тремя большими;
* одна выборка на сравнение (зерно закреплено), условия — рядом с числом.

## 11. Оптимальность — что ломает гарантию (1 − 1/e)

| Что | Гарантия |
|---|---|
| запрет места (карта ПВН) | **не ломает** — уменьшает саму задачу (потолок 56.4 → 39.6 %) |
| бонус высоте, приоритет крупным городам — **бонусом** | не ломает |
| попарный разнос | ломает (лечится разносом ячейками — план 7, З2) |
| типы по очереди | ломает; общий проход с квотами — граница 1/2 (13.6) |
| этап целей перед общим | у каждого прохода своя гарантия, **у решения целиком — нет**; цена видна числом |
| большие датчики вне жадного | вне гарантии вовсе |
