| | ОГРАНИЧЕНИЯ | методички |

| отвечает на вопрос | **какое правило действует и с каким числом** | **как механизм устроен и почему** |

планы и код; перенумеровать — значит увести все прежние ссылки не туда **молча**, без
единой битой ссылки.
