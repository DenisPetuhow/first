# Стартовый комплект — шаблоны нового проекта

> **Правился:** 06.10.2026 — заведён при разборе переносимых правил под новый проект (журнал 367).

Всё, что наработано о ведении проекта с помощником, — в виде **файлов, готовых к работе**: `CLAUDE.md` со всеми
правилами, `РАБОТА.md`, журнал, структура и навигация, папка разборов кода, правила и эталон, каркас кода `src/`,
запускатель проверок, настройки `.claude` (хук, разрешения, два режима и команды их переключения), заметки памяти.
Шаблоны — файлы `*.tmpl`: проверки этого проекта их не трогают.

## Как развернуть

```bash
python tools/переносимое/new_project.py "C:/Projects/Новый" --name "Новый" --about "Что делает программа" --dry
python tools/переносимое/new_project.py "C:/Projects/Новый" --name "Новый" --about "Что делает программа"
```

Скрипт копирует правила (`теория/переносимое/`), проверки (`tools/переносимое/`), стиль оформления и разворачивает
шаблоны с подстановкой `{{ПРОЕКТ}}`, `{{ДАТА}}`, `{{ОПИСАНИЕ}}`. Существующие файлы не перезаписывает. `--memory <папка>` —
скопировать заметки памяти (папка памяти Claude Code появляется после первой сессии в новом проекте). Режим по
умолчанию — «с подтверждением». Дальше — [4_ПЛАН_ВНЕДРЕНИЯ](../4_ПЛАН_ВНЕДРЕНИЯ.md).

## Что внутри

| Шаблон | Что получится |
|---|---|
| `CLAUDE.md.tmpl` | правила: режимы, экономия токенов, «где мы», первое действие после `/clear`, документирование, каталог работы, проверки 0–10, навигация, соглашения, git |
| `теория/РАБОТА.md.tmpl` | каталог работы: «где мы», последние изменения, ждёт заказчика, дальше, ловушки, блоки задач |
| `теория/журнал/*.tmpl` | журнал (пункт 1 — заведение проекта) и его указатель |
| `теория/структура/*.tmpl` | навигация, структура теории, структура проекта |
| `теория/код/01.README.md.tmpl` | папка разборов кода с форматом эталона |
| `теория/правила/*.tmpl`, `теория/планы/README.md.tmpl` | правила и эталон контрольного прогона; указатель планов |
| `src/*.tmpl`, `main.py.tmpl` | каркас кода: параметры, корень данных, точка входа с `src/` в пути |
| `tools/check_all.py.tmpl` | все проверки одной таблицей (проверки программы — дописывать) |
| `.claude/*.tmpl` | хук без `cd`, точные разрешения, режимы «без остановок» и «с подтверждением», команды переключения |
| `.gitignore.tmpl` | кэши, локальные настройки, сборка |
| `память/*.tmpl` | заметки памяти о привычках работы: команды без приставок, дата по часам, комментарии, токены, режимы, самопроверка, эталон разбора |
