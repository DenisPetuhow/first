# 14 · Экономия токенов: куда уходит лимит и что с этим делать

> **Правился:** 06.10.2026 — заведено при разборе переносимых правил под новый проект (журнал 367); замеры — журнал 361.

> **Переносимый документ.** Почему лимит помощника кончается быстрее, чем кажется, и какие привычки его берегут.

## 1. Суть

**Почти весь расход — перечитывание контекста.** Каждый вызов инструмента заново подаёт модели всю историю сессии; вывод
самой модели — доли процента. Длинная сессия дорожает квадратично: сотый вызов стоит в разы больше первого. Фоновые
прогоны токенов не тратят; удаляют из контекста только `/clear` и `/compact`.

**Замер** (сессия проекта-источника, 351 запрос): первый запрос после `/clear` — 67 тыс. токенов, средний — 506 тыс.,
всего 177,8 млн при выводе 0,5 млн — **99,7 %** лимита ушло на перечитывание.

## 2. Правила

| Правило | Почему |
|---|---|
| закрыл задачу (журнал записан) — сказать «удобный момент для `/clear`»; внутри длинной задачи — `/compact` | новая задача начинается с 67 тыс., а не с 500 тыс. |
| `CLAUDE.md` — **без хроники и пояснений**: правила и «где мы»; история — в журнале, состояние — в `РАБОТА.md` | файл читается при КАЖДОМ запросе: 40 тыс. знаков → 19 тыс. экономят на каждом вызове |
| правки документов по задаче — **одним скриптом**, а не десятком `Edit` | каждый `Edit` — вызов с перечитыванием всей истории |
| текст с обратными кавычками — только файлом-скриптом | в строке командной оболочки они исполняются как команды, текст портится молча |
| файлы целиком не читать: поиск → чтение с отступом и пределом | 80 строк вместо 1 800 |
| вывод проверок — **одной таблицей** (единый запускатель, полный вывод — в файлы) | десяток выводов целиком съедает контекст |
| длинные прогоны — в фоне | ожидание не стоит токенов, вывод читается выборочно |
| путь проекта — копировать из вывода, не набирать | опечатки в длинных путях — повторные вызовы |

⚠️ **Не пересжимать.** Первый вариант сжатия резал и правила вместе с историей («слишком убавил» — заказчик); вернуть
пришлось. Режется **история и пояснения-разборы**, правила остаются все; полная прежняя редакция — в архив.

## 3. Пример

`CLAUDE.md` 40,6 → 18,9 тыс. знаков, `РАБОТА.md` 26,4 → 17,2 тыс., шапка указателя журнала 57,4 → 48,4 тыс. — при тех же
правилах. При 300 вызовах за сессию экономия ≈ 21,7 тыс. знаков × 300 ≈ 6,5 млн знаков ≈ 1,6 млн токенов (оценка по
формуле, ≈ 4 знака на токен).

| Где легко сломать | Почему |
|---|---|
| дописывать в `CLAUDE.md` «почему так вышло» | файл снова пухнет, а читается при каждом запросе |
| не делать `/clear` между задачами | новая задача несёт за собой старую историю |
| проверять «главные» скрипты по одному с полным выводом | контекст растёт, а пропущенная проверка ловит своё неделю спустя |
