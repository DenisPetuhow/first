## Правила для этой папки

1. **Один замер — один файл**, имя `ЗАМЕР_ДД.ММ.ГГГГ_ТЕМА.md`. Дописывать старый замер новыми
   числами нельзя: замер — это снимок на дату и на том коде.
2. **В начале файла — сценарий целиком**: участок, район, цель, сектор, запас хода, сколько
   маршрутов, зерно, чем считалось. Без этого числа невоспроизводимы.
3. ⚠️ **Сравнивать значения только ВНУТРИ одного прогона.** Выборка маршрутов у каждого прогона
   своя, если не закреплено зерно; между прогонами числа гуляют (замер 16.09.2026: средняя
   кратность 5.59 и 5.55 на двух прогонах подряд при одинаковых настройках).
4. **Вывод обязателен** — строкой «что это значит для работы», иначе таблица бесполезна.
5. Числа, на которые ссылаются методички и правила, **дублируются там кратко**, а подробности
   остаются здесь. Ссылка идёт сюда, а не наоборот.
