## Схема сборки

### Режим — папка, а не один файл

`--onedir`, не `--onefile`. Одиночный `.exe` при каждом запуске распаковывает себя во
временный каталог: старт долгий, а пути к `geo_cache` и `tile_cache` начинают вести
«внутрь» распакованного временного каталога, а не рядом с программой. Заказчику нужна
именно папка — она же и архивируется.

### Что исключаем из сборки

```
pyrosm, geopandas, rasterio, shapely, pyproj, fiona, pandas   — только для .osm.pbf
python-docx                                                    — только для docs/
tkinter, PyQt5.QtWebEngine, PyQt5.QtBluetooth, …               — не используются
```

### Что кладём рядом с `.exe`

| что | размер | зачем |
|---|---|---|
| `geo_cache/threat_layers.npz` | 8.4 МБ | весовая карта — **без неё программа бесполезна** |
| `geo_cache/dem.tif` | 8.5 МБ | рельеф (кнопка «Добавить рельеф») |
| `tile_cache/osm/` | ~100 МБ | подложка без интернета, зумы 7–15 |
| `ЧИТАТЬ.txt` | — | как запустить, что делать при предупреждении Windows |

**НЕ кладём:** `severodonetsk.osm.pbf` (23 МБ), `threat_layers_OLD.npz` (45 МБ),
`threat_layers_2026-08-06_before_place_codes.npz` (8.4 МБ) — нужны только для пересборки
карты, для показа бесполезны. Экономия ~76 МБ.

Ожидаемый размер папки: **450–580 МБ**, в архиве заметно меньше.

### Настройки для демонстрации

* `map_offline3 = True` — иначе на ПК без интернета программа будет ждать тайлы из сети;
* проверить, что пути к `geo_cache`/`tile_cache` ищутся **рядом с `.exe`**, а не в рабочей
  папке процесса: при запуске ярлыком рабочая папка может оказаться другой, и карта не
  найдётся.

## Чек-лист проверки (обязательно до показа)

**На машине сборки:**
- [ ] `.exe` запускается двойным щелчком, окно открывается;
- [ ] все три вкладки открываются без ошибок;
- [ ] вкладка 3: «Построить карту» отрабатывает, весовая карта видна;
- [ ] «Добавить рельеф» работает (значит `dem.tif` найден);
- [ ] подложка OSM видна **при выключенном интернете** (проверить, отключив сеть);
- [ ] «Расставить датчики» и «Пакетно» считают, показатели заполняются;
- [ ] в консоли нет ошибок про отсутствующие модули.

**На чужом ПК — этого не заменит ничто:**
- [ ] распаковать архив и запустить;
- [ ] пройти те же пункты.

Проверить всё отсюда нельзя: у меня нет «чистой» Windows без Python. Я могу проверить, что
сборка проходит, `.exe` стартует, данные находятся и программа не лезет в сеть. Поведение
на машине без Python и без Visual C++ runtime подтверждается только запуском на настоящем
чужом компьютере — этот шаг стоит сделать заранее, а не в день показа.

## Что сказать заказчику заранее

* Windows покажет **SmartScreen** на неподписанном `.exe` — «Подробнее → Выполнить в любом
  случае». Это нормально для самосборных программ, но на демонстрации выглядит неловко,
  если не знать заранее. Убирается только покупкой сертификата подписи.
* Антивирус может задержать первый запуск.
* Первый запуск дольше обычного (распаковка/прогрев).
* Кэш подложки покрывает **только рабочий участок**. Если отмотать карту в другую область
  страны, подложки там не будет — останется схема (сетка координат и ориентиры). Расчёт
  при этом работает: он весь локальный.
