## Как пользоваться

1. начинается пункт плана → завести блок: что делается, какие файлы кода;
2. по ходу правок **дописывать** затронутые файлы кода и документы — **в тот момент,
   когда файл открыт**, а не в конце. Это самое частое место, где всё ломается;
3. пункт закончен → пройти по списку документации сверху вниз, каждый отметить ✅;
4. спорное — вынести заказчику **одним** вопросом;
5. всё отмечено → одна строка в [журнал](журнал/README.md) со ссылками, блок отсюда
   **удалить**.

**Шаблон блока:**

```
## ДД.ММ.ГГГГ · план N, задача N.M — короткое имя
**Что делается:** одной фразой.
**Файлы кода:** путь :: функция :: строка
**Документация к обновлению:**
  - файл §раздел — что именно поправить   ⬜
**Проверки:** reference_run ⬜ · docmap --check ⬜ · что ещё ⬜
**Статус:** в работе / документация обновлена ✅
```
