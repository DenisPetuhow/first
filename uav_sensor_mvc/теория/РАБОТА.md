## Как пользоваться

1. начинается пункт плана → завести блок: что делается, какие файлы кода;
2. по ходу правок **дописывать** затронутые файлы кода и документы — **в тот момент,
   когда файл открыт**, а не в конце. Это самое частое место, где всё ломается;
3. пункт закончен → пройти по списку документации сверху вниз, каждый отметить ✅;
4. спорное — вынести заказчику **одним** вопросом;
5. всё отмечено → одна строка в [журнал](журнал/README.md) со ссылками, блок отсюда
   **удалить**.

**Шаблон блока:**

```
## ДД.ММ.ГГГГ · план N, задача N.M — короткое имя
**Что делается:** одной фразой.
**Файлы кода:** путь :: функция :: строка
**Документация к обновлению:**
  - файл §раздел — что именно поправить   ⬜
```

**Что делается.** Подложка перестаёт быть ОДНОЙ склеенной картинкой: каждый тайл кладётся
на сцену своим элементом. Решение заказчика 13.09.2026 — «сначала переделаем виджет для
плавности и чёткости тайлов и зума».

**Три выигрыша одной работой:**

| | сейчас | станет |
|---|---|---|
| плавность | мозаика пересобирается целиком, дебаунс 180 мс, мигание | тайлы доезжают поштучно |
| чёткость | мозаику растягивают — мутно (`TODO(map-blur)`) | тайл в родном разрешении |
| совмещение со слоями | **8.6 px** на виде «вся область» | **0.18 px** |

**Почему совмещение чинится само.** Нелинейность Меркатора копится по высоте того куска,
что натягивается линейно. Кусок = вся мозаика → 8.6 px; кусок = один тайл (на зуме 9 это
**35.6 км**) → **48.5 м, 0.18 px**.

**Новый модуль `view_qt/tile_layer.py`** (правило «крупный функционал — отдельный файл»):

* `TileLayer` — набор `QGraphicsPixmapItem` внутри `ViewBox`;
* `set_view(box_km, width_px)` — какие тайлы нужны; зовётся на `sigRangeChanged`;
* словарь `{(z,x,y): item}` + пул свободных элементов — ⚠️ **без переиспользования
  панорама затормозит**;
* номер поколения запросов — отбрасывать результаты, ставшие ненужными (приём есть:
  `_map_req`);
* прежний зум держится под новым, пока тот не доехал — это и есть плавность.

**Берётся готовым из `geomap.py`, заново НЕ пишется:** `deg2num`/`num2deg`,
`fetch_tile_bytes`, `_decoded_tile_u8`, кэш `_TILE_MEM`, раскладки XYZ/TMS,
