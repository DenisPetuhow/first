## Как пользоваться

1. начинается пункт плана → завести блок: что делается, какие файлы кода;
2. по ходу правок **дописывать** затронутые файлы кода и документы — **в тот момент,
   когда файл открыт**, а не в конце. Это самое частое место, где всё ломается;
3. пункт закончен → пройти по списку документации сверху вниз, каждый отметить ✅;
4. спорное — вынести заказчику **одним** вопросом;
5. всё отмечено → одна строка в [журнал](журнал/README.md) со ссылками, блок отсюда
   **удалить**.

**Шаблон блока:**

**Что делается:** одной фразой.
**Файлы кода:** путь :: функция :: строка

**Что делается.** Векторные слои съезжают относительно тайлов подложки. Свести их на
экране — **поправкой на ПОКАЗ**, не трогая расчёт.

**Суть в трёх строках.** Тайлы нарисованы в **Web Mercator** (стандарт OSM, поменять
нельзя). Всё остальное — реки, дороги, сетка 500 м, датчики, маршруты — считается в
**км-фрейме** от юго-западного угла области. Меркатор растягивает расстояния к северу в
`1/cos(широта)`, км-фрейм — нет; отсюда расхождение, и оно растёт с высотой района.

**Замеры сдвига (уже сняты, заново не надо):**

| Высота района | Сдвиг | Видно ли |
|---|---|---|
| 55 км (прежний участок) | 117 м | нет |
| 73 км (район расчёта) | ~200 м | в пределах ячейки |
| **250 км (область показа `arh`)** | **2.5 км** | **да, больше радиуса малого датчика** |
| 1035 км (область + поле) | 43 км | расходятся полностью |

**Файлы кода — точки правки:**

* `view_qt/geomap.py` :: `build_raster_basemap` :: **302** — сборка мозаики;
  `lonlat_to_km` :: **44** · `km_to_lonlat` :: **38** — пара перевода ПОКАЗА;
* `view_qt/basemap_mixin.py` :: `_refresh_basemap` :: **130** · `_on_basemap_ready` ::
  **159** — укладка мозаики на сцену; `_set_view_limits` :: **110**;
* ⚠️ `model/threat_grid.py` :: `lonlat_to_km` :: **89** — **НЕ ТРОГАТЬ**: это пара МОДЕЛИ.
  Как только правка дошла сюда — задача переросла в смену проекции, другая цена.

**Замысел решения (принят, но не проверен замером).** Мозаика кладётся на сцену одним
`setRect`, и внутри прямоугольника содержимое распределено по Меркатору — нелинейно.
Резать мозаику на **полосы по широте**, у каждой свой прямоугольник в километрах: внутри
узкой полосы нелинейность мала. Оценка по формуле — **8 полос на 250 км дают ~30 м вместо
2.5 км**. ⚠️ Это расчёт, а не замер: первым шагом задачи снять таблицу по 5–7 опорным
точкам (устья рек, перекрёстки).
