# Документация проекта — указатель

Документация разложена по папкам: **общее для всех вкладок — здесь, в корне**, остальное
по темам. У каждой папки свой `README.md`; у каждого документа длиннее 300 строк —
оглавление с номерами строк в начале файла.

> **Не читать файлы целиком.** Вся документация — ≈160 тыс. токенов. Порядок работы:
> этот указатель → `README` нужной папки → конкретный раздел документа.

## Структура папок

```
теория/
├── ОГРАНИЧЕНИЯ.md                  правила и пороги модели + эталон прогона (§6)
├── МЕТОДИЧКА.md                    математика вкладок 1–2
├── МЕТОДИЧКА_МОДЕЛИ_МАРШРУТОВ.md   модели движения всех вкладок, сводка формул
├── переносимое/                правила для ЛЮБОГО проекта: контекст и навигация,
│                               оглавления, сверка с кодом, план внедрения
├── СТРУКТУРА_ПРОЕКТА.md            карта кода: файлы, классы, кто за что отвечает
├── пособие/     УЧЕБНОЕ: теория оптимизации, язык записи, обзоры обеих постановок,
│                23 рисунка (считаются по формулам скриптом make_figures.py)
├── журнал/      что и когда меняли: указатель + живая часть 5 (ч. 1–4 в архиве)
├── вкладка_3/   карта угроз: механика весов, рельеф, история доработок
├── карты/       подложка, тайлы, проекция, где брать .osm.pbf
├── интерфейс/   настройка вида руками
├── сборка/      .exe: сборка, правки без пересборки, руководство пользователя
├── планы/       ЕДИНЫЙ действующий план (7); прежние 1–6 — в архиве
├── архив/       выполненные планы: хранятся ради отклонённых вариантов
├── основа/      исходники пособия (.doc/.docx): архив, частично устарели
└── Стиль оформления/  как ПИСАТЬ: регистр, шаблоны постановки задачи
```

**Пособие против методичек — разные вопросы.** Методичка отвечает «как устроено
**сейчас** в коде» и переписывается вслед за правками; пособие — «**почему** так и что
это значит», от правок кода не зависит. Правишь механизм — открывай методичку;
объясняешь или описываешь задачу — пособие.

**Почему так, а не по вкладкам.** Половина документов охватывает несколько вкладок сразу
(модели маршрутов — все три, ОГРАНИЧЕНИЯ — вообще всё). Раскладка строго «вкладка 1 /
вкладка 2 / вкладка 3» заставила бы дублировать файлы, поэтому общее лежит в корне, а
папки заведены по темам. Отдельная папка — от трёх файлов; на каждую один `README.md`.

## Как это поддерживается

| Что | Чем | Когда |
|---|---|---|
| оглавления с номерами строк | `python tools/переносимое/docmap.py` | после правки середины файла |
| имена и числа в текстах против кода | [`tools/переносимое/`](../tools/переносимое/README.md) | при сверке на достоверность |
| битые ссылки между документами | он же, режим `--check` | перед сдачей работы, в конце сверки |
| папка без `README.md`, файл длиннее 1 500 строк | он же | автоматически, в том же прогоне |

```bash
python tools/переносимое/docmap.py           # пересобрать оглавления + отчёт
python tools/переносимое/docmap.py --check   # ничего не менять, код 1 при проблеме
```

Правила ведения документации (журнал коротко, методичка подробно; пятишаговая сверка на
достоверность) — в [CLAUDE.md](../CLAUDE.md), помощник читает их автоматически.
