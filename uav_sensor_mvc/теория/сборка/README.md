# Сборка и поставка `.exe` — документы папки

Как превратить проект в программу, которая запускается на чужом компьютере: без Python,
без библиотек и без интернета. Здесь же — что можно поправить в уже собранной программе,
не пересобирая её, и что передать вместе с ней заказчику.

## Три правила, которые нарушать нельзя

1. **Собирать из ветки `exe-build`** — режим показа (одна вкладка, офлайн-подложка,
   справка в программе) живёт только там. Рабочая ветка остаётся полной, с тремя
   вкладками.
2. **Собирать из пути БЕЗ КИРИЛЛИЦЫ** (`C:\uav_build\src`). Qt отдаёт PyInstaller путь
   к своим плагинам в системной кодировке: `C:\Users\Денис` превращается в
   `C:\Users\?????`, и сборка падает.
3. **Каждая сборка — в СВОЮ папку** `dist\<имя>\`. PyInstaller **удаляет** каталог
   назначения перед сборкой: собрав в тот же путь, вы потеряете прежнюю программу.
   Подробно и с примером — [СБОРКА_EXE.md §0](СБОРКА_EXE.md).
