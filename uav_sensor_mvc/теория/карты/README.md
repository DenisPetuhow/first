# Карты и данные — документы папки

Подложка (тайлы OSM), гео-привязка, откуда брать `.osm.pbf` и как подключить свой кэш.

| Файл | О чём | Когда открывать |
|---|---|---|
| [МЕТОДИЧКА_КАРТА.md](МЕТОДИЧКА_КАРТА.md) | подсистема карты: тайлы, проекция, подбор зума, кэш, оффлайн-режим | подложка размыта, не тот масштаб, не грузится |
| [МЕТОДИЧКА_ЗАГРУЗКА_КАРТ.md](МЕТОДИЧКА_ЗАГРУЗКА_КАРТ.md) | где скачать данные под участок (bbox, Overpass, BBBike), как подключить | нужны новые данные местности |
| [МЕТОДИЧКА_КАРТА_ВОПРОСЫ.md](МЕТОДИЧКА_КАРТА_ВОПРОСЫ.md) | справочник по стороннему кэшу тайлов (например, SAS.Planet), онлайн-слои, стиль | вопрос по чужому кэшу или слою |

**Важно про кэш:** `tile_cache/`, `geo_cache/`, `offline_packages/` — локальные данные,
**в git не попадают**. После правки `PLACE_CODES` кэш `threat_layers.npz` надо пересобирать:
он хранит уже закодированный тип пункта (см. [ОГРАНИЧЕНИЯ.md](../ОГРАНИЧЕНИЯ.md) 3.10г).

История правок подложки — [указатель журнала](../журнал/README.md), пункты 24–37 и 47.
