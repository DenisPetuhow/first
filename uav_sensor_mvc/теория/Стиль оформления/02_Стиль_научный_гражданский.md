# ОБЩЕНАУЧНЫЙ СТИЛЬ ИЗЛОЖЕНИЯ (ГРАЖДАНСКИЕ ТЕМЫ)
## Правила и требования к тексту статей для публикации в российских рецензируемых изданиях (ВАК/РИНЦ), без военной терминологии

Базовый регистр — тот же российский научно-технический стиль, что и в файле 01 (разделы 1–3 и 5 файла 01 применяются полностью). Ниже — отличия и словарь.

---

## 1. ОТЛИЧИЯ ОТ ВОЕННО-НАУЧНОГО ВАРИАНТА

1.1. **Терминология.** Исключается военно-профессиональная лексика (см. словарь замен, раздел 3). Объект описывается в нейтральных категориях: «сложная техническая система», «система специального (промышленного, ответственного) назначения», «критическая информационная инфраструктура».

1.2. **Мотивация актуальности.** Вместо оперативно-боевых аргументов — экономические, технологические, нормативные: «рост объёмов данных», «требования импортозамещения», «требования нормативных документов (ФЗ, ГОСТ, приказы регуляторов)», «снижение затрат жизненного цикла», «повышение качества обслуживания потребителей».

1.3. **Структура допускает элементы IMRAD** (Введение – Материалы и методы – Результаты – Обсуждение), но для инженерных статей сохраняется отечественная схема: Введение → Постановка задачи → Основные разделы → Результаты/Пример → Заключение.

1.4. **Формальные атрибуты гражданских журналов:** УДК перед заголовком; аннотация 100–250 слов (по ГОСТ Р 7.0.99), при необходимости — англоязычные title/abstract/keywords; сведения о финансировании (грант); ORCID. Список литературы — по ГОСТ 7.0.100–2018 либо по требованиям конкретного журнала.

1.5. **Допустимая интернациональная лексика.** Устоявшиеся англоязычные термины ИТ-области допускаются с русской расшифровкой при первом употреблении: «машинное обучение (Machine Learning, ML)», «датасет (набор данных)» — предпочтителен русский эквивалент.

## 2. КОМПОЗИЦИОННЫЕ КЛИШЕ (гражданский вариант)

### Аннотация
«Рассмотрена задача … Предложен(а) … , отличающийся(аяся) от известных … Приведены результаты экспериментального исследования (численных расчётов), подтверждающие … Полученные результаты могут быть использованы при …»

### Введение
- «Развитие современных … предъявляет повышенные требования к …»
- «В течение последних … стали важным элементом …»
- «Анализ работ [1–5] показал, что известные подходы не позволяют …»
- «Целью работы является …» / «Данная работа посвящена …»
- «Новизна подхода заключается в комбинировании … с … и последующей …»

### Основная часть
Идентична файлу 01, раздел 3.3 («Рассмотрим…», «Введём…», «где … – …» и т. д.).

### Результаты
- «Эксперименты на датасете … показали высокие значения точности … (99,3%), при этом доля ложноположительных срабатываний составила менее 1%».
- «Полученные результаты подтверждают целесообразность использования … для повышения эффективности …».

### Заключение
- «Предложенный … позволяет … , что подтверждается …»
- «Результаты работы могут найти применение при проектировании (сопровождении, эксплуатации) …»
- «Дальнейшие исследования могут быть направлены на …»

## 3. СЛОВАРЬ ЗАМЕН ВОЕННОЙ ЛЕКСИКИ НА НЕЙТРАЛЬНУЮ

| Военный термин | Гражданский эквивалент |
|---|---|
| ВВТ, образец ВВТ | сложная техническая система; технический комплекс; изделие |
| система военного назначения | система специального (ответственного, промышленного) назначения |
| боевое применение; применение по назначению | целевое применение; эксплуатация по назначению |
| целевые задачи (боевые) | прикладные (целевые) задачи; функциональные задачи |
| группировка войск (сил) | совокупность (комплекс) технических средств; парк оборудования |
| противник; средства воздействия противника | нарушитель; источники деструктивных воздействий; неблагоприятные факторы |
| театр (район) военных действий | зона обслуживания; регион эксплуатации; проблемная область |
| боевая готовность | готовность к применению; работоспособное состояние |
| директивный срок | нормативный (установленный, регламентированный) срок |
| поражающие факторы | неблагоприятные (дестабилизирующие) факторы; внешние воздействия |
| живучесть (боевая) | отказоустойчивость; устойчивость функционирования |
| орган военного управления; пункт управления | орган управления; центр (пункт) управления; диспетчерский центр |
| личный состав | персонал; обслуживающий персонал; операторы |
| разведка (данных) | мониторинг; сбор данных; наблюдение |
| помехозащищённость (в военном контексте РЭБ) | помехоустойчивость; устойчивость к воздействию помех |
| государственный оборонный заказ | государственный контракт; договор на выполнение работ |

Правило: если термин имеет общетехническое хождение (отказоустойчивость, контрольная точка, устойчивость, нарушитель, критическая инфраструктура), он сохраняется без изменений — это общенаучная лексика.

## 4. ЗАПРЕТЫ

Полностью совпадают с разделом 4 файла 01 (разговорная лексика, публицистика, оценочные эпитеты, «я», риторика). Дополнительно для гражданских журналов: не допускать рекламных формулировок («уникальный», «не имеющий аналогов» без доказательств), избегать избыточных самоцитирований.
