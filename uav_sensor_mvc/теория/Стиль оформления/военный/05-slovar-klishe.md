## 1. Ввод и дефиниция объекта

- *X представляет собой … , обеспечивающую …*
- *X является … <класс> … уровня, предназначенным для …*
- *Базовое предназначение <объекта> — обеспечение …*
- *Система <X> (кодовое наименование … ) представляет собой …, реализуемую <кем>.*
- *X строится по принципу … интеграции.*
- *Ключевой принцип работы — …, что принципиально повышает … и сокращает …*

## 2. Ввод фактов (событийная база)

- *По сообщениям, в <месяц год> <субъект> подписал(а) … соглашение с …*
- *По условиям соглашения <сторона> передаёт … и право на …*
- *По состоянию на <дата> <группировка> насчитывает … единиц, что составляет …% от целевого состава.*
- *В <месяц год> заключён(о) … контракт / партнёрство с …, охватывающее …*
- *По результатам анализа открытых источников прямого подтверждения … нет, однако установленный факт … свидетельствует о …*

## 3. Маркировка достоверности

(полная таблица — в `03` §4; рабочие обороты)

- подтверждено: *установленный факт*; *согласно технической документации*;
- сообщение: *по сообщениям*; *по заявлению производителя*; *анонсировано*;
- косвенно: *подтверждена косвенно*; *создаёт технические предпосылки для …*;
- не подтверждено: *по состоянию на <дата> не подтверждены*; *прямого подтверждения нет*;
- не раскрыто: *в открытой документации не раскрыты*;
- оценка: *проведённый анализ позволяет … оценить*; *обоснованно оценить наличие*;
- прогноз: *прогнозируется*; *ожидается*; *в перспективе <годы> направлено на …*

## 4. Технический анализ и устройство

- *Основу <чего-л.> составляет / составляют …*
- *Для обеспечения … применяются / развёртываются …*
- *<Элемент> обеспечивает … со скоростью … при задержке …*
- *<Сегмент> базируется на … архитектуре с использованием …*
- *Проведённый анализ по ограничивающему критерию <критерий> позволяет сделать вывод о применимости … на конкретных классах носителей.*
- *Интеграция … потребует существенной доработки … , однако является технически реализуемой при наличии …*
- *Основные технические особенности <объекта>:* (зачин списка)

## 5. Оценка угрозы и значимости

- *Данный факт создаёт потенциальную угрозу для … , расположенных на большой глубине территории …*
- *Совокупность сведений о … , а также результаты анализа … позволяют обоснованно оценить наличие потенциальных возможностей для …*
- *Совокупность указанных факторов обусловливает принципиальную недостаточность применения какого-либо одного метода …*
- *Реализация … возможности позволит повысить устойчивость … при применении на больших дальностях.*

## 6. Меры и рекомендации

- *Организация эффективного противодействия … возможна за счёт выполнения следующего комплекса взаимодополняющих мер:* (зачин нумерованного списка)
- *<Мера>. <Раскрытие механизма>, что позволит <эффект>.*
- *Своевременное … в едином контуре управления обеспечивает сокращение времени реакции и накопление статистики …*
- *Применение … деградирует <характеристику> (переход от режима … к режиму …), что снижает устойчивость …*

## 7. Перспективы и прогноз

- *Определены следующие направления развития … на период <годы> гг.:* (зачин)
- *Интеграция алгоритмов типа … позволила бы перейти к … режиму: прогнозировать … и упреждающе …*
- *Совокупность изложенных факторов позволяет прогнозировать в ближайшей перспективе устойчивый рост внедрения …*
- *Распространение … обусловливает необходимость разработки принципиально новых методов …*

## 8. Сравнение и противопоставление

- *В отличие от <X>, Y …*
- *Наряду с этим / Дополнительно осуществляется …*
- *Принципиальным нововведением … является …*
- *…что радикально превосходит возможности …*
- *…что на порядок превосходит показатели традиционных … систем (… против …).*

## 9. Причина — следствие — цель

- *За счёт … достигается …*
- *…что обеспечивает / позволяет …*
- *С целью … прорабатывается …*
- *В результате … обеспечивается …*

## 10. Оценочные блоки (одной строкой, через «;»)

- *Преимущества <объекта>: …; …; … .*
- *Ограничения <объекта>: …; …; … .*

## 11. Ввод таблиц и рисунков

- *В таблице N приведены характеристики …*
- *Технические характеристики <объекта> по состоянию на <дата> приведены в таблице N.*
- *…приведён на рисунке N* / *(Рис. N)*

## 12. Замки разделов и обобщение

- *Таким образом, основными особенностями … являются: …*
- *Проведённый анализ позволяет выявить ряд устойчивых закономерностей …*
- *Основной тренд — переход от … к …*
- *В перспективе <годы> развитие направлено на …*
- *Совокупность данных программ формирует комплексную экосистему … , что создаёт качественно новые возможности для реализации концепции …*

## 13. Связочный аппарат

| Функция | Связки |
|---|---|
| Следствие | таким образом · в результате · тем самым |
| Добавление | наряду с этим · кроме того · дополнительно · параллельно |
| Контраст | в отличие от · однако |
| Цель | с целью · для обеспечения · в интересах |
| Причина / средство | за счёт · посредством · благодаря · на основе |
| Рамка | в рамках · в контексте · по состоянию на |

Правило: каждое логическое отношение между фразами маркируется связкой;
бессоюзные «прыжки» между мыслями недопустимы.

## 14. Глоссарий аббревиатур (вводить при первом употреблении)

**Общевоенные:** ВС (вооружённые силы), ВВТ (вооружение и военная техника),
АСУ (автоматизированная система управления), ТВД (театр военных действий),
ПВО/ПРО (противовоздушная / противоракетная оборона), РЭБ/РЭП
(радиоэлектронная борьба / подавление), РСЗО, САУ.

**Беспилотные и космос:** БПЛА / БЛА (беспилотный летательный аппарат), БЭК
(безэкипажный катер), КА (космический аппарат), ОГ (орбитальная группировка),
НОСГ (низкоорбитальная спутниковая группировка), ГСО/СОО/НОО (гео- / средняя /
низкая околоземная орбита), GNSS (Global Navigation Satellite System —
глобальная навигационная спутниковая система).

**Связь и антенны:** КСС (космическая система связи), SATCOM (Satellite
Communications — спутниковая связь), АФАР/ФАР (активная / фазированная антенная
решётка), ЭИИМ (эквивалентная изотропно-излучаемая мощность), MANET (Mobile
Ad-hoc Network — мобильная самоорганизующаяся сеть), ОМЛКС (оптические
межспутниковые лазерные каналы связи), SWaP (Size, Weight and Power —
габариты, масса и энергопотребление).

**Доктрина и ИИ:** CJADC2 (Combined Joint All-Domain Command and Control —
объединённое вседоменное командование и управление), ИИ/МО (искусственный
интеллект / машинное обучение), LSTM (Long Short-Term Memory), DRL (Deep
Reinforcement Learning).

Список пополняемый: при работе над новой темой добавляй встретившиеся
устойчивые аббревиатуры сюда, чтобы архив рос вместе с практикой.
