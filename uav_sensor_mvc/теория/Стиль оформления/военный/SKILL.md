# Военно-научный аналитический отчёт

> **Правился:** 06.10.2026 — папка положена заказчиком (скилл `voennyy-analiticheskiy-otchet`), отметка заведена.

Скилл готовит аналитические документы в военно-научном регистре: от краткой
справки-доклада об одном объекте до большого сравнительно-аналитического
обзора класса объектов. Применяй его при любой задаче этого профиля, а не
только когда стиль запрошен дословно.

## Критично — прежде всего

Военный доклад вводит читателя в заблуждение, если в нём искажены факты.
Поэтому **достоверность важнее объёма и красоты**. До написания —
прочитай `references/03-dostovernost-i-istochniki.md` и соблюдай его без
исключений:

- опирайся на реально существующие источники, приоритет — официальная
  документация и спецификации; СМИ и тем более мессенджеры — только при
  отсутствии иного и с явной пометкой;
- ключевые факты (ТТХ, состав, статус, даты, контракты) подтверждай
  перекрёстно по 2–3 источникам;
- **ничего не выдумывай**: если факт не найден или не подтверждён — так и
  пиши («не найдено», «не подтверждено», «в открытых источниках не
  раскрыто»), а не подставляй правдоподобное значение;
- разделяй факт, оценку и прогноз; маркируй степень достоверности прямо в
  тексте принятыми формулировками.

## Обязательная последовательность работы

1. **Определи тип документа.** Один объект (образец, система, программа) →
   жанр «справка-доклад», структура `references/01-struktura-spravka-doklad.md`.
   Несколько сопоставимых объектов под сравнение → жанр «сравнительный
   обзор», структура `references/02-struktura-sravnitelnyy-obzor.md`. Если
   неясно — уточни у пользователя одним вопросом.
2. **Исследуй углублённо.** Не ограничивайся одним источником. Сделай
   несколько запросов `web_search`, открой первоисточники через `web_fetch`,
   собери ТТХ, статусы, даты, связи. Фиксируй, что подтверждено, а что нет.
3. **Проверь достоверность.** Прогони материал по
   `references/03-dostovernost-i-istochniki.md`: перекрёстная сверка,
   привязка ко времени («по состоянию на <месяц год>»), маркировка статусов.
4. **Выбери и наполни структуру** — соответствующий файл `01` или `02`.
   Один аспект — один абзац; новый аспект — новый абзац с новым зачином.
   Для калибровки тона и структуры просмотри эталон соответствующего жанра
   в `references/primery/`: справка-доклад — `primer-01-resa-satcom.md` и
   `primer-02-amazon-leo.md`; сравнительный обзор класса —
   `primer-03-nosg-sravnitelnyy-obzor.md`. Достаточно одного примера — это
   образец стиля, а не источник актуальных данных.
5. **Примени регистр и лексику** — `references/00-registr-i-stil.md`.
   Готовые обороты бери из `references/05-slovar-klishe.md`.
6. **Оформи в Word** — `references/04-oformlenie-word.md`. Перед созданием
   `.docx` прочитай `/mnt/skills/public/docx/SKILL.md` и применяй параметры
   оформления из reference `04`.
7. **Прогони итоговый чек-лист** (ниже).

## Два жанра — когда какой

| Признак | Справка-доклад (`01`) | Сравнительный обзор (`02`) |
|---|---|---|
| Объект | один | класс из нескольких объектов |
| Объём | ~5–15 страниц | ~20–80 страниц |
| Ядро логики | актуальность → факты → анализ → угроза/противодействие → перспективы | единые критерии → кластеры → сводная таблица → заключение |
| Сводная таблица класса | нет | обязательна |
| Когда брать | разбор одной системы, оценка её военного потенциала | сопоставление поколений, стран, классов техники |

Если по ходу сравнительного обзора объект фактически один — переключайся на
жанр справки-доклада.

## Принципы регистра (полностью — в reference `00`)

- Безличность (третье лицо, без «я/мы»), констатирующая модальность,
  оценка через число, единый нейтральный тон для «своей» стороны и
  противника.
- Развёрнутый связный текст сложными предложениями. **Список — не основа
  повествования**, а инструмент для перечислений и подпунктов; перед списком
  — вводная фраза, пункты в одной грамматической форме.
- Термин при первом употреблении вводится по конвенции: аббревиатура
  (полная расшифровка на языке оригинала — перевод на русский), далее —
  только аббревиатура.

## Жанровые элементы (детали — в reference `01` и `04`)

- **Врезка `[Справочно]`** — курсивный блок с расширенным контекстом об
  организации, принципе или термине, вынесенный из основного потока, чтобы
  не разрывать аргументацию.
- **Маркировка достоверности по тексту** — конвенция формулировок из
  reference `03`.
- **Таблицы ТТХ и сравнения**, **рисунки с подписями** — оформление в
  reference `04`.

## Итоговый чек-лист (прогнать перед выдачей)

- [ ] Тип документа определён, взята правильная структура (`01` или `02`).
- [ ] Источники реальны; ключевые ТТХ/статусы сверены ≥2 источниками.
- [ ] Неподтверждённое явно помечено, ничего не выдумано.
- [ ] Факт, оценка и прогноз разделены; есть привязка ко времени.
- [ ] Регистр выдержан: нет «я/мы», оценки — числом, список не как основа.
- [ ] Термины введены по конвенции при первом употреблении.
- [ ] Оформление Word соответствует reference `04` (подписи рисунков и
      таблиц, врезки `[Справочно]`, единицы и диапазоны).
- [ ] Источники перечислены в конце.

## Замечания по применению

- Скилл консультируется на содержательных задачах. Тривиальный одношаговый
  запрос («что такое АФАР одним словом») скилл поднимать не обязан — это
  нормально.
- Объёмный контент держится в `references/`; тело скилла читать целиком не
  требуется — достаточно дойти до нужного reference по шагам выше.
