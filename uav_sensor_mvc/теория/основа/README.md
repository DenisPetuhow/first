# Исходные материалы — указатель папки

> **Что это.** Четыре документа Word, написанные до появления пособия. Из них собрана
> папка [пособие/](../пособие/README.md) — там тот же материал, объединённый,
> дополненный, сверенный с кодом и снабжённый рисунками.
>
> ⚠️ **Это архив, а не действующая документация.** Часть сведений здесь устарела
> (см. таблицу ниже). Для работы открывать пособие или рабочие методички; эти файлы
> хранятся ради формулировок, которые в переработку не вошли.

Word или браузером.

## Что НЕ вошло в пособие и почему

Из `оптим задача гем.docx` намеренно не перенесены разделы, описывающие механизмы,
которых **в программе нет**. Они остаются заделом:

| Раздел | Почему не вошёл |
|---|---|
| модель пространства состояний, фильтр Калмана | трекинг цели не реализован: задача — размещение, а не сопровождение |
| информационная энтропия как целевая функция | целевая функция — покрытие; энтропийный критерий не заводился |
| вероятностные ограничения (chance-constrained) | оптимизируется среднее, а не квантиль |
| робастная постановка (Robust SAA) | распределение маршрутов задаётся моделью, доверительного набора нет |
| непрерывный жадный алгоритм, матроиды, SMSC | ограничение чисто кардинальное `\|S\| = N` |

⚠️ Эти разделы в исходнике написаны так, будто механизмы уже работают («реализовано в
модуле `optimization.py`»). **Это не так** — при чтении исходников держать в уме.
