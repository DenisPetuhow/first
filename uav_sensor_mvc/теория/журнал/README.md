## Правило обновления

**Раз в 5 новых пунктов** — продлить последний диапазон и поправить числа. Иначе
указатель тихо отстанет и станет врать (так уже было с §12.0 методички, журнал п. 174).

1. **шапка** — число пунктов и строк;
2. **последняя строка таблицы разделов** — продлить диапазон или завести новый;
3. **«Быстрый поиск по симптому»** — если появилась новая повторяющаяся тема;
4. **номера строк** — сдвигаются только при правке СЕРЕДИНЫ части; при дописывании
   в конец прежние остаются верными.

**Когда часть перевалит 1 500 строк** — завести следующую (`ЖУРНАЛ_6.md`), перенести
в неё новые пункты и добавить строку в таблицу выше. Закрытые части переносить в
`теория/архив/журнал/` и чинить в них глубину относительных ссылок (`../` → `../../`).

Проверить номера строк:

```bash
python tools/переносимое/docmap.py --check      # оглавления и ссылки
```
