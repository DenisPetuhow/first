в `МЕТОДИЧКА.md`; этапы, проблемы и история — в [журнале](../журнал/README.md)
(живая часть 5, части 1–4 в архиве; вход через указатель).

Два интерфейса на **общей** модели (`model/`) и общей логике контроллера:
* matplotlib — `main.py`, `view/`, `controller/` (вкладка 1);
* PyQt5 + pyqtgraph — `main_qt.py`, `view_qt/`, `controller_qt/` (вкладки 1, 2, 3).

Вся документация — в папке `теория/`: общее в корне, остальное по папкам, у каждой
свой `README.md`. Начинать поиск с [теория/README.md](../README.md).

## model/trajectories.py

Геометрия дуг:
* `make_arc_by_angle(A,B,θ,n)` — дуга по касательно-хордовому углу θ.
* `arc_length_from_angle`, `max_deflection_angle` — длина дуги и предельный угол θ_max.
  (`_sagitta_from_angle` — построение через стрелу прогиба — **удалена**: дуга при θ > 90°
  вырождалась в малую, заменена прямой параметризацией `make_arc_by_angle`.)
* `_sample_angle(rng,θ_max,σ,profile)` — случайный угол по профилю.
* `sample_arc_trajectory(...)` — случайная дуга; `arc_fan`, `frequent_arcs` — веер/частые.

Коридор движения:
* `corridor_outline / corridor_polygon / corridor_filter / corridor_bbox` — границы и фильтр.
* `_reach_ellipse_halves` — половины эллипса (для манёвра).

Петли/змейки:
* `make_serpentine`, `max_serpentine_amplitude`, `sample_serpentine_trajectory`,
  `frequent_serpentines`, `serpentine_fan`.

Физика и манёвр по точкам/синусу:
* `turn_radius_km(V,φ)` — **R_min = V²/(g·tan φ)** (км).
* `_WP_MODE`, `_BALANCED_P`, `_pick_mode` — параметры режимов разброса (амплитуда ρ,
  пологость, чередование) и выбор «смешанного».
* `_waypoints(S0,B,L_max,rng,mode,r_min,nrange,s_min)` — путевые точки: число из
  nrange, продольная стратификация, боковой вынос-линза с базой `b` (полу-малая
  ось эллипса); сложный — 1–2 крупных лепестка к краю; `s_min` — нижняя доля.
* `_round_corners(verts,r_min,turn_frac,n)` — скругление углов дугами ≥ R_min.
* `_waypoint_path(...,rounded,s_min)` — путь по точкам с укладкой в L_max.
* `_sine_path(...)` — манёвр по гармоникам с ограничением кривизны ≤ 1/R_min.
* `maneuver_path(...,law,s_min)` — диспетчер: «sine» → `_sine_path`, иначе по точкам.
* `polyline_path(...,s_min)` — путь по точкам без скругления.
* `sample_maneuver_trajectory`, `sample_polyline_trajectory`, `frequent_maneuvers`,
  `maneuver_fan` — сэмплеры/слои.
* `SAMPLERS` — словарь сэмплеров по ключу модели.

## model/simulation.py — `SimulationModel` (вкладка 1)

Старт — точка A. `reset()` считает `r_min` (из ТТХ) и фильтрует кандидатов

`r_min`, `(n_min,n_max)`, `maneuver_law`. `recompute_placement` — жадный выбор с

## model/area_start.py — `AreaStartModel` (вкладка 2)

Старт — случайная точка `S0` из эллипса зоны. Векторная геометрия и условия:
* `_frame(A,B)` — орты оси и нормали; `start_zone_outline`, `reach_ellipse_outline`;
* `reach_envelope_outline(A,B,depth,width,L_max)` — огибающая достижимости с учётом
  зоны старта (объединение эллипсов S0,B; маршруты не выходят за контур);
* `sample_start_point(A,B,depth,width,rng)` — точка старта в эллипсе зоны;
* `_zone_exit_frac(S0,A,B,depth,width)` — доля выхода из зоны (опорная проекция,
  формула 14) → `s_min` для путевых точек «только за зоной»;
* `points_outside_start_zone(pts,A,B,depth,width)` — маска кандидатов ВНЕ эллипса
  зоны (датчики в зоне не размещаются);
* `sample_area_arc / sample_maneuver / sample_polyline` — генераторы маршрутов;
  `zone_exclude` решает, ставить ли точки только за зоной (по `waypoint_zone`).

Класс `AreaStartModel`: `set_route(A,B)` (запоминает направление `_dir`),
`reset()` (B = A + |AB|·_dir — следует за полем; фильтрует кандидатов: не за B,
вне зоны старта И не за её задней кромкой 180°), `_sample` (диспетчер + флаг
зоны), `_anchor_idx`, `recompute_placement`, `step / run_batch / evaluate / слои`.

## Поток данных (одна итерация)

```
sample_trajectory() ─► маршрут γ
        │
        ▼
CoverageCache.add_trajectory(γ)   (hit / segmask / covfrac по кандидатам)
        │
        ▼
recompute_placement()  = greedy(N, weights, якорь у B, развязка)
        │
        ▼
View: анимация полёта + датчики + метрики
```

Накопление `T` итераций → выборочное среднее F_t стабилизируется → расстановка
датчиков перестаёт меняться.
