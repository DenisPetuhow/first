# Интерфейс — документы папки

Как поправить вид программы руками.

| Файл | О чём | Когда открывать |
|---|---|---|
| [НАСТРОЙКА_ИНТЕРФЕЙСА.md](НАСТРОЙКА_ИНТЕРФЕЙСА.md) | подписи, цвета, толщина линий, легенда, прозрачность, начальные значения полей, заставка при запуске — что где менять | «сделай линию толще / другой цвет» |

**Соглашение о цветах.** Все цвета вкладки 3 — только в `view_qt/threat_view.py`
(`THREAT_COLORS`, `LAYER_STYLE`); остальные параметры и тема — в `config.py`
(`Params`, `THEME`). Не разбрасывать константы по коду.

➡️ **Сборка `.exe` переехала в отдельную папку** — [теория/сборка/](../сборка/README.md):
там инструкция по сборке, правки в готовой программе без пересборки и руководство
пользователя для передачи вместе с программой.
