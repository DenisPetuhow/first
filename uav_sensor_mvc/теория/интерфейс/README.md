# Интерфейс и поставка — документы папки

Как поправить вид программы руками и как собрать её для показа на чужом компьютере.

| Файл | О чём | Когда открывать |
|---|---|---|
| [НАСТРОЙКА_ИНТЕРФЕЙСА.md](НАСТРОЙКА_ИНТЕРФЕЙСА.md) | подписи, цвета, толщина линий, легенда, прозрачность, начальные значения полей — что где менять | «сделай линию толще / другой цвет» |
| [СБОРКА_EXE.md](СБОРКА_EXE.md) | сборка демонстрационного `.exe`: окружение, рецепт `build_demo.spec`, флаги `DEMO_*`, ловушки | пересобрать демо-версию |

**Соглашение о цветах.** Все цвета вкладки 3 — только в `view_qt/threat_view.py`
(`THREAT_COLORS`, `LAYER_STYLE`); остальные параметры и тема — в `config.py`
(`Params`, `THEME`). Не разбрасывать константы по коду.

⚠️ **Сборка — из ветки `demo-build`**, из пути без кириллицы. Три ловушки, на которых
уже спотыкались, перечислены в начале `СБОРКА_EXE.md` — прочитать до начала работы.
