## 1. Шкала градаций (13.5.1)

**Где:** `view_qt/grad_legend.py :: GradLegend` (плашка) · `view_qt/threat_view.py :: SCALE_SPECS`, `_note_scale_layer`, `_update_scale`, `_place_grad_legend`, `_grad_rows`; числа шкал кладут `render_threat`, `render_iter_heat`, `render_relief`, `render_relief_priority`, `render_buildings` в `self._grad_info`.

**Суть простыми словами.** Цвет на карте сам по себе ничего не говорит — нужна «линейка»: какой цвет какому числу соответствует. Линейка на карте одна и подписывает последний включённый слой — как подпись к карте, положенной на стол последней. Её числа — тем же правилом, каким красили слой, иначе цвет и подпись разойдутся.

**Как работает.** Каждая отрисовка слоя с градацией кладёт числа своей шкалы (верх, низ). Порядок включения — список `_scale_order`: включили — ключ в конец, сняли — в начало. Показывается последний ключ, чей слой виден. Плашка — дочерний виджет окна карты, вне раскладки графика, поэтому карта не ужимается.

**Плашка — строки «цвет — значение» поверх карты:**

```python
class GradLegend(QtWidgets.QFrame):
    """Плашка шкалы поверх карты. Вход: виджет карты (родитель). Отдаёт: виджет; `show_rows` — заполнить и показать,
    `place` — прижать к правому краю."""

    ROWS_MAX = 12                                    # строк шкалы больше не бывает (категории + непрерывные)
    MARGIN_PX = 8                                    # отступ от правого края окна карты, px

    def __init__(self, parent):
        super().__init__(parent)
        self.setObjectName("gradLegend")
        # ⚠️ щелчки и колесо — карте: плашка лежит поверх неё и иначе съедала бы перетаскивание вида
        self.setAttribute(QtCore.Qt.WA_TransparentForMouseEvents, True)
        self.setStyleSheet("#gradLegend { background: #ffffff; border: 1px solid #9aa3ad; border-radius: 6px; }")
        lay = QtWidgets.QVBoxLayout(self)            # заголовок и строки сверху вниз
        lay.setContentsMargins(3, 3, 3, 3)
        lay.setSpacing(1)
        self._title = QtWidgets.QLabel()             # что за величина и в чём
        self._title.setAlignment(QtCore.Qt.AlignCenter)
        # ⚠️ фон — явно: тёмная тема окна красит фон всех надписей, и заголовок выходил тёмным по тёмному
        self._title.setStyleSheet("background:#ffffff; color:#222222; font-size:8pt; font-weight:bold; padding:0 2px;")
        lay.addWidget(self._title)
        self._cells = []                             # строки шкалы — подписи на цветном фоне
        for _ in range(self.ROWS_MAX):               # заготовка строк: прячутся лишние
            cell = QtWidgets.QLabel()                # строка шкалы
            cell.setAlignment(QtCore.Qt.AlignCenter)
            lay.addWidget(cell)
            self._cells.append(cell)
        self.key = None                              # чья шкала сейчас показана (ключ слоя) — для проверок
        self.hide()

    def show_rows(self, key, title, rows):
        """Заполнить шкалу и показать. Вход: ключ слоя, заголовок, строки [((r, g, b), подпись)] сверху вниз.
        Отдаёт: ничего."""
        self.key = key
        self._title.setText(title)
        for i, cell in enumerate(self._cells):       # строки по порядку; лишние — спрятать
            if i >= len(rows):                       # строк меньше заготовки
                cell.hide()
                continue
            rgb, text = rows[i]                      # цвет клетки и подпись
            hexc = "#%02x%02x%02x" % tuple(int(round(c)) for c in rgb[:3])   # цвет клетки
            cell.setText(text)
            cell.setStyleSheet("background:%s; color:%s; font-size:8pt; padding:1px 6px; border-radius:2px;"
                               % (hexc, ink_for(rgb)))
            cell.show()
        self.adjustSize()
        self.show()
        self.raise_()

    def hide_rows(self):
        """Спрятать шкалу: ни одного слоя с градацией не включено. Вход: нет. Отдаёт: ничего."""
        self.key = None
        self.hide()

    def place(self, top_px):
        """Прижать к правому краю окна карты. Вход: верх плашки, px от верха окна. Отдаёт: ничего."""
        par = self.parentWidget()                    # окно карты
        if par is None:                              # не на чем держаться
            return
        self.adjustSize()
        self.move(max(0, par.width() - self.width() - self.MARGIN_PX), int(top_px))
```

**Шесть слоёв и порядок включения:**

```python
def _note_scale_layer(self, key, on):
    """Запомнить, какой слой включили последним, и показать его шкалу. Вход: ключ слоя, включён ли.
    Отдаёт: ничего."""
    if key in self._scale_order:           # слой уже в списке — переставить
        self._scale_order.remove(key)
    if on:                                 # включили — в конец: его шкала и покажется
        self._scale_order.append(key)
    else:                                  # выключенный уходит в начало, а не пропадает:
        self._scale_order.insert(0, key)   # включат обратно — снова станет последним
    self._update_scale()
```

```python
def _update_scale(self):
    """Показать шкалу слоя, включённого последним из видимых; ни одного — скрыть. Вход: нет. Отдаёт: ничего."""
    if getattr(self, "grad_legend", None) is None:   # окно ещё строится
        return
    # ⚠️ «видим» — по самому слою, а не по галке: галку уже сняли, а перерисовка ещё не дошла — или слой
    # включён, но данных нет (рельеф без файла высот), и шкала без картинки только запутала бы
    live = [k for k in self._scale_order   # видимые слои с градацией, по порядку включения
            if k in self._grad_info and getattr(self, self.SCALE_SPECS[k]["item"]).isVisible()]
    if not live:                           # градаций на карте нет — плашку убрать
        self.grad_legend.hide_rows()
        return
    key = live[-1]                         # последний включённый
    self.grad_legend.show_rows(key, self.SCALE_SPECS[key]["title"], self._grad_rows(key))
    self._place_grad_legend()
```

**Строки шкалы — тем же преобразованием, что картинка слоя:**

```python
def _grad_rows(self, key):
    """Строки шкалы слоя по числам его последней отрисовки. Вход: ключ слоя. Отдаёт: [((r, g, b), подпись)]
    сверху вниз — как на образце `фото пример/…015613`."""
    g = self._grad_info[key]               # числа шкалы: верх, низ …
    ts = np.linspace(1.0, 0.0, self.SCALE_ROWS)   # доли шкалы сверху вниз
    if key == "threat":                    # вес: доля от 97-го перцентиля (выше — тот же цвет), LUT turbo
        return [(self._lut[int(round(t * 255))][:3], ("≥ " if t == 1.0 else "") + _num(g["top"] * t))
                for t in ts]
    if key == "iter_heat":                 # цвет — по √ доли от максимума, подпись — маршрутов: верх · t²
        lut = _iter_heat_lut()             # magma
        ts = np.linspace(1.0, np.sqrt(0.005), self.SCALE_ROWS)   # ниже 0.5 % от максимума слой прозрачен
        return [(lut[int(round(t * 255))][:3], _num(g["top"] * t * t)) for t in ts]
    if key == "relief":                    # высоты: шкала по перцентилям 2…98 %, цвет — RELIEF_RAMP без светотени
        st = np.array([p for p, _c in RELIEF_RAMP], float)   # ступени шкалы, доли
        cl = np.array([c for _p, c in RELIEF_RAMP], float)   # их цвета, RGB
        return [([np.interp(t, st, cl[:, ch]) for ch in range(3)],
                 ("≥ " if t == 1.0 else "≤ " if t == 0.0 else "") + "%d м" % round(g["lo"] + t * (g["hi"] - g["lo"])))
                for t in ts]
    if key == "relief_k":                  # множитель веса: укрытие · без изменения · возвышенность · снято
        rows = [(_over_white(RELIEF_HIDE_RGB, f * RELIEF_MAX_ALPHA), "%.2f укрытие" % (1 + f * (g["hi"] - 1)))
                for f in (1.0, 0.5)]       # сильное и половинное укрытие
        rows.append(((255, 255, 255), "1.00 без изменения"))
        rows += [(_over_white(RELIEF_OPEN_RGB, f * RELIEF_MAX_ALPHA), "%.2f возвышенность" % (1 - f * (1 - g["lo"])))
                 for f in (0.5, 1.0)]      # половинная и сильная возвышенность
        if g["cut"]:                       # есть снятое отсечкой
            rows.append((_over_white(RELIEF_CUT_RGBA[:3], RELIEF_CUT_RGBA[3]), "0 коридор снят"))
        return rows
    # ПОСТРОЙКИ: число — логарифмом от 1 до максимума участка, этажность — линейно (как в `render_buildings`)
    c0 = np.array(_qcolor(THREAT_COLORS[g["lo_c"]]).getRgb()[:3], float)   # низ шкалы, RGB
    c1 = np.array(_qcolor(THREAT_COLORS[g["hi_c"]]).getRgb()[:3], float)   # верх шкалы, RGB
    if key == "bld_count":                 # число: top^t — та же доля, что log(v)/log(top)
        return [(c0 + (c1 - c0) * t, "%d" % round(g["top"] ** t)) for t in ts]
    return [(c0 + (c1 - c0) * t, "%.1f" % (1.0 + t * (g["top"] - 1.0))) for t in ts]
```

**Пример.** Весовая → «Постройки: число» → «этажность» → сняли этажность: шкала числа построек (180 … 1 на `arh`).

**Пример с расчётом.** десять строк, доли шкалы t = 1, 8/9, 7/9 … 0 (`arh`, числа — скриптом).
* **Весовая — линейно.** Верх — 97-й перцентиль веса **28.28** (выше — тот же цвет, отсюда «≥»). Подпись = 28.28 · t: ≥ 28.3 · 25.1 · 22.0 · 18.9 · 15.7 · 12.6 · 9.4 · 6.3 · 3.1 · 0 — ровный шаг 3.14.
* **Постройки, число — логарифмом.** Максимум ячейки **180**; доля цвета = ln v / ln 180, обратно подпись = 180^t: 180 · 101 · 57 · 32 · 18 · 10 · 6 · 3 · 2 · 1. Ячейка с 32 постройками: ln 32 / ln 180 = 3.47 / 5.19 = **0.667** — ровно четвёртая строка (t = 6/9). Шаг неровный нарочно: при линейной шкале 1–20 построек слились бы в один цвет.
* **Тепловая маршрутов — по √.** Цвет = √(доля от максимума), подпись = верх · t². Пусть в самой частой ячейке 200 маршрутов (число для примера): середина цвета t = 0.5 → 200 · 0.25 = **50** маршрутов, нижняя строка t = √0.005 = 0.071 → 200 · 0.005 = **1** маршрут. √ поднимает редкие пролёты: ячейка с 1 % маршрутов окрашена на 10 % шкалы, а не на 1 %.

| Где легко сломать | Почему |
|---|---|
| класть плашку в раскладку `PlotItem` | вернётся сужение карты («0.97») |
| судить о видимости по галке | галку сняли, а перерисовка не дошла; слой без данных (нет файла высот) |
| менять формулу картинки без `_grad_rows` | подписи разойдутся с цветом (тепловая — по √, постройки — по логарифму) |

## 2. Прозрачность групп (13.5.2)

**Где:** `view_qt/threat_view.py :: OPACITY_TARGETS`, `_opacity_items`, `_set_group_opacity`, `_apply_opacity`, `_reapply_opacity`.

**Суть простыми словами.** Ползунок группы — общий диммер: он не задаёт яркость каждой лампы, а убавляет каждую в одно и то же число раз. Слабые элементы так и остаются слабее сильных. Для этого у каждого элемента запоминается его «родная» прозрачность, и множитель всегда умножается на неё, а не на текущую.

**Как работает.** Ползунок группы задаёт множитель и умножает на него родную прозрачность каждого элемента группы. `@имя` — список, который пересоздаётся при отрисовке (датчики, подписи): множитель помнится и применяется к новым элементам после каждой перерисовки.

```python
def _opacity_items(self, attrs):
    """Развернуть цели в реальные элементы сцены (включая словарные слои)."""
    out = []
    for attr in attrs:
        for item_name in self.OPACITY_TARGETS.get(attr, ()):
            if item_name.startswith("@"):     # список элементов (датчики, подписи) — все его элементы
                out += list(getattr(self, item_name[1:], None) or [])
                continue
            if item_name == "*vectors":
                out += list(self._layer_items.values())
                out += list(self._layer_casing.values())
                continue
            it = getattr(self, item_name, None)
            if it is not None:
                out.append(it)
    return out
```

```python
def _set_group_opacity(self, attrs, value):
    """Прозрачность слоёв-заливок. Модель не трогаем — это чистая отрисовка.

    Ползунок МАСШТАБИРУЕТ родную прозрачность слоя, а не задаёт её: у рельефа она
    0.55, у тепловой карты 0.62 — выставив 1.0, мы бы сделали их непрозрачными и
    закрыли всё под ними. При 100 % слой выглядит ровно так, как задумано."""
    a = max(0.0, min(1.0, value / 100.0))
    for attr in attrs:                     # множитель группы — помнить: пересозданным элементам он тоже нужен
        self._group_alpha[attr] = a
    self._apply_opacity(attrs)
```

```python
def _apply_opacity(self, attrs):
    """Применить множители групп к элементам слоёв (13.5.2). Вход: галки-слои. Отдаёт: ничего."""
    for attr in attrs:                     # слой за слоем: у каждого множитель своей группы
        a = self._group_alpha.get(attr, 1.0)   # множитель; 1 — ползунок не трогали
        for it in self._opacity_items([attr]):   # все элементы слоя на сцене
            try:
                # ⚠️ родная прозрачность — СВОЙСТВОМ ЭЛЕМЕНТА, а не по `id`: у пересозданных датчиков `id`
                # повторяются, и база бралась от чужого, уже притушенного элемента
                base = getattr(it, "_base_op", None)   # родная прозрачность
                if base is None:           # элемент встречен впервые — запомнить
                    base = it._base_op = float(it.opacity())
                it.setOpacity(base * a)
            except Exception:              # элемент уже снят со сцены
                pass
```

```python
def _reapply_opacity(self):
    """После перерисовки списков (датчики, подписи) — вернуть им прозрачность групп. Вход: нет. Отдаёт: ничего."""
    if self._group_alpha:                  # ползунки трогали
        self._apply_opacity(list(self._group_alpha))
```

**Пример.** «Датчики и подписи» на 50 % — все 69 значков вдвое бледнее, и после «Расставить датчики» тоже (`gui_check` 26).

**Пример с расчётом.** ползунки «Тепловая маршрутов» и «Весовая» на 50 %.
* родная прозрачность тепловой **0.62**, весовой **0.55** (`threat_view.py`, `setOpacity`): 0.62 × 0.5 = **0.31**, 0.55 × 0.5 = **0.275** — тепловая по-прежнему плотнее весовой;
* «Расставить датчики» пересоздаёт значки: новый значок запоминает свою базу (непрозрачный — 1.0) и получает 1.0 × 0.5 = 0.5;
* ⚠️ ошибка, от которой бережёт `_base_op`: база взята с уже притушенного значка (0.5) → 0.5 × 0.5 = 0.25, после следующей перерисовки 0.125 — каждый пересчёт вдвое бледнее, при том же положении ползунка.

## 3. Колесо мыши: уровни тайлов, плавный Ctrl, рука (13.5.3, 13.5.6, 13.5.7)

**Где:** `view_qt/tile_layer.py :: SteppedViewBox` (`__init__`, `zoom_smooth`, `_free_tick`, `wheelEvent`, `mouseDragEvent`), `TileLayer.set_view` (`hold_z`) · `view_qt/threat_view.py :: _on_free_zoom`, `_ctrl_poll` · `view_qt/basemap_mixin.py :: nearest_level_span`.

**Суть простыми словами.** Подложка — готовые снимки местности на каждом уровне масштаба, и каждый уровень вдвое крупнее предыдущего. Обычное колесо прыгает по этим уровням — картинка всегда чёткая. Ctrl — «лупа»: масштаб любой и плавный, снимки на это время берутся с замороженного уровня и чуть растягиваются; отпустили Ctrl — вид мягко встаёт на ближайший уровень, и чёткость возвращается.

**Как работает.** Обычное колесо — охват ×2 за щелчок (уровень тайлов, подложка пиксель в пиксель). С Ctrl щелчок не прыгает, а копит множитель, и таймер «доезжает» до него кадрами по 16 мс — четверть оставшегося пути за кадр, в логарифме. Уровень тайлов на это время заморожен. Ctrl отпустили — вид той же анимацией встаёт на ближайший уровень, заморозка снимается. Перетаскивание — курсор «сжатая рука».

```python
def zoom_smooth(self, factor, at, done=None):
    """Плавно умножить охват вида (13.5.6). Вход: множитель (< 1 — приблизить), неподвижная точка (x, y) км,
```

```python
def _free_tick(self):
    """Кадр плавного масштаба: часть оставшегося пути. Вход: нет. Отдаёт: ничего."""
    left = self._free_left                     # остаток пути, множитель охвата
    # ⚠️ шаг — в ЛОГАРИФМЕ: ×0.8 и ×1.25 — одинаковые по ощущению шаги, а доля разности их бы исказила
    step = left if abs(math.log(left)) < 0.002 else left ** self.FREE_SHARE   # множитель охвата за кадр
    self._free_left = left / step
    (x0, x1), (y0, y1) = self.viewRange()
    ny0, ny1 = self._zoom_axis(y0, y1, self._free_at.y(), step)   # Y — к той же точке
    set_span_x(self, self._zoom_axis(x0, x1, self._free_at.x(), step), y_center=(ny0 + ny1) * 0.5)
    if self._free_left == 1.0:                 # доехали
        self._free_timer.stop()
        done, self._free_done = self._free_done, None   # обработчик — один раз
        if done is not None:                   # было что сделать по окончании
            done()
```

```python
def _ctrl_poll(self):
    """Ctrl отпустили — снять заморозку и поставить вид на ближайший уровень тайлов (картинка снова пиксель в

        return

        """Доехали до уровня — снять заморозку и догрузить тайлы уровня. Вход: нет. Отдаёт: ничего."""

        return

    span = (x1 - x0) * self.vb._free_left       # охват, к которому ещё едет анимация, км
```

```python
def nearest_level_span(self, span_km):
    """Охват вида на ближайшем уровне тайлов — где подложка пиксель в пиксель (13.5.3, 13.5.6). Вход: охват, км.
    Отдаёт: охват уровня, км."""
    km_per_deg = gm._km_per_deg_lon(self._geo_lat0)   # км в градусе долготы на широте якоря
    width_px = self._map_px()                      # ширина карты, px
    # ширина вида на уровне z: (px / 256 тайлов) / 2^z мира · 360° · км на градус; ближайший — по логарифму
    want = [(width_px / 256.0) / (2.0 ** z) * 360.0 * km_per_deg for z in range(gm.ZOOM_MIN, gm.ZOOM_MAX + 1)]
    return min(want, key=lambda w: abs(math.log(w / float(span_km))))
```

**Пример.** Щелчок с Ctrl — ×1.25 за 18 кадров (~0.3 с); тачпад шлёт мелкие порции, и масштаб идёт с пальцем.

**Пример с расчётом.** (числа — скриптом по коду `_free_tick` и `nearest_level_span`).
* **Сколько кадров у щелчка.** Приблизить в 1.25 раза — охват × 0.8, путь в логарифме ln 0.8 = −0.2231. Кадр проходит четверть оставшегося: после n кадров остаётся 0.2231 · 0.75ⁿ. Меньше 0.002 — при n = 17 (0.2231 · 0.0075 = 0.0017), 18-й кадр добирает остаток. **18 кадров × 16 мс ≈ 0.29 с.** Охват по кадрам: × 0.9457 · × 0.9590 · × 0.9691 · × 0.9767 … — шаг тает, движение тормозит к концу; произведение ровно 0.8.
* **Почему в логарифме.** Приблизить × 1.25 и отдалить × 1.25 — пути +0.2231 и −0.2231, одинаковые: оба идут за 18 кадров. Шаг долей разности в километрах (100 → 80 км и 80 → 100 км) дал бы разную скорость в двух направлениях.
* **Ближайший уровень.** Карта шириной 1 142 пикселя (пример), широта `arh` — 1° долготы = 52.76 км. Охват уровня z = (1142 / 256) / 2^z · 360 · 52.76: z8 — 331.0 км, **z9 — 165.5 км**, z10 — 82.7 км. Ctrl отпустили на охвате 148 км: |ln(165.5 / 148)| = **0.112**, |ln(82.7 / 148)| = 0.581 → ближе z9, вид плавно расширится до 165.5 км. Сравнение — в логарифме, потому что уровни идут × 2: середина между z9 и z10 — 117 км (√ произведения), а не 124 км.

| Где легко сломать | Почему |
|---|---|
| шаг анимации — долей разности, а не в логарифме | приближение и отдаление пойдут с разной скоростью |
| `hold_z` без предела в два уровня | при отдалении тысячи тайлов разом |
| ждать отпускания Ctrl по событию клавиши | у карты нет фокуса — событие не придёт; поэтому опрос таймером |
| курсор-рука без пары `restoreOverrideCursor` | рука «залипнет» на всё приложение |

## 4. Слои МОГ: пути доезда по векторным дорогам, слитые контуры (13.5.9, 13.5.12)

**Где:** `model/road_access.py :: road_graph`, `reach_lines` · `model/sensor_zones.py :: dissolved_rings` · `controller_qt/threat_controller.py :: on_type_zone` · `view_qt/threat_view.py :: show_type_zone`, `_arrow_heads`.

**Суть простыми словами.** МОГ ездит только по дорогам, поэтому «куда доедет» считается не по прямой, а по дорогам — как навигатор. Навигатор (алгоритм Дейкстры) расходится от цели волной: сначала закрывает ближайшие перекрёстки, потом дальние, и каждому запоминает, откуда к нему пришли кратчайшим путём. Эти «откуда» и есть дерево путей на карте, стрелки — направление от цели. Лес на карте — много кусков от разных авторов OSM; если обвести каждый, внутри массива видны швы, поэтому обводится общий контур — как контур лужи, а не каждой капли.

**Как работает.** Граф строится по самим линиям дорог OSM: узел — вершина ломаной (совпавшие до метра — один узел, так сходятся перекрёстки), ребро — отрезок. Дейкстра от ближайшего к цели узла даёт дерево кратчайших путей; оно рисуется ломаными от конца каждой ветки к развилке, стрелки — где путь пересекает очередные 5 км. Лес, болота, неудобья — один слитый контур (`shapely.unary_union`), без швов между кусками OSM.

```python
def road_graph(layers, names=DRIVE_LAYERS, tol_km=0.001):
    """Граф дорог по ВЕКТОРНЫМ линиям (план 13.5, 13.5.9): узел — вершина ломаной (совпавшие до `tol_km` — один узел,
    так сходятся перекрёстки OSM), ребро — отрезок. Вход: dict слой -> ломаные (M,2) км, имена слоёв, допуск км.
    Отдаёт: (узлы (N,2) км, CSR: начала (N+1,), соседи (E,), длины (E,) км); дорог нет — пустые массивы."""
    lines = [np.asarray(a, float)[:, :2] for n in names for a in layers.get(n, []) if len(a) >= 2]   # ломаные дорог, км
    if not lines:                                    # дорог на карте нет
        return np.zeros((0, 2)), np.zeros(1, np.int64), np.zeros(0, np.int64), np.zeros(0)
    pts = np.vstack(lines)                           # все вершины подряд, км
    own = np.repeat(np.arange(len(lines)), [len(a) for a in lines])   # номер ломаной у каждой вершины
    # ⚠️ ОДИН УЗЕЛ НА ТОЧКУ: на перекрёстке OSM у дорог общая вершина — округлив до метра, склеиваем её в один узел.
    # Без склейки граф распался бы на 12 тыс. отдельных ломаных, и от цели нельзя было бы уехать дальше своей дороги
    key = np.round(pts / tol_km).astype(np.int64)    # координаты в метрах (при допуске 1 м), целые
    _u, node = np.unique(key[:, 0] * 2_000_003 + key[:, 1], return_inverse=True)   # номер узла у каждой вершины
    nodes = np.zeros((len(_u), 2))                   # координаты узлов, км
    nodes[node] = pts
    same = own[1:] == own[:-1]                       # соседние вершины — из одной ломаной (отрезок)
    a, b = node[:-1][same], node[1:][same]           # концы отрезков — номера узлов
    ln = np.hypot(*(pts[1:][same] - pts[:-1][same]).T)   # длины отрезков, км
    ok = a != b                                      # отрезок короче допуска — петля в узле, выбросить
    src = np.concatenate([a[ok], b[ok]])             # ребро в обе стороны: откуда
    dst = np.concatenate([b[ok], a[ok]])             # куда
    w = np.concatenate([ln[ok], ln[ok]])             # длина, км
    order = np.argsort(src, kind="stable")           # рёбра — подряд по узлу-началу (CSR)
    start = np.searchsorted(src[order], np.arange(len(nodes) + 1))   # где начинаются рёбра узла
    return nodes, start, dst[order], w[order]
```

```python
def reach_lines(layers, targets, lim_km=0.0, step_km=5.0, names=DRIVE_LAYERS):
    """Пути доезда МОГ от целей по ВЕКТОРНЫМ дорогам (13.5.9): дерево кратчайших путей и стрелки по ходу движения.
    Вход: dict слой -> ломаные км, цели [(x, y)] км, предел км (0 — без), шаг стрелок км, слои дорог.
    Отдаёт: (ломаные [(M,2) км] — от конца ветки к развилке, стрелки [(x, y, dx, dy)] км)."""
    nodes, start, nbr, w = road_graph(layers, names)   # граф дорог по линиям
    if not len(nodes) or not targets:                # ехать не по чему или не откуда
        return [], []
    best = np.full(len(nodes), np.inf)               # км по дорогам от ближайшей цели
    par = np.full(len(nodes), -1, np.int64)          # узел-родитель в дереве кратчайших путей
    heap = []                                        # очередь: (км, узел)
    for x, y in targets:                             # от каждой цели — ближайший узел дороги
        i = int(np.argmin(np.hypot(nodes[:, 0] - x, nodes[:, 1] - y)))   # исток у цели
        best[i] = 0.0
        heap.append((0.0, i))
    heapq.heapify(heap)
    st, nb, wl = start.tolist(), nbr.tolist(), w.tolist()   # списками: в цикле быстрее, чем индекс numpy
    while heap:                                      # ближайший ещё не закрытый узел
        d, u = heapq.heappop(heap)                   # км до него, узел
        if d > best[u]:                              # устаревшая запись очереди
            continue
        for e in range(st[u], st[u + 1]):            # рёбра узла
            v, nd = nb[e], d + wl[e]                 # сосед и км до него через u
            if nd < best[v] and (lim_km <= 0 or nd <= lim_km):   # короче известного и в пределе выезда
                best[v], par[v] = nd, u
                heapq.heappush(heap, (nd, v))
    lines, seen = [], np.zeros(len(nodes), bool)     # ломаные; узлы, уже вошедшие в ломаную
    for u in np.argsort(-best):                      # от дальних узлов: каждая ветка — с конца
        u = int(u)                                   # узел
        if not np.isfinite(best[u]) or par[u] < 0 or seen[u]:   # не доезжает, исток или уже нарисован
            continue
        path = [u]                                   # узлы ветки от конца к развилке
        while par[u] >= 0 and not seen[u]:           # вверх по дереву до цели или до нарисованного
            seen[u] = True
            u = int(par[u])
            path.append(u)
        lines.append(nodes[path])
    # СТРЕЛКИ — где путь пересекает очередные step км, по ходу движения от цели; ближе 0.6·step к уже поставленной —
    # не ставить (на развилках ветки пересекают отметку рядом)
    arrows, taken = [], {}                           # стрелки; занятые клетки решётки прореживания
    cell = 0.6 * float(step_km)                      # клетка прореживания, км
    for v in np.argsort(best):                       # от цели наружу
        v = int(v)                                   # узел
        u = int(par[v])                              # его родитель
        if u < 0 or not np.isfinite(best[v]) or np.floor(best[v] / step_km) <= np.floor(best[u] / step_km):   # нет отметки
            continue
        ax, ay = nodes[v]                            # место стрелки, км
        k = (int(ax // cell), int(ay // cell))       # клетка решётки
        near = [taken.get((k[0] + i, k[1] + j)) for i in (-1, 0, 1) for j in (-1, 0, 1)]   # соседние стрелки
        if any(q is not None and math.hypot(q[0] - ax, q[1] - ay) < cell for q in near):   # рядом уже есть
            continue
        taken[k] = (ax, ay)
        arrows.append((float(ax), float(ay), float(ax - nodes[u, 0]), float(ay - nodes[u, 1])))
    return lines, arrows
```

```python
    fp = layers_path()                               # файл мест участка
    key = (fp, os.path.getmtime(fp) if os.path.exists(fp) else 0.0, layer, min_km2, tol_km)   # ключ: файл не правили
    if key in _DISSOLVED:                            # уже сливали — дорогое не повторять (12 тыс. колец — секунды)
        return _DISSOLVED[key]
    polys = []                                       # куски слоя полигонами
    for r in load().get(layer, []):                  # внешние кольца файла мест
        if len(r) < 3:                               # не кольцо
            continue
        p = Polygon(np.asarray(r, float)[:, :2])     # кусок полигоном, км
        if not p.is_valid:                           # упрощение при извлечении дало самопересечение
            p = p.buffer(0)                          # — починить
        if not p.is_empty:                           # кусок не выродился
            polys.append(p)
    out = []                                         # кольца слитого контура
    if polys:                                        # есть что сливать
        # ⚠️ СЛИЯНИЕ, А НЕ РИСОВАНИЕ КУСКОВ: лес OSM нарезан на тысячи соседних полигонов (у 8 685 из 12 297 колец меньше
        # 10 вершин), и общие края рисовались линиями внутри массива — «много лишних линий» (заказчик 02.10.2026)
        u = unary_union(polys).simplify(tol_km)      # одно целое без внутренних швов, упрощённое
        for part in getattr(u, "geoms", [u]):        # острова слитого слоя
            if part.geom_type != "Polygon" or part.area < min_km2:   # мелочь — на карте не читается
                continue
            out.append(np.asarray(part.exterior.coords, float))
            out += [np.asarray(h.coords, float) for h in part.interiors if Polygon(h).area >= min_km2]   # поляны
    _DISSOLVED[key] = out
    return out
```

```python
def _arrow_heads(self, arrows):
    """Наконечники стрелок путей доезда — «галочки» по ходу движения. Вход: [(x, y, dx, dy)] км. Отдаёт: ломаные
    [(3,2) км]."""
    out = []                                   # по ломаной на стрелку
    L = self.REACH_HEAD_KM                     # длина наконечника, км
    c, s = np.cos(np.radians(25.0)), np.sin(np.radians(25.0))   # раствор наконечника ±25°
    for x, y, dx, dy in arrows:                # стрелка: место и направление
        n = float(np.hypot(dx, dy))            # длина направления
        if n <= 1e-12:                         # направления нет — пропустить
            continue
        ux, uy = dx / n, dy / n                # единичное направление
        out.append(np.array([[x - L * (c * ux - s * uy), y - L * (s * ux + c * uy)], [x, y],
                             [x - L * (c * ux + s * uy), y - L * (-s * ux + c * uy)]]))
    return out
```

**Пример.** `arh`: сеть путей 4 906 км из 5 709 км дорог (85.9 %), 4 022 ломаные, 372 стрелки, 0.16 с; лес — 12 297 колец → 3 246 (2.9 с один раз, дальше из памяти).

**Пример с расчётом.** игрушечная сеть, цель A (0, 0) (проверено вызовом `reach_lines`, шаг стрелок 2 км).
```
дороги:  A(0,0) — B(2,0)        2 км
         B(2,0) — C(2,3)        3 км
         A(0,0) — D(-1,3) — C   √10 = 3.16 км + 3 км (объезд)
```
1. исток A = 0; соседи: B = 2, D = 3.16;
2. закрыть ближайший B (2): C через B = 2 + 3 = **5**;
3. закрыть D (3.16): C через D = 3.16 + 3 = 6.16 > 5 — не меняем;
4. закрыть C (5). Дерево: C ← B ← A и D ← A. Отрезок D — C в дерево не входит и **не рисуется**: к C короче через B.
5. ломаные — от дальних узлов: C → B → A (5 км), затем D → A (3.16 км); узел, уже вошедший в ломаную, второй раз не рисуется;
6. стрелки — в узле, где путь перешёл очередную отметку: B (2 км, отметка 2), D (3.16, отметка 2), C (5, отметка 4); направление — от родителя. На настоящих дорогах вершины OSM идут через десятки метров, и стрелка стоит практически на отметке. Прореживание: клетка 0.6 × 5 = 3 км — две ветки пересекли отметку 5 км в 1 км друг от друга, вторая стрелка не ставится.
* **Слитый контур:** 12 297 колец леса → 3 246 (на 74 % меньше линий), 2.9 с при первом показе, дальше из памяти до смены файла участка.

## 5. Накопленные маршруты — дописыванием (13.5.11б)

**Где:** `view_qt/threat_view.py :: iter_show_accumulated`, `_acc_new_chunk`, `_acc_clear`.

**Суть простыми словами.** Прежде на каждый новый маршрут вся тетрадь переписывалась заново. Теперь маршруты пишутся страницами по 50, и новый дописывается на последнюю страницу — исписанные страницы не трогаются.

**Как работает.** Прежде на каждый новый маршрут склеивались и перерисовывались ВСЕ накопленные. Теперь маршруты лежат кусками по 50 (`ACC_CHUNK`): новый маршрут дописывается в текущий кусок, готовые не трогаются; выборку сменили (не продолжение по ссылкам) — рисуется с нуля.

```python
def iter_show_accumulated(self, routes):
    """Накопленные маршруты тонкими линиями — ДОПИСЫВАНИЕМ (13.5.11б): новые — в текущий кусок, готовые куски по
    `ACC_CHUNK` маршрутов не трогаются. Вход: маршруты (M,2) км; пустой — убрать. Отдаёт: ничего."""
    routes = list(routes or [])              # маршруты выборки, по порядку
    n = len(self._acc_routes)                # уже нарисовано
    # выборка росла с хвоста — те же объекты по порядку (`is`); иначе (сброс, новая выборка) — рисовать с нуля
    if n > len(routes) or any(a is not b for a, b in zip(self._acc_routes, routes)):
        self._acc_clear()
        n = 0
    new = routes[n:]                         # ещё не нарисованные маршруты
    i = 0                                    # сколько новых уже разложено по кускам
    while i < len(new):                      # новые — по кускам: текущий дополнить, полный — начать следующий
        if not self._acc_items or self._acc_n >= self.ACC_CHUNK:   # куска нет или он полон
            self._acc_new_chunk()
        take = new[i:i + self.ACC_CHUNK - self._acc_n]   # сколько влезет в текущий кусок
        for r in take:                       # маршрут — точки и разрыв NaN перед следующим
            a = np.asarray(r, float)         # точки маршрута, км
            self._acc_xs += [a[:, 0], self._NAN1]
            self._acc_ys += [a[:, 1], self._NAN1]
        self._acc_n += len(take)
        i += len(take)
        self._acc_items[-1].setData(np.concatenate(self._acc_xs), np.concatenate(self._acc_ys), connect="finite")
    self._acc_routes = routes
```

```python
def _acc_new_chunk(self):
    """Начать новый кусок накопленных линий. Вход: нет. Отдаёт: ничего."""
    it = self.pi.plot([], [], antialias=True, connect="finite",   # кусок линий: цвет и вид — как прежде
                      pen=pg.mkPen(_qcolor(THREAT_COLORS["route_iter"], 80), width=1.4))
    it.setZValue(1)
    self._acc_items.append(it)
    self._acc_xs, self._acc_ys, self._acc_n = [], [], 0
    self._reapply_opacity()                  # прозрачность группы «пролёт БПЛА» — и новому куску
```

```python
def _acc_clear(self):
    """Убрать все куски накопленных линий. Вход: нет. Отдаёт: ничего."""
    for it in self._acc_items:               # куски — со сцены
        self.pi.removeItem(it)
    self._acc_items, self._acc_routes = [], []
    self._acc_xs, self._acc_ys, self._acc_n = [], [], 0
```

**Пример.** 1 000 маршрутов — 20 кусков; новый маршрут трогает один кусок из ≤ 50 маршрутов, а не 155 тыс. точек.

**Пример с расчётом.** 1 000 маршрутов — 154 644 точки, в среднем ~155 на маршрут (замер журнала 360); суммы — оценка по формуле.
* **прежде:** маршрут n — склеить и отдать на отрисовку все n маршрутов; за прогон 1 + 2 + … + 1 000 = 500 500 маршрутов × 155 ≈ **77.6 млн точек**, последний шаг — 154 644 точки;
* **теперь:** маршрут n попадает в кусок ⌈n / 50⌉ и перерисовывает только его (≤ 50 маршрутов ≈ 7 750 точек); за кусок 1 + … + 50 = 1 275, за 20 кусков 25 500 маршрутов × 155 ≈ **3.95 млн точек** — в **19.6 раза** меньше, и работа на маршрут не растёт с длиной прогона.
