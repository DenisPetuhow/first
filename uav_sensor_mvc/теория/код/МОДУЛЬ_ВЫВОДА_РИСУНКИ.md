## 1. Снимок данных — `report_data`

**Где:** `src/model/threat/report_data.py :: report_data`; зовут `threat_controller.py :: on_report_data` (окна) и `docs/make_pk_pictures.py :: main` (Word).

**Суть простыми словами.** Все рисунки строятся из одного набора чисел, собранного в момент нажатия кнопки: весовая сетка, маршруты, средства с радиусами, объекты защиты, точки входа, нагрузка и разбивка по направлениям. Набор только читается из результатов расчёта, поэтому рисунки не могут изменить расстановку или показатели. Если выбрана одна цель, в набор попадают только маршруты к ней.

**Как работает.** `sensor_load(target)` проверяет номер цели (такой нет — все цели) и отдаёт его же в `target`; этот номер идёт в `routes_by_target` и `sector_stats` — нагрузка, маршруты и сектора всегда об одной выборке. Радиус средства — из паспорта типа (`sensor_types`; большой тип берёт `threat_R_big`) — тот же, которым считается засечка. Сетка отдаётся без копии (`np.asarray`).

<!-- код: src/model/threat/report_data.py::report_data -->
```python
def report_data(m, target=None):
    """Снимок модели для рисунков. Вход: `ThreatModel`, None — все цели, номер с нуля — маршруты одной цели.
    Отдаёт: dict(grid, bbox, routes, sensors, types, targets, entries, load, sectors, k, target, source)."""
    from model.placement.sensors import sensor_types
    g = m.grid                                       # весовая сетка; None — карта не построена
    grid = None if g is None else dict(weight=np.asarray(g.weight), ox=float(g.ox), oy=float(g.oy), h=float(g.h),
                                       nx=int(g.nx), ny=int(g.ny))   # сетка для фона
    bbox = None if g is None else tuple(map(float, g.extent_km()))   # рамка сетки, км
    load = m.sensor_load(target)                     # нагрузка: строки, выборка, названия; цели нет — все цели
    tgt = load.get("target")                         # номер цели, если такая есть; иначе None
    parts = m.routes_by_target() if len(m.target_points_km()) else []   # выборка по целям — как у «Анализа»
    routes = (parts[tgt] if tgt is not None else [r for p in parts for r in p])   # маршруты для рисунка, км
    types = {s.type_id: dict(name=s.name, r_km=float(s.r_km)) for s in sensor_types(m.p)}   # номер -> имя и радиус типа, км
    sensors = [dict(n=int(r["n"]), type_id=int(r["type_id"]), x_km=float(r["x_km"]), y_km=float(r["y_km"]),
                    r_km=types.get(int(r["type_id"]), {}).get("r_km", float(m.p.threat_R)))
               for r in m.sensors_table()]           # средства на карте с радиусом своего типа, км
    return dict(grid=grid, bbox=bbox, routes=list(routes), sensors=sensors, types=types,
                targets=[tuple(map(float, t)) for t in m.target_points_km()],
                entries=[tuple(map(float, e)) for e in np.asarray(m.entry_points_km(), float).reshape(-1, 2)],
                load=load, sectors=m.sector_stats(tgt), k=int(m.p.threat_k), target=tgt,
                source=load.get("source"))
```

## 2. Откуда числа: чей маршрут, откуда он заходит, сколько через средство

**Где:** `src/model/placement/targets.py :: route_target_index`; `threat_grid.py :: ThreatModel._approach_bearing`, `sector_stats`; нагрузка — `src/model/placement/sensor_load.py :: seen_matrix`, `load_rows` (разбор — [НАГРУЗКА_НА_СРЕДСТВО](НАГРУЗКА_НА_СРЕДСТВО.md)).

**Суть простыми словами.** Маршрут относится к той цели, у которой он заканчивается. Направление подлёта — сторона, с которой маршрут подходит к цели в самом конце, а не место старта: точки старта общие для целого сектора появления и почти не различают направления. Круг вокруг цели разбит на 12 секторов по 30°; в каждом считается, сколько маршрутов пришло и сколько из них засечено нужное число раз.

**Взаимодействие** — кто кого зовёт и что передаёт (вложенность — вызов, справа — что отдаёт):

```text
report_data(модель, цель)                 → снимок для рисунков; зовут on_report_data и calc (§1)
├─ sensor_load(цель)                      → нагрузка на средства (разбор НАГРУЗКА_НА_СРЕДСТВО)
│  └─ load_rows(таблица, seen_matrix(…))  → строки «средство · маршрутов через зону · %»
└─ sector_stats(цель)                     → 12 секторов по 30°: пришло, засечено ≥ k
   ├─ routes_by_target()[цель]            → маршруты этой цели; цель не задана — _sample_for_sensors(), вся выборка
   ├─ route_target_index(маршрут, цели)   → номер цели, у которой маршрут кончается
   ├─ _approach_bearing(маршрут, цель)    → азимут захода, ° (0° — север, по часовой);
   │                                        сектор = round(азимут / 30) % 12
   └─ _meets_k(засечки)                   → засечён ≥ k раз — то же правило, что «Засечено ≥ k»
дальше: снимок["load"] → draw_load (рис. 8, §5) · снимок["sectors"] → draw_sectors (рис. 9, §6)
```

**Как работает.** `route_target_index` — цель, ближайшая к последней точке. `_approach_bearing` идёт по точкам с конца и берёт первую дальше `THREAT_COMPASS_APPROACH_KM` = 0.5 км от цели; азимут `atan2(dx, dy)` — 0° север, по часовой. Сектор — `round(θ / 30) % 12`. «Прошёл через средство» — то же выражение, что засечка «Аналитики»; «≥ k» — `_meets_k`.

<!-- код: src/model/placement/targets.py::route_target_index -->
```python
def route_target_index(route, points):
    """Чья цель у маршрута: ближайшая к его КОНЦУ — маршрут кончается в ячейке цели.
    Вход: маршрут (M, 2) км, места целей [(x, y)]. Отдаёт: номер с нуля (0 — цель одна)."""
    if len(points) <= 1:                           # цель одна — спрашивать нечего
        return 0
    pts = np.asarray(points, float)                # места целей, км
    end = np.asarray(route[-1], float)             # конец маршрута, км
    return int(np.argmin(np.hypot(pts[:, 0] - end[0], pts[:, 1] - end[1])))
```

<!-- код: src/model/threat/threat_grid.py::ThreatModel._approach_bearing -->
```python
@staticmethod
def _approach_bearing(route, target_xy):
    """Азимут ОТ ЦЕЛИ на КОНЕЧНУЮ часть маршрута — направление ЗАХОДА, а не старта
    (см. `sector_stats`). Идёт по точкам маршрута С КОНЦА и берёт первую, что дальше
    `THREAT_COMPASS_APPROACH_KM` от цели; `None` — весь маршрут ближе этого порога
    (вырожденный случай, короче одной клетки сетки)."""
    B = np.asarray(target_xy, float)
    for p in route[::-1]:
        d = np.asarray(p, float) - B
        if np.hypot(d[0], d[1]) >= THREAT_COMPASS_APPROACH_KM:
            return float(np.degrees(np.arctan2(d[0], d[1])) % 360.0)
    return None
```

<!-- код: src/model/threat/threat_grid.py::ThreatModel.sector_stats -->
```python
def sector_stats(self, target=None):
    """Приход БПЛА по 12 направлениям компаса (шаг 30°, по ЗАХОДУ на свою цель). Вход:
    None — вся выборка, номер цели — её маршруты. Отдаёт: 12 × dict(deg, n_routes,
    n_zero, n_ge1, n_ge_k, k, ok); ok=False — кратности не хватило (красным)."""
    # План 8, задача 8.9, довесок 06.09.2026 (кнопка «Анализ моделирования»).
    # Направление — азимут ОТ ЦЕЛИ на КОНЕЧНУЮ часть маршрута: 0° = север (+y), по
    # часовой (90° = восток, +x); сектор k — [k·шаг − шаг/2, k·шаг + шаг/2).
    # ⚠️ ИМЕННО ЗАХОД, А НЕ СТАРТ (исправлено 06.09.2026, заказчик: «смотреть конечную
    # точку захода на цель»): старт общий на весь сектор появления, и азимут от него
    # стягивался в 3–5 секторов из 12. `_approach_bearing` идёт С КОНЦА, пока не
    # отойдёт от цели на `THREAT_COMPASS_APPROACH_KM` — последняя точка лежит В цели.
    # Кратность — по тому же правилу, что «Засечено ≥ k» (`_meets_k`): при «одна на всех»
    # общая по всем типам, иначе — хоть один тип своими датчиками (В13.13, 23.09.2026).
    step = float(THREAT_COMPASS_STEP_DEG)
    n_sec = max(1, int(round(360.0 / step)))
    out = [dict(deg=int(round(i * step)), n_routes=0, n_zero=0, n_ge1=0, n_ge_k=0,
                k=int(self.p.threat_k), ok=True) for i in range(n_sec)]
    # `target` (план 13, 23.09.2026): None — вся выборка, номер — только маршруты к этой цели
    sample = (self._sample_for_sensors() if target is None
              else self.routes_by_target()[int(target)])
    if not sample or not len(self.sensors):
        return out
    tpts = self.target_points_km()               # цели (план 13), км
    seen_all = seen_matrix(sample, self.sensors, self._sensor_radii())   # какие датчики видят маршрут
    for r, seen in zip(sample, seen_all):        # маршрут и датчики, что его видят
        # направление подхода — к СВОЕЙ цели маршрута, а не к первой (план 13, 13.14)
        B = np.asarray(tpts[route_target_index(r, tpts)], float)
        bearing = self._approach_bearing(r, B)
        if bearing is None:
            continue                  # маршрут целиком лежит в цели — без направления
        idx = int(round(bearing / step)) % n_sec
        hits = int(seen.sum())
        e = out[idx]
        e["n_routes"] += 1
        e["n_zero"] += int(hits == 0)
        e["n_ge1"] += int(hits >= 1)
        e["n_ge_k"] += int(self._meets_k(seen[None, :])[0])   # то же правило, что у «≥ k»
    for e in out:
        e["ok"] = (e["n_routes"] == 0) or (e["n_ge_k"] == e["n_routes"])
    return out
```

## 3. matplotlib в коде: лист, оси, элементы, холст; настройки и шрифт

**Где:** `src/view_qt/output/figures.py :: WORD_COLORS` … `MAP_PRESETS`, `_opts`, `_rc`, `_ticks`, `_color`, `_empty`; холсты — `figure_base.py` (окно — `FigureCanvasQTAgg`, PNG — `FigureCanvasAgg`).

**Суть простыми словами.** Библиотека рисует в три уровня: лист заданного размера, на нём оси со своей системой координат, на осях — отдельные элементы: растр, линии, круги, столбцы, подписи. Каждый элемент хранит данные в километрах и оформление, а в пиксели всё переводится только при отрисовке. Поэтому один набор элементов показывается в окне любого размера и записывается в файл любого размера и разрешения. Настройки рисунка — набор именованных значений; чего в нём нет, берётся из умолчаний, повторяющих рисунки Word.

**Как работает.** Объекты matplotlib, которыми пользуется код:

| объект | что это | где у нас |
|---|---|---|
| `Figure` | лист: размер в дюймах, разрешение (dpi), раскладка полей (`layout="constrained"`) | окно — `self.fig`; PNG — свой `Figure(figsize=…)`; Word — `plt.figure` |
| `Axes` (`fig.add_subplot`) | оси: пределы в км, подписи, деления; `projection="polar"` — угол и радиус | все рисунки; рис. 9 — полярные |
| `AxesImage` (`ax.imshow`) | растр в прямоугольнике `extent`; числа → цвет нормировкой и палитрой | веса, тайлы, своя карта |
| `LineCollection` | много ломаных одним элементом | маршруты |
| `Circle`, `Rectangle` (`ax.bar`) | фигуры в единицах данных | зоны (км), столбцы, лепестки |
| `Line2D` (`ax.plot`) | значки в пунктах, пунктир | средства, цели, точки входа, средняя |
| `Text`, `Legend`, `Colorbar` | подписи, легенда, шкала цвета | номера, типы, шкала весов |
| `FigureCanvasAgg` | рисовальщик Agg (C++): буфер RGBA → PNG | «Сохранить PNG…», Word |
| `FigureCanvasQTAgg`, `NavigationToolbar2QT` | тот же Agg в виджете Qt, панель масштаба | окно |
| `rc_context`, `colormaps`, `Affine2D`, `FuncFormatter` | шрифт на время, палитры, своё преобразование, подписи делений | `_rc`, `_weights`, `_background`, `draw_sectors` |

Точка проходит цепочку **км (данные) → доли осей → доли листа → пиксели**; первое звено — пределы осей (`set_xlim`, `set_ylim`), поэтому рамка рисунка меняется без пересчёта данных. `pyplot` в программе **не используется**: у него общее состояние на весь процесс, а окна «Аналитики» живут одновременно — рисунок создаётся `Figure()`, холст прикрепляется явно. Шрифт: `_rc` — на время построения; подписи делений matplotlib создаёт уже при отрисовке, вне `rc_context`, — им семейство задаёт `_ticks`.

## 4. Карта — `draw_map`, `_weights`, `_background` (рисунки 5–7, «Поверх подложки»)

**Где:** `src/view_qt/output/figures.py :: draw_map`, `_weights`, `_background`, `_grid_ext`; готовые виды — `MAP_PRESETS`.

**Суть простыми словами.** Карта собирается слоями снизу вверх: фон местности, весовая сетка, маршруты, зоны средств, значки и подписи. Весовая сетка раскрашивается палитрой по шкале до 97-й процентили, чтобы редкие очень тяжёлые ячейки не сделали остальной рисунок одноцветным; слабые ячейки можно сделать прозрачными — тогда сквозь них видна местность. Рамка рисунка вычисляется по нарисованному до того, как положен фон: фон всегда шире района и иначе раздвинул бы рисунок.

**Как работает.** `_weights`: `clip` минусов → перцентиль → маска `masked_less_equal` → палитра с прозрачным «плохим» цветом → `imshow(origin="lower", extent=…)` (строка 0 — юг). Маршруты — одна `LineCollection`. Зоны — `Circle` в км (растут с картой), значки — `plot` в пунктах (не растут). Слои — `zorder`: фон 0 → веса 1 → маршруты 2 → зоны 3 → значки 8 → цели 9. `_background`: тайлы — `imshow` по рамке склейки; своя карта — `imshow` с преобразованием `Affine2D(…) + transData`. Рамка: `autoscale_view` → пределы → фон → пределы обратно; `set_aspect("equal")` — 1 км по X равен 1 км по Y, круг не становится эллипсом.

<!-- код: src/view_qt/output/figures.py::_grid_ext -->
```python
def _grid_ext(g):
    """Рамка весовой сетки. Вход: dict сетки (ox, oy, h, nx, ny). Отдаёт: (x0, x1, y0, y1) км."""
    return (g["ox"], g["ox"] + g["nx"] * g["h"], g["oy"], g["oy"] + g["ny"] * g["h"])
```

<!-- код: src/view_qt/output/figures.py::_weights -->
```python
def _weights(ax, g, o):
    """Весовая сетка: шкала до 97-го перцентиля, слабые ячейки по выбору прозрачны. Вход: оси, сетка, настройки.
    Отдаёт: растр (для шкалы цвета)."""
    w = np.clip(np.asarray(g["weight"], float), 0.0, None)   # вес без минусов — для показа
    vmax = float(np.percentile(w[w > 0], 97)) if (w > 0).any() else 1.0   # верх шкалы — 97-й перцентиль, как в Word
    if o["hide_low"]:                                # слабые ячейки — насквозь: под ними видна карта
        w = np.ma.masked_less_equal(w, vmax * float(o["weights_cut"]) / 100.0)
    cmap = colormaps[o["cmap"]].copy()               # палитра весов
    cmap.set_bad(alpha=0.0)                          # спрятанные ячейки — прозрачны
    return ax.imshow(w, origin="lower", extent=_grid_ext(g), cmap=cmap, alpha=float(o["weights_alpha"]),
                     vmin=0, vmax=vmax, zorder=1)
```

<!-- код: src/view_qt/output/figures.py::_background -->
```python
def _background(ax, snap, o):
    """Фон под рисунком: подложка-тайлы или своя карта (с поворотом и перекосом). Вход: оси, снимок (basemap —
    (rgba, рамка км); own_map — (rgba, коэф. QTransform)), настройки. Отдаёт: True — фон положен."""
    a = float(o["bg_alpha"])                         # непрозрачность фона
    if o["background"] == "tiles" and snap.get("basemap") is not None:   # подложка: строка 0 — юг
        rgba, ext = snap["basemap"]                  # картинка и её рамка, км
        ax.imshow(rgba, origin="lower", extent=ext, alpha=a, zorder=0)
        return True
    if o["background"] == "own" and snap.get("own_map") is not None:   # своя карта по аффинной привязке
        rgba, (m11, m12, m21, m22, dx, dy) = snap["own_map"]   # картинка и привязка: пиксель -> км
        h, w = rgba.shape[:2]                        # размер картинки, пикс.
        tr = Affine2D.from_values(m11, m12, m21, m22, dx, dy) + ax.transData   # x' = m11·x + m21·y + dx (Qt)
        ax.imshow(rgba, origin="lower", extent=(0, w, 0, h), alpha=a, zorder=0, transform=tr)
        return True
    return False
```

def draw_map(fig, snap, opts=None, colors=None):
    """Рисунки 5–7 — карта района: фон, весовая сетка, маршруты, средства с зонами, цели, точки входа.

    snap = snap or {}                                # снимок данных
    fig.clear()
    with _rc(o):
        ax = fig.add_subplot()                       # оси рисунка
        g = snap.get("grid")                         # весовая сетка или None
        if g is None and not snap.get("routes"):     # ни карты, ни маршрутов

**Где:** `src/view_qt/output/figures.py :: draw_load`; порядок строк — `sensor_load.py :: sort_rows`, `ORDERS`.

**Суть простыми словами.** Столбец на каждое средство — какая доля маршрутов прошла через его зону. Столбцы окрашены по типу средства, под столбцом — номер средства по списку, порядок — тот же, что в таблице нагрузки. По выбору — числа у столбцов, средняя линия и шкала до 100 %, чтобы рисунки разных расчётов можно было сравнить.

**Как работает.** Фильтр типа → `sort_rows` → `bar` (или `barh`) на местах 0 … N − 1 с подписями-номерами → `bar_label` (числа) → `axhline` (средняя) → `set_ylim(0, 105)` (шкала до 100 %) → легенда из заглушек `Line2D` по типам на рисунке.

```python
def draw_load(fig, load, opts=None, colors=None):
    """Рисунок 8 — нагрузка на каждое средство столбцами. Вход: рисунок, снимок `sensor_load` (rows, names),
    настройки (`LOAD_DEFAULTS`), {тип: цвет} или None — цвета Word. Отдаёт: оси."""
    o = _opts(LOAD_DEFAULTS, opts)                   # настройки рисунка
    fig.clear()
    with _rc(o):
        ax = fig.add_subplot()                       # оси рисунка
        rows = list((load or {}).get("rows", []))    # строки нагрузки
        if o["type"] is not None:                    # выбран тип — только его средства
            rows = [r for r in rows if r["type_id"] == int(o["type"])]
        rows = sort_rows(rows, o["order"])
        if not rows:                                 # рисовать нечего
            _empty(ax, "Нагрузки нет: нет маршрутов или средств на карте.")
            return ax
        pos = np.arange(len(rows))                   # места столбцов
        val = np.array([r["load_pct"] for r in rows], float)   # нагрузка, %
        col = [_color(colors, r["type_id"]) for r in rows]     # цвет столбца — по типу
        labels = [str(r["n"]) for r in rows]         # подписи — номера по списку
        if o["horizontal"]:                          # горизонтальные столбцы — длинный список читается сверху вниз
            bars = ax.barh(pos, val, color=col)      # столбцы — для подписей чисел
            ax.set_yticks(pos)
            ax.set_yticklabels(labels)
            ax.invert_yaxis()
            ax.set_ylabel("номер средства"); ax.set_xlabel("нагрузка, %")
        else:                                        # вертикальные — как рисунок Word
            bars = ax.bar(pos, val, color=col)       # столбцы — для подписей чисел
            ax.set_xticks(pos)
            ax.set_xticklabels(labels)
            ax.set_xlabel("номер средства"); ax.set_ylabel("нагрузка, %")
        if o["full_scale"]:                          # шкала всегда до 100 % — рисунки сравнимы между собой
            (ax.set_xlim if o["horizontal"] else ax.set_ylim)(0, 105)
        if o["values"]:                              # числа у концов столбцов
            ax.bar_label(bars, fmt="%.0f", padding=2, fontsize=max(6.0, float(o["font"]) - 3))
        if o["mean"]:                                # средняя нагрузка пунктиром
            mv = float(val.mean())                   # средняя нагрузка, %
            line = ax.axvline if o["horizontal"] else ax.axhline   # линия поперёк столбцов
            line(mv, color="#555555", ls="--", lw=1.0, label="средняя %.1f %%" % mv)
        if o["grid"]:                                # сетка вдоль шкалы нагрузки
            ax.grid(axis="x" if o["horizontal"] else "y", alpha=0.3)
            ax.set_axisbelow(True)
        if o["legend"]:                              # легенда — по типам на рисунке
            names = (load or {}).get("names", {})    # номер типа -> название
            hs = [Line2D([], [], marker="s", ls="", color=_color(colors, t), label=names.get(t, "тип %d" % t))
                  for t in sorted({r["type_id"] for r in rows})]   # значок типа
            if o["mean"]:                            # и пунктир средней
                hs.append(Line2D([], [], color="#555555", ls="--", label="средняя %.1f %%" % float(val.mean())))
            ax.legend(handles=hs, fontsize=max(6.0, float(o["font"]) - 2))
        if o["title"]:                               # заголовок задан
            ax.set_title(o["title"])
        _ticks(ax, o)
    return ax
```

* средняя: сумма 35 нагрузок / 35 = **26,0 %**; большие средства (№32–35) — по 100 %: их зоны (15 км) накрывают цель, куда приходят все маршруты;

## 6. Направления — `draw_sectors` (рисунок 9)

**Где:** `src/view_qt/output/figures.py :: draw_sectors`; данные — `sector_stats` (§2).

**Суть простыми словами.** Двенадцать лепестков по направлениям захода на цель: длина серого — сколько маршрутов пришло с этой стороны, зелёного — сколько из них засечено нужное число раз. Где серый выступает из-под зелёного, средств не хватает. Можно показать доли от всей выборки вместо штук и подписать «засечено / всего».

**Как работает.** `add_subplot(projection="polar")`, ноль угла — север (`set_theta_zero_location("N")`), по часовой (`set_theta_direction(-1)`). Лепестки — `bar(θ, r, width)` слоями от большего к меньшему: серый → светло-зелёный (≥ 1) → зелёный (≥ k); «без засечки» стоит на светло-зелёном (`bottom=n_ge1`); недобор — пустой лепесток с красным краем (`fill=False`). Доля — множитель 100 / Σn и подписи делений `FuncFormatter`.

<!-- код: src/view_qt/output/figures.py::draw_sectors -->
```python
def draw_sectors(fig, stats, opts=None):
    """Рисунок 9 — маршруты и засечка по 12 направлениям подлёта (полярная диаграмма, север сверху, по часовой).
    Вход: рисунок, строки `sector_stats`, настройки (`SECTOR_DEFAULTS`). Отдаёт: оси."""
    o = _opts(SECTOR_DEFAULTS, opts)                 # настройки рисунка
    fig.clear()
    with _rc(o):
        ax = fig.add_subplot(projection="polar")     # полярные оси
        ax.set_theta_zero_location("N"); ax.set_theta_direction(-1)
        stats = list(stats or [])                    # строки секторов
        n = np.array([e["n_routes"] for e in stats], float)   # маршрутов в секторе
        if not len(n) or n.sum() <= 0:               # рисовать нечего
            _empty(ax, "Маршрутов по направлениям нет: нет выборки или средств на карте.")
            return ax
        th = np.radians([e["deg"] for e in stats])   # азимуты секторов, рад
        g1 = np.array([e["n_ge1"] for e in stats], float)    # засечено хоть раз
        gk = np.array([e["n_ge_k"] for e in stats], float)   # засечено с кратностью k
        sc = 100.0 / n.sum() if o["share"] else 1.0  # множитель шкалы: доля от всей выборки, % — или штуки
        w = np.radians(float(o["width"]))            # ширина столбца, рад
        if o["routes"]:                              # все маршруты сектора — серым
            ax.bar(th, n * sc, width=w, color="#cccccc", label="маршрутов")
        if o["ge1"]:                                 # засечено хоть раз — светло-зелёным
            ax.bar(th, g1 * sc, width=w, color="#a6d96a", label="засечено ≥ 1")
        if o["gek"]:                                 # засечено с кратностью — зелёным
            ax.bar(th, gk * sc, width=w, color="#2ca02c", label="засечено ≥ k")
        if o["zero"]:                                # не засечено ни разу — красным, у края столбца
            ax.bar(th, (n - g1) * sc, bottom=g1 * sc, width=w, color="#d62728", label="без засечки")
        if o["short"]:                               # сектора, где кратности не хватило, — красной рамкой
            bad = np.array([not e.get("ok", True) for e in stats])   # сектор с недобором
            if bad.any():                            # есть такие сектора
                ax.bar(th[bad], n[bad] * sc, width=w, fill=False, edgecolor="#d62728", lw=1.6,
                       label="кратности не хватает")
        if o["values"]:                              # «засечено ≥ k / всего» у конца столбца
            pad = 0.06 * float(n.max() * sc)         # отступ подписи от столбца
            for a, nn, kk in zip(th, n, gk):         # сектор за сектором
                if nn > 0:                           # пустые сектора без подписи
                    ax.text(a, nn * sc + pad, "%d/%d" % (kk, nn), ha="center", va="center",
                            fontsize=max(6.0, float(o["font"]) - 3))
        if o["share"]:                               # шкала в процентах
            ax.yaxis.set_major_formatter(FuncFormatter(lambda v, _p: "%g %%" % v))
        if o["legend"]:                              # легенда под диаграммой слева — как в Word
            ax.legend(loc="lower left", bbox_to_anchor=(-0.1, -0.12), fontsize=max(6.0, float(o["font"]) - 2))
        if o["title"]:                               # заголовок задан
            ax.set_title(o["title"], pad=18)
        _ticks(ax, o)
    return ax
```

**Пример с расчётом.** 
* ширина лепестка 28° = 28 × π / 180 = **0,4887** рад — зазор 2° из 30°;
* сектор 120°: θ = 120 × π / 180 = 2,094 рад; серый 287, зелёный 285 → кромка 2 маршрута — недобор;
* «доля от выборки»: 287 × 100 / 1 000 = **28,7 %**; подпись «285/287».

| Где легко сломать | Почему |
|---|---|
| ноль угла по умолчанию | у matplotlib 0° — восток и против часовой: азимуты повернутся на 90° и пойдут в обратную сторону |
| зелёный нарисовать раньше серого | зелёный закроется серым |

## 7. Окно с рисунком — `FigureDialog`

**Где:** `src/view_qt/output/figure_base.py :: FigureDialog`, `_value`.

**Суть простыми словами.** Окно — панель настроек слева и рисунок справа. Любая настройка перерисовывает рисунок целиком с короткой задержкой, чтобы не перерисовывать на каждый щелчок счётчика. Данные берутся один раз — при открытии или по кнопке «Обновить данные»; файл PNG строится заново в заданном размере, а не снимается с экрана.

**Как работает.** Помощники `_add_check`, `_add_spin`, `_add_combo`, `_add_color` кладут виджет в форму и в словарь `_w` под ключом настройки; `opts()` читает их через `_value`. Смена → `QTimer` 150 мс → `redraw` → `_draw_into` (цвета «как на карте» или «как в Word») → `draw_idle`. `set_opts` выставляет готовый вид с заблокированными сигналами — одна перерисовка вместо двадцати. `save_png` — новый `Figure` + `FigureCanvasAgg`, `layout="constrained"`, `savefig(dpi)`: размер файла ровно заданный.

<!-- код: src/view_qt/output/figure_base.py::_value -->
```python
def _value(w):
    """Значение виджета настройки. Вход: виджет. Отдаёт: bool, число, данные строки списка, текст или цвет."""
    if isinstance(w, QtWidgets.QCheckBox):           # галка
        return w.isChecked()
    if isinstance(w, (QtWidgets.QSpinBox, QtWidgets.QDoubleSpinBox)):   # число
        return w.value()
    if isinstance(w, QtWidgets.QComboBox):           # список — данные строки (None — «все»)
        return w.currentData()
    if isinstance(w, QtWidgets.QLineEdit):           # текст
        return w.text().strip()
    return w.property("color")                       # кнопка цвета
```

<!-- код: src/view_qt/output/figure_base.py::FigureDialog._add -->
```python
def _add(self, key, label, w, signal):
    """Положить виджет в форму и в настройки; смена — перерисовка. Вход: ключ, подпись (None — без), виджет,
    сигнал смены. Отдаёт: виджет."""
    self._w[key] = w
    signal.connect(lambda *_a: self._timer.start())
    if label is None:                            # галка — подпись в ней самой
        self.form.addRow(w)
    else:
        self.form.addRow(label, w)
    return w
```

```python
def set_opts(self, values):
    """Выставить настройки разом (готовый вид), без лишних перерисовок. Вход: {ключ: значение}. Отдаёт: ничего."""
    for k, v in values.items():                  # настройка за настройкой
        w = self._w.get(k)                       # её виджет; нет — настройка не из этого окна
        if w is None:                            # чужая настройка — пропустить
            continue
        w.blockSignals(True)
        if isinstance(w, QtWidgets.QCheckBox):   # галка
            w.setChecked(bool(v))
        elif isinstance(w, QtWidgets.QSpinBox):   # целое — PyQt5 дробное не примет
            w.setValue(int(round(v)))
        elif isinstance(w, QtWidgets.QDoubleSpinBox):   # дробное
            w.setValue(float(v))
        elif isinstance(w, QtWidgets.QComboBox):   # список — по данным строки
            w.setCurrentIndex(max(0, w.findData(v)))
        elif isinstance(w, QtWidgets.QLineEdit):   # текст
            w.setText(str(v))
        else:                                    # кнопка цвета
            self._paint_color(w, v)
        w.blockSignals(False)
    self._timer.start()
```

def save_png(self, path=None):
    """«Сохранить PNG…»: рисунок заново в заданном размере (см) и разрешении. Вход: путь или None — спросить.
    Отдаёт: путь записанного файла или None."""
    if path is None:                             # путь не задан — окно выбора файла
        name = "%s_%s.png" % (self.FILE, datetime.datetime.now().strftime("%Y%m%d_%H%M"))   # имя по умолчанию

        if not path:                             # человек передумал
            return None
    if not path.lower().endswith(".png"):        # расширение не указали
        path += ".png"
    fig = Figure(figsize=(self.png_w.value() / 2.54, self.png_h.value() / 2.54), layout="constrained")   # файл, дюймы
    FigureCanvasAgg(fig)
    try:
        self._draw_into(fig)
        fig.savefig(path, dpi=self.png_dpi.value())
    except Exception as e:                       # не записалось — сказать, где
        self.lbl_info.setText("<br>".join(self._info() + ["<b>Ошибка записи: %s</b>" % e]))
        return None
    self.lbl_info.setText("<br>".join(self._info() + ["<b>Записано: %s</b>" % path]))
    return path

def _on_snapshot(self):
    """Новый снимок — список типов заново (выбор сохраняется, если тип есть). Отдаёт: ничего."""
    load = self._snap.get("load") or {}          # снимок нагрузки

## 9. Подложка — тайлы, склейка, выпрямление по широте

**Где:** `map_figure_window.py :: _TilesTask.run`, `MapFigureDialog._tiles_box`, `_tiles_for`, `_tiles_ready`; `analytics_open.py :: basemap`, `straighten_rows`; `geomap.py :: deg2num`, `_pick_zoom`, `build_raster_basemap`.

**Суть простыми словами.** Карта местности приходит квадратами-тайлами из кэша участка (или из сети, если она разрешена) в проекции, где высота строки растёт к северу. Квадраты склеиваются в одну картинку, после чего каждая её строка переносится на ту широту, где она лежит на самом деле, — иначе середина карты съезжает относительно расчётных слоёв. Сборка идёт в фоне, окно перерисовывается, когда картинка готова.

**Как работает.** `_tiles_box` — район плюс самая большая зона и 1 км (или рамка вида); `_tiles_for` — такая рамка уже собрана → картинка, иначе поток `_TilesTask` → `basemap` → `build_raster_basemap`: уровень `_pick_zoom` ≈ 1 : 1 к 2 400 пикс., не больше 192 тайлов, до 8 загрузок разом, кэш декодированных тайлов на 512 штук → `straighten_rows` → сигнал → `_tiles_ready` → `redraw`. Программа считает в км, линейных по широте (`geo_frame.py`: y = (φ − φ₀) · 110,574), а строки тайлов равномерны по Меркатору m = asinh(tan φ) — отсюда выпрямление; столбцы линейны по долготе и там и тут.

```python
def deg2num(lon, lat, z):
    """(долгота, широта, зум) -> дробные тайловые координаты (xt, yt)."""
    n = 2.0 ** z
    xt = (lon + 180.0) / 360.0 * n
    lat_r = math.radians(lat)
    yt = (1.0 - math.asinh(math.tan(lat_r)) / math.pi) / 2.0 * n
    return xt, yt
```

```python
def _pick_zoom(lon_min, lon_max, zmin=ZOOM_MIN, zmax=ZOOM_MAX,
               target_px=None, min_tiles_x=2.0):
    """Зум, при котором тайлы отображаются ~1:1 к экрану (родной размер подписей).

    История: сначала было размытие (брали слишком НИЗКИЙ зум — мозаика меньше экрана,
    её растягивали). Потом перегнули в другую сторону: брали ПЕРВЫЙ зум, где мозаика
    уже ≥ экрана. Но тайлов на уровень вдвое больше, поэтому «первый ≥» давал мозаику
    до 2× шире экрана — её ужимали вдвое, и ПОДПИСИ на тайлах становились вдвое мельче
    и гуще (симптом «замельчает», не как в обычном OSM).

    Правильно — как в слиппи-картах: подобрать зум, при котором ширина мозаики в
    пикселях БЛИЖЕ ВСЕГО к ширине виджета (масштаб ≈ 1:1). Тогда подписи отрисованы
    в их «родном» размере. Выбираем z с минимальным |log2(nx) − log2(need)|.

    target_px — ЛОГИЧЕСКАЯ ширина виджета в px (без домножения на DPR: важнее верный
    размер подписей, чем субпиксельная чёткость на HiDPI — при необходимости обычные
    OSM-тайлы всё равно не дают retina-варианта).
    need — целевое число тайлов по 256 px, чтобы покрыть экран в масштабе 1:1.
    """
    span = max(lon_max - lon_min, 1e-6)
    need = max(min_tiles_x, (target_px / 256.0) if target_px else 4.0)
    best, best_err = zmin, float("inf")
    for z in range(zmin, zmax + 1):
        nx = deg2num(lon_max, 0, z)[0] - deg2num(lon_min, 0, z)[0]
        err = abs(math.log2(max(nx, 1e-9)) - math.log2(need))    # отклонение от 1:1 (в октавах)
        if err < best_err:
            best, best_err = z, err
    return best
    return best                              # даже zmax не дотянул — берём самый чёткий
```

```python
def straighten_rows(rgba, ext, lat0):
    """Строки мозаики тайлов — из Меркатора в км района: строка встаёт на свою широту. Вход: rgba (строка 0 — юг),
    рамка (x0, x1, y0, y1) км, широта якоря. Отдаёт: новый rgba того же размера."""
    from model.threat.geo_frame import KM_PER_DEG_LAT
    # Строки тайлов равномерны по Меркатору m = asinh(tan φ), а км района — по широте: прямоугольник сдвигал
    # середину на 0,59 км (замер 07.10.2026). Столбцы трогать не нужно — и там, и тут они линейны по долготе.
    h = rgba.shape[0]                                # строк в мозаике
    lat_lo, lat_hi = lat0 + ext[2] / KM_PER_DEG_LAT, lat0 + ext[3] / KM_PER_DEG_LAT   # широты нижнего и верхнего края
    m_lo, m_hi = (np.arcsinh(np.tan(np.radians(v))) for v in (lat_lo, lat_hi))   # они же в Меркаторе
    lat = lat_lo + (lat_hi - lat_lo) * (np.arange(h) + 0.5) / h   # широта центра каждой новой строки
    src = (np.arcsinh(np.tan(np.radians(lat))) - m_lo) / (m_hi - m_lo) * h - 0.5   # её место в мозаике, строки
    return rgba[np.clip(np.rint(src).astype(int), 0, h - 1)]
```

def _tiles_for(self, o):
    """Подложка для рисунка; нет — запустить сборку в потоке. Вход: настройки. Отдаёт: (rgba, рамка) или None."""
    box = self._tiles_box(o)                     # нужная рамка, км

    if t["box"] == box and t["state"] in ("done", "none", "loading"):   # уже есть, нет тайлов или собирается
        return t["res"] if t["state"] == "done" else None
    t.update(box=box, res=None, state="loading")
    QtCore.QThreadPool.globalInstance().start(_TilesTask(self._basemap_fn, box, TILES_PX, self._sig))
    return None

def own_map(view):
    """Своя карта вкладки фоном. Вход: вид. Отдаёт: (rgba, (m11, m12, m21, m22, dx, dy) — пиксель -> км),
    «vector» — карта векторная (растра нет), None — не загружена."""
    if getattr(view, "map_svg_item", None) is not None:   # векторная своя карта
        return "vector"
    it = getattr(view, "map_img_item", None)         # растровая своя карта

        return None

    return np.asarray(it.image), (t.m11(), t.m12(), t.m21(), t.m22(), t.dx(), t.dy())

## 11. Рисунки и снимки для Word

**Где:** `docs/make_pk_pictures.py :: calc`, `_save`, `_box`, `_arrow`, `fig_structure`, `fig_stages`, `_fig_map`, `fig_weight` … `fig_compass`, `_shot_windows`, `shot`; `docs/make_pk_description_docx.py :: Doc.figure`, `main`.

**Суть простыми словами.** Документ собирается в два шага: сначала расчёт примера, рисунки и снимки окон, а числа расчёта записываются в файл; затем текст документа строится по этим числам и вставляет рисунки. Рисунки 5–9 рисуют те же функции, что окна программы. Снимки окон делаются без экрана на той же модели, что посчитала рисунки, поэтому текст, рисунки и снимки согласованы.

**Как работает.** `calc` → `report_data` → `_fig_map` с видами «Рис. 5/6/7», `fig_load`, `fig_compass` → `_save` (170 dpi, поля обрезаются по содержимому — `bbox_inches="tight"`). Схемы 1–2: оси без делений, координаты — доли листа 0 … 1, `_box` — скруглённый прямоугольник с текстом, `_arrow` — стрелка `annotate`. `shot`: Qt `offscreen` и `QT_QPA_FONTDIR` (без него снимки без букв), вкладка на модели примера, отрисовка как по окончании «Пакетно», `grab()`; два окна одного рисунка — склейка `QPainter` с зазором 16 пикс. → `числа.json`. `Doc.figure` — `add_picture(width=Cm(…))`, счётчик рисунков, подпись «Рисунок N — …»; `main` — файл занят Word → код 1.

def _box(ax, x, y, w, h, text, fc):
    """Прямоугольник схемы с текстом по центру. Вход: оси, угол, размеры (доли), текст, цвет. Отдаёт: ничего."""

def _arrow(ax, x0, y0, x1, y1, text=""):

def _shot_windows(app, v):
    """Снимки немодальных окон вкладки 3: открыть методом вида, снять, два окна склеить рядом.
    Вход: QApplication, вид вкладки 3. Отдаёт: dict файл -> путь (не снялся — нет в словаре)."""
    from PyQt5.QtGui import QColor, QPainter, QPixmap
    out = {}                                         # файл -> путь снимка
    for fname, *wins in WINDOWS:                     # рисунок за рисунком
        pms = []                                     # снимки окон этого рисунка
        for meth, attr in wins:                      # окно за окном
            try:
                getattr(v, meth)()
            except Exception as e:                   # окно не открылось — рисунок без него
                print("окно %s не открылось: %s" % (meth, e))
                continue
            for _ in range(25):                      # дорисовать окно
                app.processEvents(); time.sleep(0.02)
            dlg = getattr(v, attr, None)             # открытое окно
            if dlg is not None:                      # окно есть — снять
                pms.append(dlg.grab())
        if not pms:                                  # ни одно окно не снялось
            continue
        gap = 16                                     # зазор между окнами, px
        canvas = QPixmap(sum(pm.width() for pm in pms) + gap * (len(pms) - 1), max(pm.height() for pm in pms))   # общий снимок
        canvas.fill(QColor("white"))
        qp = QPainter(canvas); x = 0                 # рисовальщик и левый край очередного окна, px
        for pm in pms:                               # окна слева направо
            qp.drawPixmap(x, 0, pm); x += pm.width() + gap
        qp.end()
        path = os.path.join(OUT, fname)              # путь снимка
        if canvas.save(path):                        # записался — в отчёт
            out[fname] = path
        for _meth, attr in wins:                     # закрыть окна рисунка
            if getattr(v, attr, None) is not None:   # окно создавали
                getattr(v, attr).hide()
    return out
