## 1. Как устроено

**Где:** `src/view_qt/output/screen_export.py :: render_image`, `thick_pens`, `save_png`, `save_svg`;
`map_figure_window.py :: MapFigureDialog.save_screen` (раздел «Копия экрана», поле «Качество ×»); виджет карты —
`analytics_open.open_figure` (`screen=lambda: view.plot`); умолчание — `config.EXPORT_SCREEN_QUALITY` = 1.

**Суть простыми словами.** Копия экрана — это сама карта программы, сохранённая в файл, а не рисунок, построенный
заново ([МОДУЛЬ_ВЫВОДА_РИСУНКИ §14](МОДУЛЬ_ВЫВОДА_РИСУНКИ.md)). PNG при качестве ×1 совпадает с экраном пиксель в пиксель, с учётом масштаба Windows. При ×2–×4 лист
крупнее, и линии, значки и подписи крупнее в той же мере. SVG хранит линии векторами.

**Взаимодействие:**

```
«Аналитика» → «Показ карты» → MapFigureDialog («Копия экрана — PNG… / SVG…»)
  └─ save_screen(«png» | «svg») → screen_export.save_png(view.plot, путь, «Качество ×»)
        └─ render_image: QImage(область карты × разрешение экрана × качество), плотность пикселей k
              ├─ thick_pens(сцена, качество)      перья линий × качество на время выгрузки, потом — прежние
              └─ scene().render(видимая часть сцены)
     или screen_export.save_svg(view.plot, путь) → pyqtgraph SVGExporter(PlotItem)
```

**Как работает.**
1. Размер листа — область карты на экране (`viewport`) в физических пикселях: логические × `devicePixelRatioF`
   (1.5 при масштабе Windows 150 %) × качество.
2. Картинке задана плотность k = разрешение × качество: Qt рисует сцену так же, как на экране с таким масштабом, и
   значки, подписи, растры растут сами.
3. Косметические перья линий от плотности не зависят (замер ниже), поэтому `thick_pens` на время выгрузки делает
   их толще в «качество» раз — `PlotCurveItem` через `opts["pen"]`, круги и пути Qt через `pen()`, — а потом
   возвращает. При ×1 перья не трогаются.
4. Видна ровно та часть сцены, что на экране (`mapToScene(viewport)`), фон — фон вида.

```python
def render_image(widget, quality=1):
    """Видимая часть карты картинкой. Вход: виджет карты (`pg.PlotWidget`), качество ≥ 1.
    Отдаёт: QImage — физические пиксели области карты × качество (с плотностью пикселей)."""
    q = max(1.0, float(quality))                     # множитель качества
    vp = widget.viewport()                           # область карты на экране
    dpr = float(vp.devicePixelRatioF())              # разрешение экрана: 1.5 при масштабе Windows 150 %
    k = dpr * q                                      # пикселей листа на логический пиксель экрана
    img = QtGui.QImage(max(1, round(vp.width() * k)), max(1, round(vp.height() * k)),   # лист выгрузки
                       QtGui.QImage.Format_ARGB32)
    img.setDevicePixelRatio(k)
    img.fill(widget.backgroundBrush().color())       # фон вида: сцена его не рисует
    src = widget.mapToScene(vp.rect()).boundingRect()   # что видно на экране — в координатах сцены
    with thick_pens(widget.scene(), q):
        p = QtGui.QPainter(img)                      # кисть на лист
        p.setRenderHint(QtGui.QPainter.Antialiasing, True)
        widget.scene().render(p, QtCore.QRectF(0, 0, vp.width(), vp.height()), src)
        p.end()
    return img
```

```python
@contextmanager
def thick_pens(scene, q):
    """На время выгрузки — косметические перья линий и контуров толще в q раз, потом прежние.
    Вход: сцена карты, качество. Отдаёт: ничего (менеджер контекста); q = 1 — ничего не трогает."""
    saved = []                                       # (элемент, его перо) — вернуть после выгрузки
    if q != 1:                                       # ×1 — копия экрана как есть
        for it in scene.items():                     # каждый элемент сцены
            if isinstance(it, pg.PlotCurveItem):     # линия pyqtgraph — перо в opts
                pen = QtGui.QPen(it.opts.get("pen") or QtGui.QPen())   # её перо
                if pen.isCosmetic():                 # толщина в пикселях — плотность её не растит
                    saved.append((it, pen))
                    it.setPen(_scaled(pen, q))
            elif isinstance(it, QtWidgets.QAbstractGraphicsShapeItem):   # круги, многоугольники, пути Qt
                pen = QtGui.QPen(it.pen())           # перо контура
                if pen.isCosmetic():                 # то же — только косметические
                    saved.append((it, pen))
                    it.setPen(_scaled(pen, q))
    try:
        yield
    finally:
        for it, pen in saved:                        # вернуть перья, как были на экране
            it.setPen(pen)
```

```python
def save_svg(widget, path):
    """SVG копией экрана: линии, круги, многоугольники — векторами, растры — вставками PNG. Вход: виджет карты, путь.
    Отдаёт: путь. ⚠️ Размер растёт с числом линий: 150 маршрутов — 5.2 МБ (замер 18.10, план 16.01 §16.12)."""
    import pyqtgraph.exporters as ex
    if not path.lower().endswith(".svg"):            # расширение не указали
        path += ".svg"
    ex.SVGExporter(widget.getPlotItem()).export(path)
    return path
```

```python
def save_screen(self, fmt, path=None):
    """«Копия экрана — PNG / SVG»: то, что видно на карте программы (16.12). Вход: «png» | «svg», путь или None —
    спросить. Отдаёт: путь записанного файла или None."""
    import datetime
    from view_qt.output import screen_export
    w = self._screen_fn()                        # виджет карты программы
    if w is None:                                # окно открыто не с карты — копировать нечего
        self.lbl_info.setText("<b>Копия экрана: карта программы не передана</b>")
        return None
    if path is None:                             # путь не задан — окно выбора файла
        name = "карта_экран_%s.%s" % (datetime.datetime.now().strftime("%Y%m%d_%H%M"), fmt)   # имя по умолчанию
        path, _flt = QtWidgets.QFileDialog.getSaveFileName(self, "Копия экрана", name, "%s (*.%s)" % (fmt.upper(), fmt))
        if not path:                             # человек передумал
            return None
    try:
        if fmt == "png":                         # растр: физические пиксели × качество
            got = screen_export.save_png(w, path, self.screen_q.value())   # (путь, ширина, высота) или None
            if got is None:                      # Qt не записал файл
                raise OSError("файл не записан")
            path, note = got[0], "%d × %d пикс., качество ×%d" % (got[1], got[2], self.screen_q.value())
        else:                                    # вектор
            path, note = screen_export.save_svg(w, path), "векторами"
    except Exception as e:                       # не записалось — сказать, а не упасть
        self.lbl_info.setText("<b>Копия экрана не записана: %s</b>" % e)
        return None
    self.lbl_info.setText("<b>Копия экрана записана: %s (%s)</b>" % (path, note))
    return path
```

| Способ | k = 1 | k = 2 | k = 3 | Вывод |
|---|---|---|---|---|
| `ImageExporter` 4 000 пикс. (18.10) | линия 2 пикс. на листе 800 | — | — | на 4 000 — те же 2 пикс.: в 5 раз тоньше листа |
| `QWidget.render` в картинку с плотностью k | линия 2 | 1 | 0 | рисует через кэш вида — не годится |
| `scene().render` с плотностью k | линия 2, кружок 21 | 2 и 40 | 2 и 59 | значки растут, косметические линии — нет |
| то же + `thick_pens` (итог) | линия 2 | **4** | — | `gui_check` 28: лист и линия ровно вдвое |

Время и размер PNG (сцена 150 линий по 200 точек, растр 300², область 800 × 600): ×1 — 0.07 с, 0.5 МБ; ×2 — 0.17 с,
1.0 МБ; ×3 — 0.29 с, 1.5 МБ; ×4 — 0.44 с, 2.0 МБ. SVG той же сцены — 0.75 с, 5.2 МБ (18.10).

**Где легко сломать.**
* **Новый вид линий** (не `PlotCurveItem` и не фигура Qt) с косметическим пером при ×2–×4 выйдет тонким — добавить
  его в `thick_pens`.
* **Перья обязаны вернуться** даже при ошибке записи — поэтому `try / finally`; `gui_check` 28 сверяет перо после
  выгрузки.
* Подложка-тайлы при ×2–×4 растягиваются: их разрешение — уровень тайлов на экране.
* Без экрана (проверки) разрешение 1 и шрифтов нет — подписи на снимке пустые; это свойство проверки.
