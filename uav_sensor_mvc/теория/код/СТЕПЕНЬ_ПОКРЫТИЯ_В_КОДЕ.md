## 1. Галка «площадное» в паспорте типа

**Где:** `src/model/placement/sensor_types.py :: SensorType.areal`, `areal_by_radius`, `from_row`, `defaults`, ключ файла
«площадное» в `_KEYS`; `src/model/placement/sensors.py :: SensorSpec.areal`; окно —
`src/view_qt/windows/sensor_types_window.py :: FIELDS`; порог — `config.THREAT_AREAL_R_KM` = 5 км.

**Суть простыми словами.** «Площадное» — свойство типа средства, а не отдельный тип: у такого средства участки маршрутов,
которые оно видит, малым средствам «не в счёт». Галку ставит человек в окне «Тип датчика». Если в справочнике галки ещё
нет, она ставится по радиусу паспорта: больше 5 км — площадное, 5 км и меньше — малое.

**Взаимодействие:**

```
sensor_types.load → _parse → from_row(запись)        галки нет в записи → areal_by_radius(радиус паспорта)
sensor_types.defaults → areal_by_radius               встроенные типы — по тому же правилу
sensors.sensor_types(p) → SensorSpec(passport=…)      паспорт — в тип задания
  SensorSpec.areal                                    читают проход (_place_multi_type) и «Анализ» (gap_all)
SensorTypesWindow (FIELDS: "areal", "bool")           галка формы ↔ поле паспорта → sensor_types.save → to_row
```

**Как работает.** Поле `areal` — такое же поле паспорта, как `static` или `targets`: ключ файла «площадное», вид `bool`.
Окно строит галку по строке таблицы `FIELDS` и читает, заполняет и записывает её общим путём для галок. Умолчание стоит в
одном месте — `areal_by_radius`; его зовут и чтение записи, и встроенный справочник.

```python
def areal_by_radius(r_km):
    """Умолчание галки «площадное» (16.1, В16.01.2): R > THREAT_AREAL_R_KM. Вход: радиус паспорта, км. Отдаёт: bool.
    ⚠️ у номеров 1–3 радиус расчёта — поле `Params`, а не паспорт: галку у них решает человек в окне типа."""
    return float(r_km) > THREAT_AREAL_R_KM
```

```python
def from_row(row):
    """Запись файла — в тип. Вход: словарь. Отдаёт: SensorType нужного класса.
    ⚠️ Класс номеров 1–4 задан мостом (1–3 малые, 4 большой) — запись его не меняет."""
    tid = _val(row, "номер", 0, int)                 # номер из файла; 0 — не задан
    if tid in LEGACY_IDS:                            # номер моста — класс от номера
        cls = Big if tid == BIG_ID else Small
    else:                                            # новый тип — класс из записи
        cls = KINDS.get(str(row.get("класс", "")).strip(), Small)
    base = cls()                                     # умолчания класса — запасные значения
    name = _val(row, "название", base.name, str)
    vals = {field: _val(row, key, getattr(base, field), kind) for key, field, kind in _KEYS}   # поля паспорта
    # справочник до 16.1 галки «площадное» не знает — она ставится по радиусу (В16.01.2), записанная — как записана
    if KEY_BY_FIELD["areal"] not in row:
        vals["areal"] = areal_by_radius(vals["r_km"])
    return cls(type_id=tid, name=name, **vals)
```

## 2. Две задачи в общем проходе: покрытие, прирост, F

**Где:** `src/model/placement/joint_greedy.py :: two_tasks`, `_Cover`, `_two_gain`, `_cov_gain`, `_Kind.phi`,
`_Kind.gains`, `_Kind.cov_gains`, `_take`, `joint_greedy` (аргумент `areal`); вес — `config.THREAT_COVER_ALL_W` = ½.

**Суть простыми словами.** У прохода две задачи: «засечь вообще» — участок маршрута видит хоть одно средство — и
«наблюдать малыми» — участок видит малое средство. Степень покрытия — их среднее поровну. Малое место получает прирост
по обеим задачам. Площадное — только по первой: увидеть то, что малые уже видят, ему ничего не даёт. Когда в проходе нет
площадных (или нет малых), задача одна, и расчёт прежний.

**Взаимодействие:**

```
ThreatModel._place_multi_type                     threat_grid.py: типы прохода, кэши, areal=[spec.areal …]
  → joint_greedy(…, areal)                         joint_greedy.py
      → two_tasks(areal, joint)                    две задачи: покрытие общее и есть и малые, и площадные
      → _Cover(T, two)                             mask_s, cov_s — «наблюдать малыми»; None — задача одна
      → _Kind(…, areal)                            у типа — его галка
      шаг:  _Kind.gains → _two_gain → _primary_gain   ×1: задача одна или площадное · ×2: малое
            _Kind.cov_gains → _cov_gain               второй ключ, так же ×1 или ×2
            _take                                  mask, cov — всеми; mask_s, cov_s — только малыми
            _exclude → pair_sep                    разнос (§3)
      итог: _Kind.phi (F по H) + top_sum(_Kind.gains) → граница Минью прохода
```

**Как работает.** При двух задачах у общего покрытия есть вторая пара полей — сегменты и доля пути, накрытые только
малыми (`mask_s`, `cov_s`). Ставит малое — растут обе пары, площадное — только первая. Прирост малого — сумма двух
обычных приростов с весами w и 1 − w (кратность входит с весом w + (1 − w) = 1), площадного — обычный прирост с весом
a2, умноженным на w. Без второй пары (`mask_s is None`) `_two_gain` зовёт прежний `_primary_gain` теми же аргументами, а
`phi` считает прежним выражением — отсюда «до бита».

<!-- код: src/model/placement/joint_greedy.py::two_tasks -->
```python
def two_tasks(areal, joint):
    """Две ли задачи «степени покрытия» (H, 16.1): покрытие общее и в проходе есть и площадные, и малые. Вход: галки
    «площадное» типов прохода, общее ли покрытие. Отдаёт: bool; False — задача одна, расчёт прежний (E)."""
    flags = [bool(a) for a in areal]                 # галки типов прохода
    return bool(joint) and any(flags) and not all(flags)
```

<!-- код: src/model/placement/joint_greedy.py::_Cover -->
```python
class _Cover:
    """Состояние покрытия выборки: засечек на маршрут, покрытые сегменты, доля пути под наблюдением.
    Вход: число маршрутов, две ли задачи (H, 16.1). Общее для всех типов при «одной на всех», иначе у каждого своё."""

    def __init__(self, T, two=False):
        self.n = np.zeros(T, np.int64)               # засечек у каждого маршрута
        self.mask = np.zeros(T, np.uint32)           # покрытые сегменты маршрута, битами — задача «засечь вообще»
        self.cov = np.zeros(T)                       # доля пути под наблюдением, 0…1
        # задача «наблюдать малыми» (16.1, H) — то же, но только от малых типов; None — задача одна, расчёт прежний
        self.mask_s = np.zeros(T, np.uint32) if two else None   # сегменты, накрытые малыми, битами
        self.cov_s = np.zeros(T) if two else None    # доля пути под наблюдением малых, 0…1
```

<!-- код: src/model/placement/joint_greedy.py::_two_gain -->
```python
def _two_gain(H, M, n, mask, mask_s, k, L, a1, a2, areal):
    """Основной прирост со «степенью покрытия» H (16.1): малому a1·ΔK + a2·[w·ΔC(всеми) + (1 − w)·ΔC(малыми)], площадному
    a1·ΔK + a2·w·ΔC(всеми). Вход: как у `_primary_gain`, сегменты малыми (T,) uint32 или None — задача одна (E),
    площадное ли. Отдаёт: (C,)."""
    if mask_s is None:                               # задача одна — прежний прирост, до бита
        return _primary_gain(H, M, n, mask, k, L, a1, a2)
    w = THREAT_COVER_ALL_W                           # вес задачи «засечь вообще»
    if areal:                                        # площадное: малым его участки не в счёт — ΔC(малыми) = 0
        return _primary_gain(H, M, n, mask, k, L, a1, w * a2)
    # малое: w·(a1·ΔK + a2·ΔC всеми) + (1 − w)·(a1·ΔK + a2·ΔC малыми) — кратность входит с весом w + (1 − w) = 1
    g = _primary_gain(H, M, n, mask, k, L, a1, a2)   # прирост задачи «засечь вообще»
    g *= w
    g += (1.0 - w) * _primary_gain(H, M, n, mask_s, k, L, a1, a2)   # плюс задача «наблюдать малыми»
    return g
```

<!-- код: src/model/placement/joint_greedy.py::_cov_gain -->
```python
def _cov_gain(cov, Fc):
    """Прирост доли пути под наблюдением (усечение 1) у кандидатов. Вход: доля у маршрута (T,), доля в зоне кандидата
    (T, C) float32. Отдаёт: (C,). ⚠️ порядок действий прежний (`_Kind.cov_gains` до 16.1) — так эталон до бита."""
    g = cov[:, None] + Fc                            # доля с кандидатом, (T, C); float64 + float32 — те же числа
    np.minimum(g, 1.0, out=g)                        # больше всего пути не накрыть
    g -= cov[:, None]                                # прирост доли
    return g.mean(axis=0)
```

<!-- код: src/model/placement/joint_greedy.py::_Kind.phi -->
```python
def phi(self, a1, a2):
    """F типа на текущем покрытии — основной критерий в среднем по маршрутам. Вход: веса a1, a2. Отдаёт: float.
    При двух задачах (16.1) сегменты в счёт — w·накрытые всеми + (1 − w)·накрытые малыми."""
    c = self.cover                               # покрытие маршрутов: засечки, сегменты, доля пути
    if c.mask_s is None:                         # задача одна — прежнее выражение, до бита
        return float((a1 * np.minimum(c.n, self.k) / self.k + a2 * _popcount(c.mask) / self.L).mean())
    w = THREAT_COVER_ALL_W                       # вес задачи «засечь вообще»
    seg = w * _popcount(c.mask) + (1.0 - w) * _popcount(c.mask_s)   # сегментов в счёт двух задач, (T,)
    return float((a1 * np.minimum(c.n, self.k) / self.k + a2 * seg / self.L).mean())
```

<!-- код: src/model/placement/joint_greedy.py::_Kind.cov_gains -->
```python
def cov_gains(self):
    """Прирост доли пути под наблюдением (усечение 1) у всех кандидатов — второй ключ. Вход: нет — `self.cover`.
    Отдаёт: (C,). ⚠️ только после насыщения основного (13.1 Д6); при двух задачах — так же, как сегменты (16.1)."""
    c = self.cover                               # покрытие маршрутов: засечки, сегменты, доля пути
    g = _cov_gain(c.cov, self.Fc)                # прирост доли — задача «засечь вообще»
    if c.cov_s is None:                          # задача одна — прежний второй ключ
        return g
    w = THREAT_COVER_ALL_W                       # вес задачи «засечь вообще»
    if self.areal:                               # площадное малым не в счёт — только первая задача
        return w * g
    g *= w
    g += (1.0 - w) * _cov_gain(c.cov_s, self.Fc)   # плюс задача «наблюдать малыми»
    return g
```

<!-- код: src/model/placement/joint_greedy.py::_take -->
```python
def _take(kinds, t, c):
    """Поставить кандидата `c` типа `t` и обновить покрытие. Вход: типы, номер типа, номер кандидата.
    Отдаёт: ничего — меняет `chosen`, `avail` и покрытие типа (общее при «одной на всех», иначе своё).
    ⚠️ При общем покрытии засечки считаются МАТРИЦЕЙ поставившего типа — его радиусом."""
    kd = kinds[t]                                    # тип, который ставит
    kd.chosen.append(c)
    kd.avail[c] = False
    cov = kd.cover                                   # общее при «одной на всех», иначе своё
    cov.n = cov.n + kd.H[:, c]
    cov.mask = cov.mask | kd.M[:, c]
    cov.cov = np.minimum(cov.cov + kd.Fc[:, c], 1.0)
    if cov.mask_s is not None and not kd.areal:      # две задачи (16.1): «наблюдать малыми» копят только малые
        cov.mask_s = cov.mask_s | kd.M[:, c]
        cov.cov_s = np.minimum(cov.cov_s + kd.Fc[:, c], 1.0)
```

**Пример с расчётом** — примеры 1 и 2 разбора, те же числа проверяет `flow_check` 4л2. Два маршрута по L = 10 участков
(T = 2), веса a1 = 0, a2 = 1 — считается одна степень покрытия; прирост `_two_gain` × T·L — в участках.

*Пример 1 — МОГ у поста.* Пост накрыл маршрут 0: `mask` = [0x3FF, 0] (все 10 бит), `mask_s` = [0, 0] — малых нет. Место
M1 видит участки 4–5 маршрута 0 (биты 0x30), M2 — участки 0–1 маршрута 1 (0x3).
1. M1, задача «засечь вообще»: popcount(0x3FF | 0x30) − popcount(0x3FF) = 10 − 10 = 0.
2. M1, задача «наблюдать малыми»: popcount(0 | 0x30) − 0 = 2.
3. M1: ½·0 + ½·2 = **1** участок; у M2 обе задачи дают 2 — ½·2 + ½·2 = **2**.
4. E (`mask_s` = None): M1 — 0, M2 — 2. Получено: H [1.0, 2.0], E [0.0, 2.0].

*Пример 2 — пост после малых.* Маршрут A (0) накрыт малыми: `mask` = `mask_s` = [0x3FF, 0]. Место поста P1 — весь
маршрут A, P2 — весь маршрут B. Площадному считается только ½·ΔC(всеми): P1 — ½·0 = **0**, P2 — ½·10 = **5**.
У варианта F было бы 10 и 10 — пост мог встать поверх малых. Получено: [0.0, 5.0].

**Где легко сломать.**
* **Порядок действий в `phi` без двух задач.** Прежнее `a2 * _popcount(mask) / L` — это (a2·p)/L, а не a2·(p/L). Если
  свести обе ветки к одному выражению, разойдётся последний бит и снимок перестанет совпадать.
* **`mask_s` копят только малые** (`_take`). Если пустить туда площадное, H превратится в E — МОГ снова не встанут у поста.
* **Правило `two_tasks` — одно на проход и «Анализ»**: `gap_all` берёт галки типов из `gap_bounds` и зовёт ту же функцию.
  Если правила разойдутся, граница «от лучшего вообще» будет считаться не той функцией, что проход.
* **Время.** Малое при двух задачах считает `_primary_gain` дважды. Замер 18.10 (три зерна, 150 маршрутов, МОГ 10, ПВН 20,
  пост 2): расстановка 0.4–0.5 с — как у замера М4г (0.3–0.4 с). Память — вторая пара полей, T × 12 байт (150
  маршрутов — 1.8 КБ).

## 3. Разнос «площадное — малое»

**Где:** `src/model/placement/joint_greedy.py :: pair_sep`, `_exclude`; проверка — `tools/placement_check.py ::
cross_rule_stats` (та же функция).

**Суть простыми словами.** Между местами разных типов держится разнос. Обычно он считается по сумме двух радиусов. Но
если одно средство площадное, а другое малое, мерой служит малый радиус: малое не ставится вплотную к площадному, но
может стоять внутри его зоны.

**Взаимодействие:**

```
joint_greedy → _exclude(kinds, t, c, pair)   после каждого выбора
```

```python
def pair_sep(pair, r1, r2, areal1=False, areal2=False):
    """Разнос мест двух разных типов, км: pair·(R₁ + R₂); пара «площадное — малое» — pair·2·R_малого (16.1, решение 17.10).
    Вход: доля пары, радиусы типов, км, их галки «площадное». Отдаёт: км."""
    if areal1 != areal2:                             # одно площадное, другое малое — мера разноса малый радиус
        return pair * 2.0 * (r2 if areal1 else r1)
    return pair * (r1 + r2)
```

**Пример с расчётом** (pair = `THREAT_SPREAD_PAIR` = 0.8):

| Пара | Было: 0.8·(R₁ + R₂) | Стало | Почему |
|---|---|---|---|
| МОГ 1 км — пост 25 км (площадное) | 20.8 км | 0.8·2·1 = **1.6 км** | одно площадное — малый радиус |
| ПВН 0.5 км — пост 25 км | 20.4 км | 0.8·2·0.5 = **0.8 км** | то же |
| МОГ 1 км — ПВН 0.5 км | 1.2 км | 1.2 км | оба малые — как было |
| два площадных 15 и 25 км | 32 км | 32 км | оба площадные — как было |

Замер `out_test/plan16/m16_1/h_measure.py` (18.10): ни одного МОГ ближе 1.6 км к посту ни в одном из трёх зёрен.

**Где легко сломать.** Галка «площадное» заменяет прежнюю границу «больше в 4 раза» (план 16 §3.1): если вернуть
сравнение радиусов, правило снова будет зависеть от подобранного 0.8. Тип 4 (кольцо) ставится после прохода и в
`_exclude` не участвует.

## 4. Граница «в целом» в «Анализе»

**Где:** `src/model/placement/joint_greedy.py :: whole_bound`; `src/model/threat/threat_grid.py :: ThreatModel.gap_whole`,
`ThreatModel.gap_all` (прибавки `_gap_diff`); `src/controller_qt/threat_controller.py :: ThreatController._gap_html`.

**Суть простыми словами.** У расстановки одна функция F на все типы, поэтому можно сказать, насколько весь набор не хуже
лучшего, а не только каждый тип. При общей кратности граница прохода и так одна, строка «в целом» показывает её прямо.
При своей кратности у каждого типа своё покрытие, и F всего набора — сумма F типов. «От лучшего вообще» прибавляет к
границе выигрыш, который дали бы места вне карты места у каждого ограниченного типа.

**Взаимодействие:**

```
ThreatController._gap_html                    окно «Анализ», раздел «ЗАЗОР ДО ОПТИМУМА»
  → ThreatModel.gap_all()                     по типам с картой места; копит _gap_diff[t] = max(0, лучшее без карты − на карте)
  → ThreatModel.gap_whole()                   → whole_bound(gap_bounds, общее ли покрытие)
  → ThreatModel.gap_whole(all_places=True)    → gap_all() → whole_bound(…, extra=_gap_diff)
```

<!-- код: src/model/placement/joint_greedy.py::whole_bound -->
```python
def whole_bound(bounds, joint, extra=None, gain=False):
    """Граница «в целом» (16.1, В16.01.3): при общем покрытии оценка одна на проход, при своём — сумма по типам. Вход:
    {номер: dict(F, F0, [FA,] UB)}, общее ли покрытие, {номер: прибавка к UB без запрета мест} или None, gain — база —
    закреплённые («от прироста», 20.10.2026). Отдаёт: доля 0…1 — «не хуже стольких от лучшего»; оценок нет — None."""
    bds = [b for b in bounds.values() if b]          # оценки типов, у которых они есть
    if not bds:                                      # расстановки по маршрутам не было
        return None
    base = "FA" if gain else "F0"                     # от чего доля: после закреплённых или до прохода
    bds = [dict(b, FA=b.get("FA", b["F0"])) for b in bds]   # путь одного типа закреплённых не знает — база F0
    keys = ("F", base, "UB")                          # F набора, база доли, граница OPT
    if joint:                                        # покрытие общее — у всех типов одна и та же оценка прохода
        f, f0, ub = (float(bds[0][key]) for key in keys)   # F набора, база доли, граница — оценки прохода
    else:                                            # у типа своё покрытие — F всего набора есть сумма F типов
        f, f0, ub = (sum(float(b[key]) for b in bds) for key in keys)   # те же три — суммой по типам
    ub += sum(max(0.0, float(v)) for v in (extra or {}).values())   # без запрета мест граница только выше
    return _share(f, f0, ub)
```

<!-- код: src/model/threat/threat_grid.py::ThreatModel.gap_whole -->
```python
def gap_whole(self, all_places=False, gain=False):
    """Зазор «в целом» по всем типам прохода (план 16.01, 16.1; В16.01.3). Вход: all_places — от лучшего вообще (зовёт
    `gap_all`, дорого); gain — «от прироста»: что добавил жадный сверх закреплённых и ПВН у целей (20.10.2026).
    Отдаёт: доля 0…1; расстановки не было или (при gain) закреплённых нет — None."""
    from model.placement.joint_greedy import whole_bound
    bounds = getattr(self, "gap_bounds", {}) or {}   # оценки прохода по типам: F, F0, FA, UB
    # «от прироста», а закреплённых нет (FA = F0 у всех типов) → None: число равно «от всего», вторая строка не нужна
    if gain and not any(b and float(b.get("FA", b["F0"])) > float(b["F0"]) + 1e-12 for b in bounds.values()):
        return None
    extra = None                                 # прибавки к границе без запрета мест
    if all_places:                               # от лучшего вообще — прибавки всех типов с картой места
        self.gap_all()
        extra = getattr(self, "_gap_diff", None)
    return whole_bound(bounds, bool(getattr(self.p, "threat_k_same", True)), extra, gain=gain)
```

<!-- код: src/controller_qt/threat_controller.py::ThreatController._gap_html -->
```python
def _gap_html(self, me):
    """Раздел «ЗАЗОР ДО ОПТИМУМА» окна «Анализ» (план 13.1, Д4): на разрешённых местах и от лучшего вообще.
    Вход: показатели расстановки. Отдаёт: HTML; оценок нет — пусто."""
    gap = me.get("gap") or {}                      # на разрешённых (тех же) местах
    if not gap:                                    # расстановки по маршрутам не было
        return ""
    allg = self.model.gap_all()                    # от лучшего вообще — по запросу, дорого
    out = ["<h3>ЗАЗОР ДО ОПТИМУМА (граница Минью)</h3><ul>"]
    # «В ЦЕЛОМ» (план 16.01, 16.1; В16.01.3): одна функция F на все типы — граница всего набора; при общей
    # кратности она же стоит у каждого типа «везде», у типа с картой места своя — «от лучшего вообще»
    whole = self.model.gap_whole()                 # на разрешённых местах, доля 0…1 или None
    if whole is not None and allg:                 # есть типы с картой места — две величины
        out.append("<li><b>в целом</b>: не хуже %.0f%% от лучшего <b>на разрешённых местах</b> · %.0f%% <b>от "
                   "лучшего вообще</b></li>" % (100 * whole, 100 * self.model.gap_whole(all_places=True)))
    elif whole is not None:                        # все типы «везде» — величина одна
        out.append("<li><b>в целом</b>: не хуже %.0f%% от лучшего</li>" % (100 * whole))
    # «ОТ ПРИРОСТА» (заказчик 20.10.2026): что добавил жадный сверх закреплённых человеком и ПВН у целей — от лучшего
    # добавления; закреплённых нет — строки нет: оба числа равны
    gain = self.model.gap_whole(gain=True)         # доля прироста жадного или None
    if gain is not None:                           # закреплённые есть — второе число
        out.append("<li><b>прирост жадного</b> (сверх закреплённых и ПВН у целей): не хуже %.0f%% от лучшего "
                   "прироста на разрешённых местах</li>" % (100 * gain))
    for t, ratio in sorted(gap.items()):              # тип и его доля «от лучшего вообще»
        if t in allg:                              # у типа карта места — две величины
            out.append("<li>тип %d: не хуже %.0f%% от лучшего <b>на разрешённых местах</b> · %.0f%% <b>от лучшего "
                       "вообще</b> (без запрета мест, по итоговому набору)</li>" % (t, 100 * ratio, 100 * allg[t]))
        else:                                      # тип «везде» — величины совпадают
            out.append("<li>тип %d: не хуже %.0f%% от лучшего (места не ограничены — величина одна)</li>"
                       % (t, 100 * ratio))
    out.append("</ul><p style=\"color:#8a93a6\">Это нижняя граница, а не точная доля: настоящий результат "
               "обычно ближе к лучшему. Разбор — датчики/ЗАЗОР_И_МАТРОИД §5.</p>")
    return "".join(out)
```

**Пример с расчётом** (`out_test/plan16/m16_1/h_measure.py`, зерно 1000, H). Доля прохода F0 = 0: она берётся до закреплённых, на пустом
покрытии. Значит, доля = F / UB. Получено: в целом 0.909; от лучшего вообще у типа 1 (МОГ, карта «дорога») — 0.864, у
типа 2 (ПВН, «застройка») — 0.875. «В целом вообще» по шагам, в долях F:
1. UB = F / 0.909 = 1.1001·F.
2. Прибавка типа 1: F / 0.864 − F / 0.909 = (1.1574 − 1.1001)·F = 0.0573·F; типа 2: (1.1429 − 1.1001)·F = 0.0428·F.
3. UB вообще = (1.1001 + 0.0573 + 0.0428)·F = 1.2002·F → доля 1 / 1.2002 = **0.833** — столько и показал `gap_whole(all_places=True)`.

**Вторая строка — «прирост жадного»** (20.10.2026): `joint_greedy` запоминает FA — F сразу после закреплённых (ПВН у
целей, поставленные человеком), `whole_bound(…, gain=True)` считает долю от неё, `gap_whole(gain=True)` отдаёт None,
если закреплённых нет (числа равны). Пример: F 0.839, FA 0.289, граница 0.979 → (0.839 − 0.289) / (0.979 − 0.289) =
0.797 — «прирост жадного: не хуже 80 %» при «в целом 86 %».

**Где легко сломать.**
* **Не ключ `metrics()`, а метод.** Снимок `golden.py` кладёт весь `metrics()` — новый ключ дал бы расхождение в снимке
  755 ключей без смены расчёта.
* **При общей кратности строки типов «везде» повторяют «в целом»** — оценка прохода одна (`joint_greedy`, конец). Отличаются
  только «от лучшего вообще» у типов с картой места.
* `gap_whole(all_places=True)` зовёт `gap_all` — у ПВН `arh` это 6.9 с (13.1 Д4): только по запросу «Анализа».
* `_gap_diff` обнуляется в начале каждого счёта `gap_all`: при раннем выходе («считать не по чему») прибавок нет.
