# Режим «без остановок» — ВКЛЮЧИТЬ

Заведён 14.09.2026 по команде заказчика: «разработай новый режим работы для себя без
остановок, ты всё делаешь кроме коммитов и пушей … чтобы меня не спрашивать».
Разбор — `теория/переносимое/5_РАЗРЕШЕНИЯ_КОМАНД.md` §0.

```bash
cp ".claude/режимы/без_остановок.json" .claude/settings.json
python -m json.tool .claude/settings.json
```

Проверить по коду возврата, что JSON цел. Сообщить одной строкой: «режим без остановок
включён».

## 2. Как работать, пока режим включён

| Делаю сам, не спрашивая | Только по команде заказчика |
|---|---|
| код, свои скрипты, разведку | `git commit`, `git push` |
| ВСЕ прогоны: `reference_run`, `reference_cases`, проверки документации, пересборку слоёв `pack_area` / `build_threat_grid`, докачку тайлов | затереть незакоммиченное (`checkout`, `restore`, `reset`, `clean`) |
| документацию по правилам `CLAUDE.md`: методички, журнал, план, `РАБОТА.md`, отметки «Правился» — **сразу, без вопроса «обновить?»** | удалить папку данных (`geo_cache`, `tile_cache`), сборку `.exe` |
| развилки — выбираю вариант с лучшим обоснованием и **записываю выбор** в план или журнал | решения, которые заказчик уже оставил за собой (вопросы В*, задачи «только по команде») |

1. **Не останавливаться и не спрашивать.** Не заканчивать ход вопросом, не вызывать
   окно вопросов. Нужно решение, а данных нет — взять осторожный вариант, записать его
   и идти дальше.
2. **Долгие прогоны — в фоне**, пока идут — делать документацию.
3. **Правила проекта не отменяются:** комментарии в новом коде, «пояснение плюс
   пример», числа только из замера, каталог работы, эталон §6, семь проверок программы.
   Режим отменяет только ВОПРОСЫ, а не проверки.
4. **Что заказчик оставил за собой — не делается и в этом режиме:** задачи с пометкой
   «не начинать без команды» (10.9, 10.13, отложенные теги, `osmium`), открытые вопросы
   В*, 10.1-б, ветка `exe-build-2`, файл `координаты.txt`. Их — в итог, отдельной строкой.
5. **В конце — одно уведомление:** что сделано, какие проверки прошли (по коду
   возврата), что вынесено на решение, готово ли к коммиту.
6. Команды — без приставок `cd`, `VAR=`, циклов и heredoc: `ask` сверяется с началом
   части команды, и приставка может спрятать коммит от проверки.
