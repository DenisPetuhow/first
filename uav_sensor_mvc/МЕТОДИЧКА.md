# Методичка: оптимальное размещение датчиков обнаружения БПЛА

Мини-обзор модели: постановка задачи (вербально и математически), все модели
движения БПЛА, модель появления старта, ограничения и условия имитации, модель
обнаружения и метод оптимизации — с формулами, пояснением каждой переменной и
обоснованием выбора методов.

> 🗺️ Подсистема **реальной карты** (вкладка 2: тайлы, кэш, оффлайн-схема Курской
> области, клики A→B) вынесена в отдельный документ — **[`МЕТОДИЧКА_КАРТА.md`](МЕТОДИЧКА_КАРТА.md)**.

## 1. Постановка задачи

### 1.1. Вербально

Беспилотник самолётного типа (тип «Shahed-136 / Герань-2») летит из района
**старта A** в **цель B**, имея ограниченный запас хода (дальность) **L_max**.
Точный маршрут заранее не известен: БПЛА может идти по прямой, отклоняться дугой,
маневрировать ломаной/змейкой в пределах запаса хода. Нужно расставить **N
датчиков обнаружения** с радиусом действия **R** так, чтобы как можно лучше
«видеть» БПЛА на любом из возможных маршрутов:
* обнаруживать его **кратно** (несколькими датчиками — критерий пересечения),
* и **равномерно вдоль всего пути** (критерий распределения/сопровождения).

Маршрут заранее неизвестен, поэтому задача **стохастическая**: оптимизируем
математическое ожидание полезности по случайным маршрутам.

### 1.2. Математически

Пусть `Γ` — случайный маршрут БПЛА (реализация `γ`) с распределением,
определяемым выбранной моделью движения и профилем разброса.
`S = {s₁, …, s_N}` — множество позиций датчиков, `s_j ∈ ℝ²`.

Полезность одного размещения на одном маршруте:

```
φ(S, γ) = α₁ · min(n(S,γ), k)/k  +  α₂ · m(S,γ)/L_seg        (1)
```

* `n(S,γ)` — число РАЗЛИЧНЫХ датчиков, засёкших маршрут (кратность обнаружения);
* `k` — требуемая кратность (целевое число независимых засечек);
* `min(n,k)/k ∈ [0,1]` — нормированная кратность с насыщением (больше `k` не нужно);
* `m(S,γ)` — число покрытых сегментов из `L_seg` равных частей маршрута (равномерность);
* `m/L_seg ∈ [0,1]` — доля покрытых сегментов (мера сопровождения вдоль пути);
* `α₁, α₂` — веса критериев пересечения и распределения (`α₁+α₂=1`), задаются режимом.

Целевая функция (математическое ожидание полезности):

```
F(S) = E_Γ[ φ(S, Γ) ] → max,   при |S| = N.                  (2)
```

Распределение `Γ` в явном виде неизвестно, поэтому используется **выборочное
среднее (SAA — Sample Average Approximation)**: накапливаем `t` независимых
маршрутов `γ₁,…,γ_t` и максимизируем эмпирическое среднее

```
F_t(S) = (1/t) · Σ_{i=1..t} φ(S, γ_i)  →  max,  |S| = N.      (3)
```

При `t → ∞` `F_t(S) → F(S)` (закон больших чисел), поэтому решение SAA сходится к
решению исходной стохастической задачи.

## 2. Геометрия задачи

### 2.1. Эллипс достижимости

Любая точка `P` маршрута длиной `≤ L_max` удовлетворяет
`|PA| + |PB| ≤ L_max`, то есть лежит в эллипсе с фокусами A и B:

```
E = { P : |PA| + |PB| ≤ L_max }
большая полуось   a = L_max / 2
фокальное расст.  c = |AB| / 2
малая полуось     b = √(a² − c²)                              (4)
```

* `|PA|, |PB|` — расстояния от точки до старта и цели;
* центр эллипса — середина AB; угол поворота — направление A→B.

Смысл: ограничение по запасу хода **автоматически** удерживает весь маршрут
внутри `E` — отдельная проверка «не вышли за эллипс» не нужна (см. `geometry.py`).

### 2.2. Коридор движения

Эллипс — слишком грубая оболочка (включает «мёртвые» зоны, куда реальный маршрут
из A в B не заходит). Поэтому кандидатные позиции датчиков и масштаб карты
ограничиваются **коридором** — областью между предельными маршрутами:
* для дуг — между дугами ±θ_max;
* для змеек — под огибающей `|y| ≤ b·sin(πx/d)`;
* для манёвра — половины эллипса достижимости.

### 2.3. Зона старта (вкладка 2)

В режиме «зона старта → цель» старт БПЛА — не точка, а **эллипс
неопределённости** с центром A:

```
зона старта: ((P−A)·û / (depth/2))² + ((P−A)·n̂ / (width/2))² ≤ 1   (5)
```

* `û` — орт оси A→B, `n̂` — перпендикуляр к ней;
* `depth` — глубина зоны (вдоль оси A→B), `width` — ширина (поперёк);
* `depth/2, width/2` — полуоси эллипса зоны.

Точка старта `S₀` каждого маршрута выбирается равномерно внутри этого эллипса.

**Огибающая достижимости (с учётом зоны).** Маршрут из `S₀` длиной `≤ L_max`
лежит в эллипсе с фокусами `S₀, B` (а не `A, B`). Поэтому показывается не эллипс
`A,B`, а **огибающая** — объединение эллипсов `(S₀, B)` по всем `S₀` из зоны:

```
Reach = { P : dist(P, зона) + |P−B| ≤ L_max }                 (5a)
```

Множество звёздно относительно `B` (общий фокус), поэтому контур считается как
максимальный радиус по направлениям через полярное уравнение эллипса из фокуса
`B`: `r(S₀,θ) = (L_max² − |B−S₀|²) / (2·(L_max + (B−S₀)·d̂))`, максимум по `S₀`
на границе зоны (`reach_envelope_outline`). Любой маршрут целиком лежит внутри
этой огибающей — ни один не выходит за контур.

## 3. Физика движения БПЛА (ТТХ → ограничения)

### 3.1. Минимальный радиус разворота

В координированном развороте с креном `φ` на скорости `V`:

```
R_min = V² / ( g · tan φ )                                    (6)
```

* `V` — путевая скорость БПЛА, м/с (из ТТХ; для Герань-2 ≈ 180 км/ч ≈ 50 м/с);
* `φ` — максимальный угол крена, рад (ТТХ; по умолчанию 25°);
* `g = 9.81 м/с²` — ускорение свободного падения;
* `R_min` — минимальный радиус разворота (в коде переводится в км).

Смысл: кривизна любого манёвра ограничена `κ ≤ 1/R_min`. При `V=180 км/ч`,
`φ=25°` получаем `R_min ≈ 0.55 км` — на картах в сотни км это ограничение
почти не «связывает», но оно физически корректно и страхует резкие манёвры.
Крен и скорость — это ТТХ аппарата, задаются пользователем в полях «Скорость
км/ч» и «Крен °».

### 3.2. Время полёта

```
t_полёта = расстояние / V                                     (7)
```

Оценивается диапазоном от `|AB|/V` (прямая) до `L_max/V` (максимальный обход).

## 4. Модели движения БПЛА

Маршрут — массив `n_points` точек от старта к B. Профиль **РАЗБРОСА** задаёт
**амплитуду** отклонения от прямой (НЕ число точек): `малый` (жмётся к прямой),
`средний`, `сложный` (к краям эллипса), `смешанный` (случайный выбор одного из
трёх каждую итерацию — поэтому встречаются и прямые маршруты).

### 4.1. Дуга по углу отклонения θ (вкладка 1, этап 1)

Дуга окружности A→B, заданная знаковым касательно-хордовым углом `θ`:

```
длина дуги:   ℓ(θ) = c_len · θ / sin θ                        (8)
радиус дуги:  R_arc = c_len / (2 · sin θ)
предельный угол θ_max:  ℓ(θ_max) = L_max  (бинарный поиск)
```

* `c_len = |AB|` — длина хорды; `θ` — угол между хордой и касательной в A;
* `θ=0` — прямая; растёт `|θ|` — дуга длиннее и круче; `θ_max` — предел по запасу хода.

Выбор угла по профилю (`_sample_angle`):
* `малый/normal` — усечённое нормальное `N(0, σ)`, `σ = sigma_frac·θ_max` (короткий путь чаще);
* `средний/mixed` — равномерно на `[−θ_max, θ_max]`;
* `сложный/complex` — тяготеет к `±θ_max` (сильно выгнутые дуги).

### 4.2. Петля / змейка (вкладка 1, этап 2)

Синусоида с закреплёнными концами:

```
y(t) = amp · sin(πt) · sin(π·n_lobes·t + ph),  t ∈ [0,1]      (9)
```

* `amp` — амплитуда петли (по профилю, в пределах `amp_max` по запасу хода);
* `n_lobes` — число лепестков; `ph` — фаза; `sin(πt)` — огибающая (ноль на концах);
* `amp_max` подбирается так, что длина = L_max (аналог `θ_max`).

### 4.3. Манёвр «по точкам» (главная модель, обе вкладки)

Маршрут самолётного типа: `S₀ → путевые точки → B`, отрезки соединены, углы
**скруглены дугами** радиуса `≥ R_min`. Это соответствует реальным маршрутам
Shahed (ломаные с плавными доворотами).

**Число точек** — случайно в пользовательском диапазоне `[n_min, n_max]`
(поля «Точек от/до»), но не больше физического предела `D/(4·R_min)`.

**Положение точки `i` (продольно)** — стратификация по доле пути со случайным
сдвигом (неравномерные расстояния):

```
frac_i = clip( s_lo + (0.95 − s_lo)·(i+1 + ξ)/(n+1),  s_lo, 0.95 )   (10)
s_i    = frac_i · D,   D = |B − S₀|,   ξ ~ U(−0.35, 0.35)
```

**Боковой вынос точки (амплитуда = «разброс»)** — линза, нулевая на концах. База
амплитуды — `b` (полу-малая ось эллипса достижимости = МАКС. достижимый боковой
вынос), а не хорда `D`:

```
b = √( (L_max/2)² − (|S₀B|/2)² )                              (11a)
x_i = (frac_i − s_lo) / (1 − s_lo)                            (11b)
h_i = sign_i · u · ρ · b · 4 · x_i · (1 − x_i)               (11)
```

* `b` — максимально достижимый боковой вынос (полу-малая ось эллипса S₀↔B);
* `ρ` — амплитуда как ДОЛЯ от `b` по профилю: малый ≈0.08–0.25, средний ≈0.32–0.62,
  сложный ≈0.70–1.05 (сложный достаёт до краёв эллипса);
* `x_i` — доля внутри ДОСТУПНОГО диапазона `[s_lo, 1]` (линза якорится на нём, см.
  §6.1) — это сохраняет полную амплитуду и когда точки сдвинуты за зону;
* `u ~ U(u_min, 1)` — доля выноса (в сложном `u_min≈0.90` → точки у края);
* `4·x·(1−x)` — форма линзы (ноль у границы и у B, максимум посередине);
* `sign_i` — сторона. В сложном — НЕ частый зигзаг, а 1–2 КРУПНЫХ лепестка
  (точки одной стороны образуют большой вынос ~b; узкий зигзаг при многих точках
  не успевает уйти от центра в пределах `L_max`). Разные маршруты выбирают разную
  сторону — огибающая заполняет эллипс с разных направлений.

База на `b` (а не `D`) принципиальна: вынос укладывается в запас хода и не
схлопывается «фитом» (укладкой в `L_max`) в прямую линию.

**Скругление углов** (`_round_corners`): в вершине с доворотом `Δψ` строится
дуга радиуса `R = T/tan(Δψ/2)`, где `T = turn_frac·min(ℓ_вх, ℓ_вых)` (пологость),
но `R` не меньше `R_min`. Между дугами — прямые участки. Кривизна ≤ `1/R_min`.

**Укладка в запас хода**: если длина > L_max, амплитуда выноса плавно
уменьшается (масштаб 1.0 → … → 0.0 = прямая), пока длина ≤ L_max.

### 4.4. Манёвр «по синусу» (альтернативный закон, выпадающий список)

Боковое отклонение — сумма гармоник (гладкая волна без прямых участков):

```
lat(t) = Σ_{j=1..lobes} a_j · sin(jπt),  t ∈ [0,1]            (12)
```

* `a_j` — амплитуда `j`-й гармоники (по режиму `ρ`, случайный знак);
* `lobes` — число горбов (по режиму).

**Учёт R_min** (добавлено по требованию): кривизна гармоники
`a_j·sin(jπx/D)` ≈ `|a_j|·(jπ/D)²`. Суммарная кривизна ограничивается сверху:

```
Σ_j |a_j|·(jπ/D)²  ≤  1/R_min;                                (13)
если превышено — все a_j масштабируются коэффициентом f = (1/R_min)/Σ(…).
```

Так синусоидальный манёвр не закладывает виражи круче физически возможных
(`R_min` из крена и скорости). Длина так же ужимается до L_max.

### 4.5. Дуга из старта (вкладка 2)

Та же дуга (4.1), но из случайной точки старта `S₀` в B; угол по профилю.

### 4.6. Ломаная (вкладка 2)

Тот же путь по точкам (4.3), но БЕЗ скругления углов (острые довороты) —
демонстрирует «угловой» манёвр.

## 6. Ограничения и условия имитации

### 6.1. Путевые точки и зона старта (выпадающий список, вкладка 2)

Список «Точки маршрута»:
* **«в зоне старта»** (по умолчанию) — `s_lo = 0.05`: точки могут появляться по
  всему пути, включая зону неопределённости (полный разброс «с первого метра»).
* **«только за зоной»** — путевые точки ставятся за эллипсом
  старта. Доля `s_lo = _zone_exit_frac(S₀,A,B,depth,width)` — опорная проекция
  эллипса зоны на ось S₀→B:

  ```
  s_lo = ( (A−S₀)·ê∥ + √[ (a·(û·ê∥))² + (b·(n̂·ê∥))² ] ) / D + запас   (14)
  ```
  где `a=depth/2`, `b=width/2`, `ê∥=(B−S₀)/D`. Точка, стоящая дальше этой
  проекции, лежит за опорной плоскостью эллипса, поэтому её боковой вынос
  (перпендикулярный оси, проекция сохраняется) **не может вернуть её в зону**.
  БПЛА выходит из района пуска, затем маневрирует.

Это — мягкое модельное условие (зона старта — область неопределённости, а не
физическое препятствие), поэтому вынесено в переключатель.

### 6.2. Датчики не размещаются в зоне старта и «за её спиной» (вкладка 2)

Кандидаты под датчики **исключаются**, если они (а) попадают внутрь эллипса
зоны (5) — `points_outside_start_zone`, либо (б) лежат «за спиной» зоны (позади
её задней кромки по оси A→B):

```
(P − A)·û  ≥  −depth/2                                        (14a)
```

то есть датчики допустимы только в полупространстве в сторону цели (180° от
задней точки эллипса старта `A − (depth/2)·û`). Смысл: свои датчики нельзя
ставить ни в районе пуска противника, ни за ним — только в коридоре к цели.
Это **жёсткое** условие (не переключается).

### 6.3. Датчики не размещаются за целью B

Кандидаты с проекцией на ось A→B больше `|AB|` убираются
(`filter_not_past_target`): маршруты заканчиваются в B, позиции за B бесполезны
и давали «кучу» позади цели.

### 6.4. Якорный датчик у цели и минимальная развязка

Первым принудительно ставится «якорный» датчик у B (центр на `B − ⅔R·ê∥`, его
зона на ⅓R заходит за B — рубеж непосредственно у цели). Кандидаты ближе
`anchor_sep = 1.35·R` к якорю исключаются (≤ ~10 % перекрытия — без «кучи» у B).

### 6.5. Физические ограничения манёвра

Кривизна любого манёвра `≤ 1/R_min` (скругление дугами/масштаб гармоник);
число точек `≤ D/(4·R_min)`; вся траектория — внутри эллипса достижимости (4).

## 7. Модель обнаружения и метрики

Обнаружение — факт входа маршрута в зону радиуса `R` хотя бы одного датчика
(повторный вход того же датчика не учитывается).

```
кратность:        n(S,γ) = #{ j : min_t |γ(t) − s_j| ≤ R }   (15)
сегментное покр.: m(S,γ) = #{ покрытых сегментов из L_seg }   (16)
сопровождение:    cov(S,γ) = (длина пути под наблюдением) / (длина пути)  (17)
вне зоны:         (1 − cov) · длина пути   [км]
```

* `γ(t)` — точки маршрута; `s_j` — позиция датчика `j`; `R` — радиус обнаружения;
* `min_t |γ(t)−s_j| ≤ R` — маршрут хотя бы раз вошёл в зону датчика `j`;
* `L_seg` — число равных сегментов разбиения маршрута (мера равномерности);
* `cov` — доля длины пути, проходящая в зоне хотя бы одного датчика;
* `доля ≥ k` — доля маршрутов выборки, обнаруженных не менее `k` раз.

Итоговая полезность размещения — формула (1); среднее по выборке — (3).

## 8. Метод оптимизации

### 8.1. Дискретизация

Непрерывная задача размещения сводится к выбору `N` позиций из конечной сетки
кандидатов `C` (после фильтров §6). Это превращает (3) в задачу **максимизации
монотонной субмодулярной функции при кардинальном ограничении** `|S|=N`.

### 8.2. Субмодулярность и жадный алгоритм

`F_t(S)` — монотонна (добавление датчика не ухудшает покрытие) и субмодулярна
(прирост от нового датчика убывает с ростом `S` — «закон убывающей отдачи»:
`min(n,k)` и доля покрытых сегментов — насыщающиеся величины).

Для таких функций **жадный алгоритм** (на каждом шаге берём кандидата с
максимальным предельным приростом `Δφ`) даёт гарантию:

```
F_t(S_greedy) ≥ (1 − 1/e) · F_t(S*) ≈ 0.632 · F_t(S*)         (18)
```

(Nemhauser, Wolsey, Fisher, 1978) — `S*` оптимум. Точный перебор `C(|C|,N)`
комбинаторно неподъёмен, а жадный — `O(N·|C|·t)` с близким к оптимуму результатом.

### 8.3. Инкрементальный SAA и структура покрытия

`CoverageCache` для каждого маршрута `i` и кандидата `c` хранит:
* `hit[i,c]` — засекает ли датчик в `c` маршрут `i` (кратность);
* `segmask[i,c]` — битовую маску покрытых сегментов (равномерность, `popcount`);
* `covfrac[i,c]` — долю точек маршрута в зоне датчика (распределение).

Это позволяет **векторизованно** (numpy) оценивать предельный прирост по всем
кандидатам сразу. Маршруты добавляются по одному (инкрементально), расстановка
пересчитывается после каждого — выборка растёт, оценка стабилизируется.

### 8.4. Вторичный критерий (распределение)

Когда основной критерий (кратность+равномерность) насыщается на малой выборке,
включается вторичный — прирост покрытой доли маршрутов (лексикографически): он
разносит оставшиеся датчики по самым частым путям, а не останавливает выбор.

### 8.5. Режимы оптимизации (веса `α₁,α₂`)

| Режим | α₁ (пересечение) | α₂ (распределение) | Смысл |
|---|---|---|---|
| распределение | 0.25 | 0.75 | равномерно вдоль пути |
| пересечение | 0.75 | 0.25 | кратное обнаружение |
| сбалансированный | 0.50 | 0.50 | компромисс |

## 9. Обзор методов и обоснование выбора

* **SAA вместо аналитики.** Распределение маршрутов сложное (нелинейные модели,
  профили, зона старта) — замкнутой формулы для `E[φ]` нет. Выборочное среднее
  сходится к матожиданию и легко учитывает любые модели движения.
* **Жадный субмодулярный выбор вместо полного перебора / MILP / эвристик.**
  Полный перебор экспоненциален; MILP для покрытия с кратностью тяжёл и не
  масштабируется; метаэвристики (GA, PSO) не дают гарантий. Жадный алгоритм —
  быстрый, детерминированный и с теоретической гарантией `1−1/e` (18).
* **Эллипс достижимости вместо моделирования физики полёта в каждой точке.**
  Свойство фокусов эллипса даёт строгую и дешёвую оболочку всех маршрутов;
  избавляет от проверок «вышли за дальность» в цикле.
* **Модель «по точкам» вместо чистой синусоиды как основной.** Реальные карты
  маршрутов Shahed — это ломаные с плавными доворотами, а не гладкие синусы;
  модель по точкам ближе к натуре. Синус оставлен как альтернатива (список).
* **R_min из ТТХ (крен/скорость), а не «на глаз».** Кривизна манёвра привязана
  к физике координированного разворота (6), что делает траектории реалистичными.
* **Якорь у цели + развязка + фильтры зоны/за-B.** Убирают вырожденные решения
  («куча» у B, датчики в недостижимых/запретных зонах), повышают практическую
  осмысленность расстановки.

### Слои показа (что рисует каждый чекбокс)

* **Тепловая карта** — 2D-плотность ВСЕХ точек накопленной выборки (где БПЛА
  бывает чаще/реже). Полная картина распределения маршрутов.
* **10 маршрутов** — ПРЕДИКТИВНЫЙ слой: 10 наиболее вероятных траекторий как
  ОБОБЩЕНИЕ всей накопленной выборки (не случайная выборка). Маршруты
  кластеризуются по форме (k-means), от каждого кластера берётся медоид (реальный
  маршрут-представитель), толщина/яркость линии = доля кластера = вероятность
  такого пролёта (`representative_trajectories`). До накопления выборки — резерв:
  аналитический набор по профилю (квантили; для манёвра — равномерно по сторонам).
* **Веер маршрутов** — геометрия ПРОСТРАНСТВА возможных маршрутов (не зависит от
  выборки):
  * дуги — семейство дуг с шагом угла `angle_step`, предельные ±θ_max пунктиром
    (рубеж запаса хода);
  * петли — семейство по шагу амплитуды (предельная пунктиром);
  * манёвр/ломаная — представительный НАБОР манёвров (пространство манёвров
    многомерно, единого «шага» нет, поэтому показывается выборка типовых манёвров,
    очерчивающая достижимую область). Это иллюстрация охвата, а не квантование.

Метрики: средняя кратность, % сопровождения (покрытие пути), длина вне зоны (км),
доля маршрутов с обнаружением ≥ k.
